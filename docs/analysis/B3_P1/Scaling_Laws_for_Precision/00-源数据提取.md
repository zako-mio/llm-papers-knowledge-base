## §4 方法
- 记号：Pw/Pa/Pkv=训练时权重/激活/KV cache 精度，Ppost=推理前 PTQ 精度；δPTQ 为 PTQ 引起的损失退化。基座为 OLMo-style Transformer++，数据 Dolma V1.7；PTQ 用 GPTQ（附录 F 用另两种方法复现）
- 概念框架（§2.1）：按瓶颈二分工作负载——预训练是 compute-bound（大矩阵乘），小 batch 推理受权重带宽约束，长序列解码受 KV cache 带宽约束；据此区分"仅权重量化"（QAT，无算力收益但利于部署）与"全量化训练"（低精度训练，可省矩阵乘算力）；按时机分 during-training 与 post-train
- 函数形式选择（§2.2/Table 1）：比较加性独立幂律、Neff/Deff 绑定与非绑定、乘性幂律等候选，以 R² 与拟合参数数折中选定实现细节无关的普适形式
- Finding 1（PTQ 缩放律）：过训练模型对 PTQ 更敏感，δPTQ(N,D,Ppost)=CT·(D^γD/N^γN)·e^(−Ppost/γpost)；当 D/N 足够大或 Ppost 很低时，继续预训练反而使量化后损失上升
- Finding 2（量化训练缩放律）：权重量化(QAT)与低精度训练(权重+激活+KV)的影响建模为独立乘性噪声，Neff(Pw,Pa,Pkv)=N·∏(1−e^(−Pi/γi))；三精度绑定时 Neff(P)≈N(1−e^(−P/γ̄))³，即精度与参数量可互换地控制有效参数量
- Finding 3（预训练含义）：C∝NPD 下联合最优化得最优精度与总算力无关（≈7–8 bit）；若 N 先行固定（如训练同族模型），最优精度随 C 对数增长→重度 overtrain 的模型应提高训练精度
- Finding 4（统一律）：L(N,D,Pw,Pa,Pkv,Ppost)=A·Neff^-α+B·D^-β+E+δPTQ；δPTQ 含"鲁棒化效应"(训练噪声 σ²tr 抵消 PTQ 噪声)与"过训练效应"(D^γD/N^γN)两个竞争因子

## §5 实验要点
- 结论一：BF16 及以上训练的固定模型随 token 数增加，INT3–INT6 PTQ 退化单调扩大，最终"更多预训练数据主动有害"
- 结论二：权重、激活、KV cache 三者量化影响独立且乘性；KV/激活敏感性常数不同（附录含逐项扫描）
- 结论三：低精度训练大模型可以胜过高精度小模型（同等算力），Figure 1 右图给出 FP32→FP8 五点对照
- 统一形式在训练精度×PTQ 精度网格上预测退化，R² 对比多种候选函数形式（Table 1：加性幂律 vs 乘性等）
- 理论支撑：缩放律的噪声视角（文献中训练视为噪声注入、量化为均匀噪声）给出 Neff 指数 3（三组件）与 e^(−P/γ) 形式的机理依据；δPTQ 的鲁棒化×过训练两因子分解在式 (10) 中显式标注
- Chinchilla 关联：C=6ND 成本模型推广为随 P 线性缩放；最优 N*(P,C)、D*(P,C) 有闭式解（式 16），等价于 Chinchilla 优化中 A→A·u(P)、B→B·P^β 的替换
- 浮点 vs 整数（附录 D）：浮点点格非均匀、更贴合高斯权重分布，同精度下损失略低；本文为拟合简单统一采用整数型量化

## §6 局限
1. 全程单一架构（无 QAT 专用架构 tweak，而此类 tweak 可缩小与全精度的差距）；2. 算力按精度线性折算过于理想，实际系统开销使减半精度收益 <2x；3. 只看 loss，无下游评测；4. 拟合常数来自 ≤220M/26B 的整数型量化实验，外推到前沿规模的数值需谨慎（趋势比数值可靠）；5. 全程仅前向量化计入成本模型，backward 量化留待后续；6. 拟合用整数型量化，浮点（FP8 等）同精度损失略低，数值预测需按附录 D 折算。
