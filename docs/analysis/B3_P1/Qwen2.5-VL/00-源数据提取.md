## §4 方法细节
- **Window Attention ViT**：多数层用窗口注意力使视觉计算量随 patch 数线性增长，小区域不填充保原分辨率；从头训练（CLIP 预训练→VL 对齐→端到端微调）；RMSNorm + SwiGLU 对齐 LLM 设计。
- **Native Dynamic Resolution**：图像按原始宽高比动态转 token 序列；bounding box/point 直接用实际像素坐标（绝对坐标），不归一化，使模型内生学习尺度信息。
- **绝对时间 MRoPE**：继承 Qwen2-VL 的 (时间,高,宽) 三分量分解，将时间 ID 对齐绝对时间戳而非帧序号，通过 ID 间隔感知节奏，支持小时级视频与秒级事件定位、动态 FPS 采样；视频两帧一组降 token。
- **文档解析 QwenVL HTML 格式**：表格/图表/公式/乐谱/化学式统一为带 data-bbox 坐标的 HTML 标签结构；图表合成 100 万样本（matplotlib/seaborn/plotly），表格用 600 万真实样本经端到端识别模型过滤。
- **Agent 数据**：mobile/web/desktop 操作统一为共享动作空间的 function call 格式；对每步 ground-truth 操作由人+模型标注推理理由（截图前后对照），模型过滤低质量 reasoning，防过拟合。
- **训练效率**：为解决变长输入导致的 GPU 负载不均，按 LLM 输入序列长度动态 packing 样本，保证各卡算力均衡；阶段一/二打包至 8192，阶段三 32768。
- **Post-training**：SFT（ViT 冻结）+ DPO（仅图文+纯文本，每样本一次）；两阶段过滤管线——Stage1 用 Qwen2-VL-Instag（源自 Qwen2-VL-72B）分 8 大域 30 子类；Stage2 规则过滤（重复/截断/有害）+ reward model 多维打分；Rejection Sampling 保留答对样本并剔除 code-switching/过长/重复，规则+模型校验 CoT 中间步骤的视觉信息整合。

## §5 实验结果要点
- 72B 在 MMMU 70.2 追平 InternVL2.5-78B，MMMU-Pro 51.1 超 GPT-4o(51.9) 附近水平；MathVista 74.8 创开源新高（此前 72.3）。
- 文档/OCR 是最强项：CC-OCR 79.8、OmniDocBench edit 距离 0.226/0.324 双语新 SOTA；OCRBench 885 超 InternVL2.5 的 854。
- 纯文本不退化：MATH 83.0、LiveBench 57.0、IFEval 86.3，与 Qwen2.5-72B 同源水平（Table 4）。
- GUI Agent 是核心卖点：ScreenSpot Pro 43.6 远超 Aguvis-72B 23.6 与基座 Qwen2-VL-72B 的 1.6；AndroidWorld 35% 无需 SoM 辅助标记即超 GPT-4o(34.5% SoM)。
- 小模型可扩展性好：7B 在多榜单达到或超上代 72B 水平（如 MMStar 63.9 vs 上代 64.5 附近）。

- Grounding 全面领先：Refcoco val 92.7 / Refcoco+ val 88.9 / Refcocog val 89.9（Table 6），Point Grounding 67.5 为 Molmo(69.2) 之外唯一可比 LVLM；CountBench 93.6 用 "detect then count" 提示超 Molmo-72b 的 91.2。
- 视频理解：Video-MME(w/o sub) 73.3 与 GPT-4o(71.9) 相当；MVBench 70.4、TempCompass 74.8 均列前茅。
- 纯文本细节（Table 4）：MMLU-Pro 71.2 / MMLU-redux 85.9 / GPQA 49.0 / GSM8K 95.3 / HumanEval 87.8 / MultiPL-E 79.5，多模态训练未损伤语言能力。
- 数据管线要点：interleaved 图文数据经四维打分（文本质量/图文相关性/信息互补/信息密度平衡）；OCR 覆盖法德意西葡阿俄日韩越等多语种；grounding 数据含 10000+ 物类开集检测与 copy-paste 增强。

## §6 局限
- 论文自述：CoT 中间步骤对视觉信息的整合"仍是 ongoing challenge"，模态对齐未完全解决（§2.3.3）。
- 长程 agent 执行仍落后专用系统：OSWorld 8.83 明显低于 Claude 14.90（Table 9）；ScreenSpot 上略低于 Aguvis-72B。
- 无独立 Limitations 章节；预训练数据构成比例、RL/DPO 细节披露有限（DPO 仅一段描述）。
