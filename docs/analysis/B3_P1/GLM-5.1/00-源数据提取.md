## §4 方法要点
- 定位为 GLM-5 之后面向 agentic engineering 的旗舰迭代；官方文档称其提升非单点突破，而是通用智能、真实编程、复杂任务执行三维度同步增强。
- 核心机制主张：长程任务中形成"实验—分析—优化"自主闭环——主动跑 benchmark、识别瓶颈、调整策略、数百轮/数千次工具调用持续迭代；强调目标一致性、减少策略漂移与错误累积。
- 模型卡表述：此前模型（含 GLM-5）早期收益后即平台期，加时无益；GLM-5.1 经反复重审推理与修正策略实现"The longer it runs, the better the result"。
- 训练细节未在两来源披露（继承 GLM-5 报告体系）。

## §5 评测结果要点
- SWE-Bench Pro 58.4 为对比表中最高，超过 GPT-5.4 (57.7)、Claude Opus 4.6 (57.3)、Gemini 3.1 Pro (54.2)、Qwen3.6-Plus (56.6)、Minimax M2.7 (56.2)、DeepSeek-V3.2 (-)、Kimi K2.5 (53.8)；较 GLM-5 的 55.1 提升 +3.3。
- 相对 GLM-5 提升最大项：CyberGym (+20.4)、NL2Repo (+6.8)、Terminal-Bench 2.0 (+7.3)、BrowseComp (+6.0)。
- 数学类基本持平或略降（HMMT Feb 2026: 82.6 vs 82.8；HMMT Nov 2025: 94.0 vs 96.9），表明迭代重心在 Agent/工程而非数学。
- 第三方榜单（HF evalResults）：SkillsBench v1.1 58.4（rank 1）、LHTB solved 2/46（mean reward 26.7，rank 5）、WildClawBench 48.2、YC-Bench medium $1,510,772（rank 2）。
- 可用性：Z.ai API Platform（model id `glm-5.1`，thinking enabled，max_tokens 示例 65536）、chat.z.ai（模型卡称"coming days"上线）、本地部署支持 SGLang ≥v0.5.10 / vLLM ≥v0.19.0 / xLLM ≥v0.8.0 / Transformers ≥v0.5.3 / KTransformers ≥v0.5.3；HF 推理 provider：zai-org（live）、featherless-ai、deepinfra（output $3.5/M tokens）。官方价格页为 SPA 未抓到，官方 API 定价未获一手数字。
