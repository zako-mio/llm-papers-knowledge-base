## §4 方法细节
**Q-Former 架构（§3.1）**: 两个共享 self-attention 的 transformer 子模块——image transformer（经隔层插入的 cross-attention 与冻结 ViT 交互）+ text transformer（兼作编码/解码器）。查询向量作为模型参数，query 间自注意力交互、经 cross-attn 抽取视觉特征、经同一 self-attn 与文本交互。信息瓶颈设计强制 query 只保留文本相关的视觉信息。

**阶段一 表示学习（§3.2）**, 三目标联合优化（不同注意力掩码控制 query-text 交互）：
- **ITC**: 对齐图像/文本表示；因 Z 含多输出，取各 query 与 [CLS] 相似度最大值；unimodal 掩码防信息泄露；冻结编码器省显存 → in-batch negatives 替代 BLIP 的动量队列。
- **ITG**: 图像条件下生成文本，multimodal causal 掩码（类 UniLM）：query 互见不见 text，text token 可见全部 query 及前文；[CLS] 换 [DEC]。
- **ITM**: 二分类判断图文匹配，双向掩码全交互；每 query 输出接二分类线性层后取 logit 平均；硬负例挖掘沿用 BLIP。

**阶段二 生成学习（§3.3）**: FC 层把 Z 投影到 LLM 文本嵌入维度，作为 soft visual prompt 前置拼接。decoder 型 LLM（OPT）用 LM loss；encoder-decoder 型（FlanT5）用 prefix LM loss（prefix 文本拼视觉表征入 encoder，suffix 为 decoder 目标）。瓶颈减轻 LLM 对齐负担、缓解遗忘。

**预训练配置（§3.4）**: 视觉骨干 CLIP ViT-L/14 或 EVA-CLIP ViT-g/14（去掉最后层取倒数第二层特征）；LLM 用 OPT 系列（无监督）/ FlanT5 系列（指令微调）；AdamW β=(0.9,0.98) wd=0.05，峰值 lr 1e-4 余弦衰减 + 2k warmup；224×224 输入。

## §5 实验结果要点
- **零样本 VQA（Table 2）**: BLIP-2 ViT-g FlanT5XXL 达 VQAv2 65.0 / OK-VQA 45.9 / GQA 44.7；FlanT5（指令微调型）全面优于同规模 OPT；OK-VQA 落后 Flamingo80B（56.3），作者归因于其 70B Chinchilla 世界知识更多。
- **指令零样本图文生成（Figure 4）**: 视觉对话、视觉知识推理、常识推理、storytelling、个性化描述等涌现能力；prompt 直接跟在视觉 prompt 后即可控生成。
- **图像描述（Table 3）**: NoCaps zero-shot 全面 SOTA（overall CIDEr 121.6），out-domain 泛化显著；仅微调 Q-Former+ViT，LLM 保持冻结。
- **VQA 微调（Table 4）**: 开放式生成类中 VQAv2 test-std 82.30（OPT6.7B），超 Flamingo80B 的 82.10；仍低于封闭式分类 SOTA BEIT-3（84.03）。
- **图文检索（Table 5）**: COCO 微调零样本迁移 Flickr30K，ViT-g 版 I→T R@1 97.6 / T→I R@1 89.7 双向 SOTA；推理先取 k=128 候选再 ITM 重排。
- **消融**: 表示学习阶段不可或缺（Figure 5）；ITG 对检索亦有增益（Table 6）。

## §6 局限
1. **无 in-context learning 能力**: 提供 few-shot VQA 示例不提升性能；预训练数据每样本仅单一图-文对，LLM 学不到跨样本关联；Flamingo 用交错多图文的 M3W 数据集才有此能力（作者计划构造类似数据）（§5）。
2. **生成失败模式**: LLM 知识不准、错误推理路径激活、信息过时（如 iPhone 11→14）三类错误案例（Figure 6/7）。
3. **继承冻结 LLM 风险**: 可能输出冒犯性语言、传播社会偏见、泄露隐私；缓解靠指令约束或过滤有害数据（§5）。
4. OK-VQA 这类重开放世界知识的任务受限于所接 LLM 的知识容量（§4.1）。
