## §3 核心主张与关键数字（含表注出处）

**核心主张**：长上下文扩展微调可以"训练时稀疏、推理时稠密"——用 S²-Attn 近似全注意力完成高效微调，推理阶段恢复原始标准注意力架构，从而兼容 Flash-Attention2 等既有基础设施；同时发现 **LoRA 必须放开 embedding 与 normalization 层训练**才能支撑长上下文扩展（论文摘要、§1 p1–2）。

## §4 方法细节

### 4.1 S²-Attn（Shifted Sparse Attention）（§3.2, p5；Figure 2/3, p2–3）
三步实现：
1. **Split**：沿 head 维度把特征切成两半（half heads 各自采用不同 pattern）；
2. **Shift**：其中一半的 token 沿序列方向 roll 半个 group 大小（G/2），保证相邻组间信息流动；
3. **Group**：按组切分 token 并把组维 reshape 进 batch 维，各组内独立做标准自注意力。

- 例：总长 8192、group=2048 → pattern 1 按 [1–2048][2049–4096]… 分组；pattern 2 偏移 1024 → [1025–3072]…（首尾 1024 token 同组）。两组分别用于一半注意力头。
- **实现仅两行 PyTorch 代码**（chunk + roll，Algorithm 1, p5）；shift 可能引入信息泄漏，可用 attention mask 小改动防止（§B.3 variant 2/3 验证无碍）。
- **关键性质**：训练后推理仍用标准全注意力——短程注意力形态与预训练一致，故兼容 FA2；而 dilated/sparse 等方案测试时必须沿用训练时的稀疏模式且效果差（Table 6, p9）。
- Group size 消融（Table 7, p13）：取目标长度 {1/2,1/4,1/6,1/8}，1/2 与 1/4 几乎无损，<1/4 开始劣化；默认取 **1/4**。
- 变体消融（Table 8, p14）：换 shift 方向 / 泄漏 token 单独成组 / 交换首尾 token，PPL 均与原版相当（≈8.04）。

### 4.2 LoRA+（Improved LoRA）（§3.3, p5–6；Table 2, p6）
- 发现：仅训注意力线性层（Wq/Wk/Wv/Wo）的普通 LoRA 在长上下文上与全参微调差距大，且提高 rank（→256）无效；
- 解法：**放开 embedding 层（Llama2 7B 中 <2% 参数）与 normalization 层（≤0.004% 参数）**参与训练，即 LoRA+，PPL 8.12 接近全参 8.08。

### 4.3 训练配置（§4.1, p6–7；§A.1, p13）
- 底座：Llama2 7B/13B/70B；位置编码重缩放采用 **Position Interpolation（PI）**（与本文正交、可叠加）。
- 数据：RedPajama；next-token prediction 目标。
- 优化：AdamW（β₁=0.9, β₂=0.95）；lr 2e-5（7B/13B）、1e-5（70B），linear warmup，weight decay=0；per-device batch=1 × grad-accum 8 × 8 GPU = 全局 64；1000 steps。
- 环境：PyTorch + DeepSpeed（常规 stage 2，极限长度 stage 3）+ Flash-Attention2；gradient checkpoint 默认开启；7B→8192 甚至可用 3090 Ti 完成。
- SFT：自建 **LongAlpaca** 长指令数据集（技术论文/科幻/书籍等多类长问答），配合 LongLoRA 做监督微调（§B.6, p18）。

## §5 实验结果要点

- **语言建模（Table 3/4, p6–7）**：同训练长度下评测越长 PPL 越好；7B 从 8192→32768 训练使 32k 评测 PPL 由 2.72→2.50（−0.22），13B −0.28；极限设定（100k/64k/32k）依旧有效，但短上下文侧出现轻微 PPL 退化（继承自 PI 的已知问题）。
- **检索能力（Table 5, p7–8；Figure 4, p8）**：topic retrieval 追平 SOTA LongChat-13B 且 16k 段反超；passkey 检索在训练长度内几乎无损，外推段靠扩 PI 上限获得中等准确率。
- **收敛行为（Figure 5, p8）**：初始 PPL 15.82；全参微调前期收敛更快，200 步后两者接近，终局差距很小。
- **注意力模式对比（Table 6, p9）**：S²-Attn 用全注意力测试 PPL 8.12 最优；cross-layer shift 尚可；only-P1/only-P2（无通信）严重劣化；dilated/block-sparse/stride-sparse 等为从头训练设计的模式在预训练模型微调场景全部明显落后。
- **效率（Fig.1, p1；Table 12/13, p18）**：LongLoRA 全面优于普通 LoRA（速度）与全参微调（显存/时长）；FA2 缺席时 S²-Attn 加速收益反而更大（2.1×）。
- **下游基准（§B.4, p14）**：LongBench、LEval 上与 GPT-3.5-Turbo 及 Llama2 系长上下文模型可比或更优，训练开销极小（4h/0.3B tokens）。

## §6 局限

1. **短上下文性能回退**：扩展后的模型在小上下文处有轻微 PPL 劣化，作者归因于 Position Interpolation 的已知缺陷（§4.2, p7）——方法本身依赖 PI 类位置重缩放。
2. **移位信息泄漏隐患**：S²-Attn 的 shift 会把文档尾部 token 移入开头组、破坏因果性直觉；虽以 mask 变体（variant 2/3）实验证明影响可忽略，但属于训练期近似，理论上非严格因果（§3.2 p5；§B.3 p14）。
3. **验证范围有限**：实验集中于 Llama2 家族 + RoPE/PI 组合；对其他架构与其他位置编码的泛化性留作 future work（§5 结论, p9）。
4. **评估以困惑度为主**：除 topic retrieval/passkey/LongBench/LEval 外缺少大规模真实长文任务证据；LongAlpaca 数据规模较小，SFT 部分仅在附录给出。
