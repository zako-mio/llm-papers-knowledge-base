## §3 核心主张与关键数字（含表注出处）

**核心主张**：VLLM 的瓶颈不在 LLM 端而在视觉端——现有视觉编码器仅 ~1B 参数且与 LLM 表示不对齐。InternVL 首次把视觉编码器放大到 **6B** 并用 **8B 语言中间件 QLLaMA** 对齐 LLM 特征空间，以"渐进式图文对齐"（噪声数据对比学习 → 高质量数据生成学习 → 指令微调）实现感知/VL 任务/多模态对话全线 SOTA（§1 p1–3）。

## §4 方法细节

### 4.1 总体架构（§3.1, p3；Figure 3, p4）
- **InternViT-6B**：vanilla ViT 放大到 ~5.9B 参数（width 3200 / depth 48 / MLP 12800 / 25 heads），作为可独立使用的视觉骨干；
- **QLLaMA**：8B 语言中间件 = 多语言增强 LLaMA-7B 权重初始化 + 新增 96 个可学 query 与 cross-attention 层（~1B，随机初始化）；既为对比学习提供强文本表示，又作视觉编码器 ↔ LLM decoder 的桥；
- 与 QFormer/Linear 等"轻胶水"路线的区别：胶水层本身具备语言能力且容量大，特征空间天然贴近 LLM。

### 4.2 InternViT-6B 超参选择（§3.2, p4；Table 11, p9）
- 在 LAION-en 100M 子集上用对比学习测 16 种配置（depth {32,48,64,80} × head dim {64,128} × MLP ratio {4,8}）；发现计算饱和后深度对速度影响小、同参数量下各因子对精度影响小 → 选吞吐/稳定最优 variant 3（3200/48/12800/25 头，28.0 GFLOPs@224）。

### 4.3 渐进对齐三阶段（§3.3, p5–6；§4.1, p6）
- **Stage 1 对比预训练**：InternViT-6B 随机初始化，文本端用多语言 LLaMA-7B（全参数可训）；CLIP 式对称交叉熵损失；数据 6.03B→清洗后 4.98B 图文对（LAION-en/multi、LAION-COCO、COYO、Wukong、CC12M、CC3M、SBU）。
- **Stage 2 生成预训练**：InternViT-6B 与 QLLaMA（继承 Stage 1 权重）**双冻结**，只训新增 query+cross-attn；BLIP-2 式损失 ITC+ITM+ITG；数据过滤到 1.03B 高质量对。产出 InternVL-C（仅视觉端 attention pooling）与 InternVL-G（QLLaMA query 编码视觉）两种推理模式。
- **Stage 3 SFT**：InternViT-6B(±QLLaMA) 经 MLP 接 Vicuna-7B/13B 或 InternLM；指令数据约 4M 条（Caption 588K / VQA 1.1M / OCR 294K / Grounding 323K / Grounded Cap 284K / Conversation 1.4M）；因特征空间已对齐，可只训 MLP 或 MLP+QLLaMA、冻结 LLM，既加速又保住 LLM 原有语言能力。

### 4.4 "瑞士军刀"式用法（§3.2, p5；Figure 4）
(a) InternVL-C：纯 CLIP 式对比；(b) InternVL-G：视觉走 QLLaMA query 编码后再对比；(c) InternViT-6B 直接 + MLP 接 LLM；(d) 完整 InternVL + MLP 接 LLM。

## §5 实验结果要点

- **视觉感知（Table 4/5, p6）**：线性探测 ImageNet 系列 88.2/90.4/79.9/77.5/89.8/69.1（1K/V2/A/R/Sketch/ReaL 相关项），开放域泛化突出；ADE20K 三种协议（linear/head/full）全部领先同级或更大模型。
- **零样本 VL（Table 6–8, p7）**：分类鲁棒性（Δ=0.8）、5 语种分类、中英检索、K400/600/700 视频分类（甚至只用单帧即超对手 8 帧/专门视频训练的 ViCLIP）全面 SOTA；InternVL-G 相对 InternVL-C 的检索增益验证 QLLaMA 二次编码的价值。
- **对话系统（Table 9, p8）**：与 BLIP-2/InstructBLIP（同为 224px 冻结 LLM 设定）比，InternVL-Chat-13B 几乎全指标翻倍级领先（GQA 59.5 vs 33.4；VizWiz 54.0 vs 26.0）；与同期最强 LLaVA-1.5-13B 比，MME 1586.4 > 1531.3、POPE 87.6 > 85.9、NoCaps 126.2 一枝独秀（LLaVA-1.5 未报 NoCaps，其 caption 弱项由 QLLaMA 零样本生成能力补足）。
- **消融（Table 12, p9）**：极简设定（仅 LLaVA-Mix-665K、只训 MLP）下 InternViT-6B 全面优于 EVA-E（MME 1022.3 vs 970.5）→ 特征更贴 LLM；换 QLLaMA 当胶水层后 MME 跳升至 1227.5，再换自家指令数据达 1298.5——三因素（视觉底座/胶水/数据）逐级贡献清晰。

## §6 局限

1. **训练成本极高**：6B 视觉编码器 + 数十亿级图文对的对比预训练只有大型机构可复现；论文未给出总 GPU 时数，开源的是模型而非完整可负担的训练路径。
2. **输入分辨率仍低**：主对话结果基于 224/336px 单图，无动态高分辨率机制（后续 InternVL 1.5/2.0 才引入），细粒度 OCR 类任务（TextVQA 61.5 落后 Qwen-VL 的 63.8）受限。
3. **评测透明度瑕疵**：Table 9 中带 ∗ 的基准（COCO caption、VQAv2、GQA 等）训练标注在训练中被观察到，非严格 zero-shot；与 LLaVA-1.5 对比时双方均存在该问题但口径不完全一致。
4. **对话能力依赖冻结 LLM**：主打冻结 decoder 以保留语言能力，意味着对话上限受 Vicuna/InternLM 版本制约，未探索 VL 联合微调的上限。
5. **生成侧未覆盖**：聚焦理解类任务，不含图像生成/编辑；文生图等方向留白（结论 §5, p9 仅展望 VLLM 社区发展）。
