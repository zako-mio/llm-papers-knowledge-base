## 摘要

Power 等人在小型算法数据集（模素数 97 的二元运算等式表与 S₅ 置换群运算）上系统记录了「grokking」现象：小规模 Transformer 先在训练集上迅速达到近乎完美的准确率并长期维持过拟合状态，之后验证准确率才从随机水平突跃至完美泛化。标志性实验中，训练准确率在不足 10³ 优化步内接近完美，而验证准确率需近 10⁶ 步才达到同等水平——泛化比记忆晚约 1000 倍优化步数。论文沿三条主线展开：其一，在 25–30% 数据占比区间内每减少 1 个百分点训练数据，达到泛化的中位时间增加 40–50%，给出「算力换数据」的定量刻画；其二，消融显示 weight decay 是最有效的干预，可将所需样本量削减一半以上，且学习率必须落在一个数量级宽度的窄窗口内才会发生泛化；其三，t-SNE 嵌入可视化表明 grok 后的网络内部形成了映射底层数学对象的表示（模加法的圆拓扑、S₅ 子群陪集）。作者推测 SGD 噪声驱动网络进入更平坦区域是可能机制，sharpness 与验证准确率的强负相关（Spearman −0.79548，p<0.000014）提供初步支持，但因果机制仍未解决。

## 一、问题定位

### 1.1 一个反直觉的现象学谜题

深度学习的教科书式图景是：模型先拟合训练分布，验证性能随之缓慢爬升，若容量过大则出现过拟合、验证曲线回落。在这一图景里，「记忆」与「泛化」被默认为同一学习过程的两个侧面，时间上大体同步。Grokking 论文的出发点正是打破这一默认：作者观察到，验证准确率可以从随机水平**突跃**至完美泛化，而且这一突跃可以发生在模型已经严重过拟合之后很久（Abstract, §1, Fig.1 p.1）。

标志性实验的量化轮廓极为清晰：在模 97 除法任务、50% 训练数据、无 weight decay、优化预算增至 10⁶ 步的设置下（Appendix A.1.2 p.7），训练准确率在 10³ 步之内就接近完美；验证准确率在 10⁵ 步之前几乎没有泛化迹象，直到接近 10⁶ 步才攀升到同等水平（Fig.1 caption p.1, §3.1 p.2）。两个里程碑之间相差约 **1000 倍优化步数**——在这段漫长的中间地带，模型是一个「训练集满分、验证集瞎猜」的纯记忆机器，而泛化的种子已在暗中生长，只是没有任何外部可见信号。

### 1.2 为什么选择小型算法数据集

论文副标题中的 "Small Algorithmic Datasets" 不是权宜之计，而是方法论上的刻意选择。数据由二元运算表 a∘b=c 的等式构成，每个元素以**无内部结构的离散符号**呈现——网络看不到十进制数字，也看不到置换的线记法，只能从符号之间的交互中归纳其运算性质，作者将这一处境类比为「填数独」（§2 p.2 + Appendix A.1.1 p.6）。这种构造带来三个独特优势：

1. **真值结构已知**：每个任务的底层代数结构（群、环、原根表示）是数学上完全清楚的，因此网络学到什么可以直接对照检验，不存在自然语言数据集中「真值不可知」的解释困境。
2. **现象学高通量**：非嵌入参数仅约 4×10⁵ 的极小模型即可复现现象，单 GPU 可跑（Appendix A.1.2 p.6），使得跨运算类型 × 数据规模 × 干预手段的大规模扫描成为可能。
3. **泛化判据无歧义**：损失与准确率只在答案 token 上计算（Appendix A.1.1 p.6），「验证准确率 100%」是一个干净利落的成功判据，不像开放生成任务那样需要模糊评分。

（推断）这一选择同时构成了论文最大的力量与最大的软肋：力量在于内部效度极高，软肋在于外部效度存疑——第五章将回到这一点。

### 1.3 与既有泛化理论的张力

论文在附录 A.3（p.7–9）专门辨析了 grokking 与 double descent 的关系。作者观察到验证 loss 存在第二次下降——从 10² 步开始上升，持续到约 10⁵ 步后才转入第二次下降（Fig.4 caption, §3.1 p.2）——表面上与 Belkin/Nakkiran 的经典 double descent 叙事相似。但作者强调两处本质差异：本文的第二次下降发生在训练 loss 首次变小**之后很远**（有时相隔数万个 epoch）；且准确率全程**没有非单调行为**。据此作者主张 grokking 不同于经典 double descent 设定（A.3）。

（推断）这一定位使 grokking 成为「记忆与泛化解耦」问题的极端标本：它把两个通常纠缠在一起的过程在时间轴上拉开到三个数量级，从而让研究者第一次有可能分别观测它们各自的动力学。

### 1.4 论文试图回答的四个问题

依章节树（§2–§3, p.2–4）可归纳为：

1. **是否普遍？**——grokking 跨越哪些模型、优化器与数据规模出现？（§3.1）
2. **何时发生？**——数据规模与达到泛化所需优化时间是什么定量关系？（§3.1.1）
3. **什么因素促成或阻碍？**——各类正则化与优化器干预的效果排序？（§3.3）
4. **网络到底学到了什么？**——grok 前后的内部表示呈现何种结构？（§3.4）

## 二、概念内核

### 2.1 Grokking 的现象学定义

综合 Abstract 与 Fig.1，grokking 可定义为包含三个阶段的学习动力学：

1. **快速记忆期**：训练准确率迅速逼近完美（<10³ 步），验证准确率停留在随机水平；
2. **潜伏平台期**：训练指标饱和，验证指标长期无起色，外部看是彻底的死过拟合；
3. **延迟突跃期**：验证准确率在某个时刻突然跃升直至完美泛化，且该时刻可比记忆晚约 1000 倍优化步数。

（推断）这个定义的关键在于「突跃」与「延迟」缺一不可：仅有延迟而缓慢单调爬升，那只是普通的慢收敛；仅有突跃而不延迟，那只是正常的泛化。grokking 的震撼之处在于两者同时出现。

### 2.2 记忆与泛化的解耦

源数据中最具理论分量的一条证据是：**训练准确率达到 99% 所需的步数，随训练数据减少反而下降，并稳定在 10³–10⁴ 步区间**（§3.1.1 p.3）。换言之，「学会把训练集背下来」这件事不仅与「学会泛化」无关，甚至方向相反——数据越少记忆越快，而泛化却越来越慢。这说明两者是由不同的动力学驱动的两个独立过程，而非同一过程的不同侧面。

容量过剩提供了另一佐证：向训练集注入 k∈{0,10,100,1000,2000,3000} 个标签噪声 outlier，≤1000 时对泛化影响不大，且**所有**实验最终都达到 100% 训练准确率（A.4, Fig.6 p.9）。网络连标签噪声都能全数吞下，说明其容量远超单纯记忆所需——「容量不足以泛化只好记忆」这类解释在此不成立，泛化本身需要一个非平凡的解释。

### 2.3 算力换数据：核心定量规律

论文最具工程价值的发现在 §3.1.1（p.3）：在一段数据规模区间内，**收敛性能恒定保持 100%，但达到泛化所需的优化时间随数据减少呈快速指数增长**。具体地，在 S₅ 群乘法任务上、以 99% 验证准确率为达标指标、7 seeds 聚合的测量下，当训练数据占比处于 25–30% 区间时，**每减少 1 个百分点的数据，达到泛化的中位时间增加 40–50%**（§3.1.1, Fig.1 center）。

（推断）这条规律的深层含义是一种「兑换率」的存在：数据与计算在某个边界区间内可以互相替代，且兑换率约为「1 个百分点数据 ≈ 半个数量级时间」。它预示了后来 scaling law 研究中「算力最优的数据量」这类议题——当数据稀缺时，继续训练不是浪费，而是购买本可用数据买到的泛化。

### 2.4 结构决定可学习性：运算难度的代数根源

并非所有运算都平等。§3.2（p.3）的难度排序揭示了泛化能力与任务代数结构的深刻联系：

- **对称优于非对称**：对称运算（x+y, x*y, x²+y², x²+xy+y²）比对对应的非对称版本（x−y, x/y, x²+xy+y²+x）需要更少数据即可泛化。作者认为部分源于架构特性——Transformer 易于通过忽略位置嵌人来表达对称函数。
- **代数等价性得到数值验证**：素数域上存在原根表示使得 x+y (mod p−1) ≡ x*y (mod p)，实验测得 x−y 与 x/y 所需数据量确实相近——任务在数学上「同构」，网络的学习难度也同步。
- **无结构则不泛化**：x³+xy²+y (mod 97) 在任何 ≤95% 的数据占比下都不泛化，网络只会记忆——对该网络而言这个多项式等效于一张随机查找表（推断：缺乏可供发现的低复杂度代数结构）。
- **不需要干净群结构的泛化也存在**：混合运算 [x/y if y odd else x−y] 表明，即使运算无法用群/环结构干净解释，泛化仍可能发生——结构是助力而非必要前提。

### 2.5 平坦区域假说：机制的候选答案

对「为什么泛化会延迟到来」，论文给出的中心猜想是：**SGD 噪声在漫长训练中将权重驱动到更平坦、更简单的极小值区域，而泛化只发生在进入平坦区域之后**。支撑证据有三条相互独立的线：

1. sharpness 度量（按 Keskar et al. 方法计算 φ）与验证准确率呈强负相关：Spearman 相关系数 −0.79548（p<0.000014），测于 S₅ composition 任务、多个 seed 训练至约一半 grok 的样本上（A.5 p.10）；
2. minibatch 梯度噪声与权重高斯噪声（σ=0.01）作为干预均有益，与「噪声帮助找到更平坦极小值」的假说一致（§3.3 p.4）；
3. weight decay 显著有效（详见第四章），而其作用机制恰是持续压缩权重的范数足迹。

（推断）值得注意的是，这三条证据都是相关性或间接干预证据，论文自己也将 sharpness 分析标注为 preliminary investigation——平坦区域假说是全文最有生命力也最少被证明的部分。

## 三、方法拆解

### 3.1 任务构造：把代数变成 token 序列

**数据形式**（§2 p.2 + Appendix A.1.1 p.6）：每个样本是一条二元运算等式 a∘b=c，序列化为五个独立 token：`⟨x⟩⟨op⟩⟨y⟩⟨=⟩⟨x∘y⟩`。输入前四个 token，预测第五个；损失与准确率只在答案 token 上计算。元素以无内部结构的离散符号编码，切断一切「数字表面线索」。

**运算清单**（mod p=97 素数）：

| 类别 | 运算 |
|------|------|
| 基础四则 | x+y、x−y、x/y（0<y<p）、混合运算 [x/y if y odd else x−y] |
| 二次多项式 | x²+y²、x²+xy+y²、x²+xy+y²+x |
| 三次多项式 | x³+xy、x³+xy²+y |
| S₅ 置换群 | x·y、x·y·x⁻¹、x·y·x |

**数据划分**：对每个运算随机选取一定比例的例子作训练集，其余作验证集；数据占比是贯穿全文的核心自变量。

### 3.2 模型与训练配置

**模型**（A.1.2 p.6）：标准 decoder-only Transformer（Vaswani et al. 2017）加 causal masking，共 2 层、width 128、4 个注意力头，非嵌入参数约 4×10⁵——单张 GPU 即可完整复现全部现象。

**默认优化配置**（A.1.2 p.6）：

| 项 | 值 |
|----|----|
| 优化器 | AdamW |
| 学习率 | 10⁻³ |
| weight decay | 1 |
| β₁ / β₂ | 0.9 / 0.98 |
| Warmup | 线性 10 updates |
| Batch size | min(512, 数据集一半) |
| 步数预算 | 10⁵ gradient updates |

超参数在模加法与 S₅ 乘法两个任务上调定，按性能/简洁性平衡选取（例如未采用在某些情形更优的 lr 退火）。注意 §3.1 的 Fig.1 展示实验特意将预算扩至 10⁶ 步并移除 weight decay，以凸显「泛化可以多晚才开始」这一主题（A.1.2 p.7）。

### 3.3 分析工具箱

1. **数据效率曲线**：固定优化步数预算，扫描训练集占比，定位「预算内能泛化的最小数据规模」；
2. **学习时间曲线**：以 99% 验证准确率为达标线，7 seeds 聚合统计中位达标时间随数据占比的变化（§3.1.1）；
3. **t-SNE 嵌入可视化**（§3.4, Fig.3）：对输出层行向量做投影，直接「看见」网络内部的数学结构；
4. **sharpness 近似 φ**（A.5 p.10）：训练多个 seed 至约一半 grok 的时刻采样，计算 sharpness 与验证准确率的秩相关。

### 3.4 消融矩阵设计（§3.3）

消融变体覆盖了正则化来源的三个不同层面：

| 层面 | 变体 |
|------|------|
| 显式权重惩罚 | AdamW (wd=1)；朝初始化而非原点的 weight decay |
| 优化器噪声 | full-batch Adam（消除 minibatch 噪声）；full-batch + 高斯噪声更新方向 |
| 隐式扰动 | residual dropout 0.1；权重高斯噪声 σ=0.01 |
| 优化超参 | 不同学习率（lr=3e-4 与 3e-3 等变体） |

（推断）这个设计的巧妙之处在于把「正则化」从一个笼统概念拆成可分离的机制假设：若只有显式惩罚有效则支持「权重范数」解释；若噪声类干预同样有效则支持「平坦极小值」解释。实验结果（见下章）恰好落在后者。

## 四、证据链

### 4.1 主现象：一条迟到三个数量级的泛化曲线（Fig.1, §3.1）

模 97 除法任务、50% 训练数据、无 weight decay、预算 10⁶ 步的设置下：训练准确率在 10³ 步内接近完美；验证 loss 从 10² 步起持续恶化，形成典型的过拟合形态，直到约 10⁵ 步才开始第二次下降（double descent 形态）；验证准确率在 10⁵ 步前几乎毫无泛化迹象，随后在接近 10⁶ 步处完成从随机到 100% 的突跃（Fig.1 caption p.1, §3.1 p.2, Fig.4 caption）。这条曲线同时确立了三件事：grokking 真实存在、时间差可达 1000 倍、验证 loss 与验证准确率的转折点并不重合。

### 4.2 普遍性验证（§3.1）

改进后的泛化现象**跨越一系列模型、优化器与数据规模**出现，并非某一特殊配置的伪影。其显著程度呈系统性分布：在接近「预算内能泛化的最小数据规模」时最为显著；而当数据量较大时，train/val 曲线趋于同步——grokking 是数据稀缺边界区间的产物（§3.1）。（推断）这意味着 grokking 在数据充裕的常见设置下不可见，恰恰解释了它为何迟至 2022 年才被系统记录：社区的标准实验配置大多落在「同步泛化」区间。

### 4.3 定量规律：数据-时间的指数交换（§3.1.1）

S₅ 群乘法任务上，以 99% 验证准确率为指标、7 seeds 聚合：

- 收敛性能在一个数据规模区间内**恒定保持 100%**——只要肯花时间，少到 25–30% 的数据也能完全泛化；
- 但达标的中位优化时间随数据减少**快速指数增长**：区间内每减少 1 个百分点数据，中位时间增加 40–50%；
- 与此同时，训练准确率达到 99% 所需步数随数据减少**反而下降**、稳定于 10³–10⁴ 步——记忆越来越容易，泛化越来越慢，两条曲线背道而驰。

（推断）这组曲线是全文的理论支点：它把 grokking 从「猎奇现象」提升为「数据与算力的兑换定律」，也为后续工作定义了明确的量化靶子。

### 4.4 结构证据：网络真的学会了数学（§3.4, Fig.3）

t-SNE 对输出层行向量的投影显示，grok 之后的网络嵌入呈现出底层数学对象的可识别结构：

- **模加法网络**：嵌入构成**圆拓扑**——一根「number line」，按 mod 8 余数着色后颜色沿圆周有序排列，直观呈现了模运算的循环群结构；
- **S₅ 置换群网络**：嵌入呈**置换聚类**，每一簇恰是子群 ⟨(0,3)(1,4),(1,2)(3,4)⟩ 或其共轭的一个 coset——网络自发发现了 120 阶对称群的一个 4 阶子群的陪集分割；
- **正则化的痕迹留在表示里**：weight decay 优化的网络，其嵌入的数学结构更加清晰。

（推断）这组可视化把「泛化发生了」从黑箱指标升级为白箱证据：验证准确率 100% 与「内部表示同构于群论对象」互为印证，排除了「碰巧答对」的解释空间。

### 4.5 干预证据：什么促成、什么破坏 grokking（§3.3）

各干预的效应排序清晰：

1. **weight decay 效果最强**：相比多数其他干预，AdamW (wd=1) 将达到泛化所需的样本量削减**一半以上**；
2. **朝初始化的 weight decay 也有效**，但略逊于朝原点衰减——「零权重先验」能解释部分而非全部收益；
3. **minibatch 梯度噪声有益**：full-batch Adam 单独使用效果不佳，而在 full-batch 上人为加回高斯噪声更新方向则恢复益处——指向噪声本身（而非批大小相关的其他因素）是有效成分；
4. **权重高斯噪声（σ=0.01）与 residual dropout 0.1 同样有益**；
5. **学习率必须落在窄窗口内**：只有在一个数量级宽度以内的 lr 窗口中泛化才会发生（lr=3e-4 与 3e-3 的对比实验）。

（推断）第 1、2 条合并阅读的含义微妙：如果 weight decay 的全部收益来自「把权重推向零」，那么朝初始化衰减应当无效或反向；它有效的事实说明「持续施加一个收缩性的约束、维持权重的小足迹」才是关键，目标点是次要的。这与「小权重偏好更简单函数」的奥卡姆式解释兼容，也与平坦区域假说不冲突。

### 4.6 相关性证据：sharpness 与泛化同步（A.5）

在 S₅ composition 任务上，将多个 seed 训练至约一半已完成 grok 的时刻，计算每个网络的 sharpness（Keskar et al. 方法近似 φ）与验证准确率的关系：Spearman 相关系数 **−0.79548**（p<0.000014）——越平坦的网络泛化越好，横截面证据与「先进入平坦区、后发生泛化」的时序假说一致。

### 4.7 鲁棒性证据：噪声标签下的镇定（A.4）

k∈{0,10,100,1000,2000,3000} 的标签噪声实验（Fig.6 p.9）：≤1000 个 outlier 对泛化影响不大，大量 outlier 才显著阻碍；同时所有设置最终都达到 100% 训练准确率。（推断）这组实验一举排除两类廉价解释——「网络其实没记住所以能泛化」与「网络记满了所以不能泛化」，把解释空间收窄到优化动力学的内在性质上。

### 4.8 证据链强度总评（推断）

| 证据 | 类型 | 强度 |
|------|------|------|
| Fig.1 主现象、学习时间曲线 | 直接现象学记录 | 强，可单 GPU 复现 |
| 数据-时间兑换率（+40–50%/百分点） | 定量规律 | 较强，但限于算法任务 |
| weight decay / 噪声 / lr 窗口消融 | 干预实验 | 较强 |
| t-SNE 结构对齐 | 表示层白箱证据 | 直观有力，但为个案展示 |
| sharpness 负相关 | 横截面相关性 | 初步（单一任务、作者自称 preliminary） |
| 平坦区域机制假说 | 猜想 | 未证明 |

## 五、批判性分析

### 5.1 机制解释止步于猜想

论文最大的诚实与最大的遗憾在同一处：它记录并刻画了现象，但**没有解决机制**。作者明确承认所给出的是猜想（SGD 噪声驱动至更平坦/更简单的解），sharpness 相关性只是初步证据——单一任务、preliminary investigation 的自我定位（§6 源数据局限条目 1）。从 −0.79548 的强相关到「平坦导致泛化」的因果结论之间，还缺少时序干预类的关键证据：例如「强制压平权重能否提前诱发泛化」这类实验在本文中并未出现。（推断）后续领域的发展方向（机制可解释性路线）某种程度上正是补上了这块缺口，但这属于本文之外的叙事。

### 5.2 外部效度的天花板

全部结论建立在小型算法生成的二元运算表之上，作者自己在 Discussion（§4 p.4–5）提出必须检验其他数据集是否呈现同样的「数据↓→优化时间指数↑」效应（源数据局限条目 2）。（推断）从算法表到自然图像/文本之间隔着重叠采样、特征层级、标签歧义等多重新变量，grokking 式的延迟突跃在真实数据管线中是否以可辨识的形式存在，本文没有提供任何直接证据。读者应把本文结论的适用域严格限定在其任务族内，外推须自行承担风险。

### 5.3 边界条件不明：不 grok 的运算

x³+xy²+y 在所有 ≤95% 数据占比下都不泛化，但论文未能给出判定「哪些运算会 grok」的一般准则——只知道有结构者易、无结构者难、混合结构亦可，边界条件不明（源数据局限条目 3）。（推断）这使得「运算难度排序」目前只是一份经验目录，尚不是一套可预测的理论。

### 5.4 复现的超参敏感性与统计功效

泛化仅在约一个数量级宽度的学习率窗口内发生（§3.3 p.4；源数据局限条目 4），窗口外的配置要么永不泛化要么训练发散，实际复现对调参相当敏感。此外，多数实验仅重复 3 seeds，仅 §3.1.1 用了 7 seeds 聚合（A.1.2 p.7）。（推断）对于「中位达标时间增加 40–50%」这类以种子间方差为分子的统计量，3–7 个种子的功效偏紧，尽管趋势方向的信噪比较高、结论大方向可信，但精确系数不宜过度解读。

### 5.5 架构依赖的暗流

对称运算的数据优势被作者怀疑部分来自 Transformer 特有的归纳偏置——位置嵌入可以被轻易忽略从而表达对称函数（§3.2 p.3；源数据局限条目 5）。（推断）这提醒我们：本文的「难度排序」是任务结构 × 架构偏置的联合产物，换成 RNN 或 CNN 重跑，排序可能改变。「grokking 本身」大概率是架构无关的（毕竟跨模型出现），但其细节纹理不是。

### 5.6 与 double descent 的切割是否彻底

作者以两点理由与经典 double descent 划界：时间间隔悬殊（有时数万 epoch）、准确率无非单调行为（A.3）。（推断）这两点是现象学层面的差异，尚未上升到机制层面的统一定义；两种现象是否共享「隐式正则化驱动模型复杂度单调上升」的底层引擎，论文没有也无法回答。划界的修辞意义大于理论意义。

### 5.7 指标选择的潜在偏差

以「99% 验证准确率」为达标指标刻画泛化时间，在突跃型曲线上对种子方差高度敏感：达标时刻近似由突跃起点决定，个别早熟的 seed 即可大幅移动中位数。（推断）配合上一条的种子数量问题，40–50%/百分点 这一系数应视为量级正确的经验估计而非精确常数。

## 六、启示与影响

### 6.1 工程实践的直接启示

1. **早停可能亲手杀死泛化**：主实验中 10⁵ 步之前验证指标毫无起色，若按常规 patience 早停，模型将在泛化来临前夜被丢弃。（推断）对小型数据/长尾任务，验证平台的持续时间本身应纳入停止准则的考量。
2. **weight decay 应升级为一档正则**：它是唯一将所需样本量削减一半以上的单一干预（§3.3），成本几乎为零——任何 grokking 邻近场景的第一调参项。
3. **学习率窗口是开关而非旋钮**：lr 必须落入一个数量级宽度的窗口泛化才发生（§3.3）。（推断）实践中与其微调 lr 提分，不如先确认自己是否在「会泛化的窗口」内。
4. **数据稀缺时的第二选项是用时间换**：25–30% 区间内每让渡 1 个百分点数据，代价是 40–50% 的额外训练时间（§3.1.1）——当采集数据的边际成本高于算力时，这是一笔可以计算的账。
5. **验证曲线的平台不等于终局**：训练诊断时应把「train 满分 + val 随机 + 尚未到达预算上限」识别为 grokking 潜伏期的签名，而非死过拟合的讣告。（推断）

### 6.2 科学层面的影响（推断）

1. **为机制可解释性提供了理想试验台**：小模型（~4×10⁵ 参数）、已知真值结构（群论）、二元判据（100% 与否）三者齐备，使后续工作可以在完全受控条件下解剖泛化的诞生过程——t-SNE 对齐群论对象的做法开创了「用已知数学结构审计神经网络表示」的范式。
2. **把「优化器噪声→平坦解→延迟泛化」的因果链提上日程**：无论该假说最终成立与否，sharpness−0.79548 的强相关都迫使后续理论工作正视「泛化是优化几何的函数」这一视角。
3. **数据-算力兑换律是 scaling 思想的微观前奏**：「减少 1% 数据 = 增加 40–50% 时间」的指数交换关系，与后来宏观 scaling law 中数据/算力的替代讨论形成呼应——grokking 可视为该议题在完全可控环境下的显微镜切片。
4. **改写了「过拟合」的诊断语义**：grokking 证明训练/验证指标的巨大裂口可以是健康过渡态而非病态终点，这促使社区重新审视以「裂口大小」为核心的正则化评价体系。

### 6.3 方法论遗产（推断）

- **消融矩阵的分类学**：把正则化干预按「显式权重惩罚 / 优化器噪声 / 隐式扰动」三维拆解对照的设计，可直接移植到任何「不明机制现象」的研究中；
- **代数等价验证**：利用原根表示预判 x−y 与 x/y 难度相近并获实验证实，示范了「先做数学同构分析、再设计实验验证」的闭环——比盲扫超参的信息增益高得多；
- **表示审计前置**：在声称「泛化」之前先用 t-SNE 检查内部结构是否对齐已知真值，可作为小规模研究的标准动作。

### 6.4 遗留问题清单

1. grokking 的因果机制：平坦区域是原因还是伴随现象？（论文遗留，A.5 仅初步）
2. 「数据↓→优化时间指数↑」是否在自然数据集（图像/文本/代码）复现？（作者在 §4 自陈待验证）
3. 不 grok 运算（如 x³+xy²+y）与可 grok 运算之间的判定边界；
4. 现象细节（难度排序等）对架构的依赖程度；
5. 窄学习率窗口的成因及其与 grokking 的必然性关系。
