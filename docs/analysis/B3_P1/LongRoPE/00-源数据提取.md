## §4 方法细节

### 4.1 背景与动机（§1 p1-2）

- 长窗瓶颈三因：微调成本高、长文本稀缺、新位置的"灾难性数值"。现有方法上限约 128k。
- 统一框架（式(2) p2）：所有插值法都是对旋转角乘 rescale 因子 λ(β)。PI 对全维全位置用固定 s；NTK 按 λ=sⁱ 把压力从高频维移向低频维（免微调上限约 4×）；YaRN 按频率人工分三组分别外推/NTK/线性插值——分组依赖人工经验，对新模型可能次优。

### 4.2 两重非均匀性发现（§2.2 p3-4）

- **Finding 1（维度）**：对每个 RoPE 维度独立搜索最优 λ，无微调下 8k/16k PPL 大幅下降；搜索出的因子逐维不同，区别于 PI 的常数、NTK 的公式值和 YaRN 的分组值。本质是保住关键维度信息、缓解近距 token 难分辨问题。附注：YaRN 免微调时未达目标窗长（8k 场景 7k 后 PPL 尖峰），PG19 上反而差于 PI/NTK。
- **Finding 2（起始位置）**：借鉴 StreamingLLM/LM-Infinite 的观察（头部 token 注意力分数大），保留前 n̂ 个 token 不做插值确实提升 PPL，且最优 n̂ 依赖目标扩展长度（8k 时 n̂=64 最优、16k 时 n̂=16 左右）。
- **Finding 3**：该非均匀插值在微调前后都优于 PI/YaRN（64k 微调实验：non-fine-tuned PPL 3.22 vs PI 72.54 / YaRN 4.15；fine-tuned 后 2.36 vs 2.44/2.42）。

### 4.3 问题形式化与搜索算法（§3.1-3.2 p4-5）

- 形式化（式(3)）：为每个维度 i 引入 I(λ̂ᵢ, n̂)：n<n̂ 时因子=1（保持原始角度），n≥n̂ 时因子=1/λᵢ；目标是在 ≥L′ 的文档上最小化 next-token loss。
- 搜索空间（Table 4）：λᵢ ∈ [1.0, 1.25s] 步长 0.01（1.0=纯外推，上限比 PI 多插 25%）；n̂ ∈ {0,1,2,4,8,12,16,20,24,28,32,64,128,256}。s=4× 时空间达 400¹²⁸/2×14 ≈ 4×10¹⁶⁷。
- **进化搜索 + 两项加速**：①初始种群注入 PI/NTK/YaRN 三个已知解并随机变异出其余个体；②**单调非降约束** λᵢ≤λᵢ₊₁（低频=高维可多插值的 NTK 理论先验），只评估满足约束的个体，大幅砍掉无效困惑度计算。流程见 Algorithm 1（P₀ 初始化 → 计算 PPL → top-k 更新 → 带约束 mutation/crossover 迭代 T 轮）。
- 搜索超参：≤256k 目标用 P=64, N₁=N₂=16, p=0.3, T=40, top-32，PPL 用 5 条 PG19 验证样本；>512k 目标减半种群/变异/交叉规模，改用 3 条 Pile-Books3 样本。

### 4.4 渐进式扩展到 2048k（§3.3 p5-6）

1. 在预训练 LLM 上分别搜索 128k、256k 目标的因子（32×/64× 扩展比）。
2. 微调至 256k：先用 128k 因子训 400 步，再换 256k 因子续训 600 步（比直接微调到 256k 高效）。LLaMA2 配置：lr 2e-5 linear decay、全局 batch 32、RedPajama 按 128k 段切分加 BOS/EOS；128k 用 8×A100，256k 用 16×A100。Mistral：lr 1e-6 恒定、batch 64、遵循 YaRN 设置仅用 16k 序列长度训 400 步、4×A100。
3. 在 256k 微调模型上**二次搜索**（免进一步微调）直达 2048k（总扩展比 512×）。
- **短窗恢复**：512× 插值使原 4k 区间位置极度拥挤导致性能下滑；对扩展后模型再做一次针对 4k/8k 的小范围搜索（降低允许的 λ 上限），推理时按输入长度动态切换因子组。

### 4.5 评测协议（§4.1 p6）

- 三个维度：①长文档语言建模（Proof-pile 10 条 ≥128k 样本、PG19 全部 100 条测试文档、Books3 抽 20 本每本 >2048k，滑窗 256）；②passkey 检索（五位数密钥随机埋点，10 次迭代取平均）；③4096 原窗口内标准基准（HF Open LLM Leaderboard：ARC-c 25-shot、HellaSwag 10-shot、MMLU 5-shot、TruthfulQA 0-shot）。
- 基线：Together-32k(PI)、Code LLaMA(NTK)、LongLoRA-full-FT-100k(PI)、YaRN-LLaMA/Mistral(s=16/32)。

## §5 实验结果要点

- **≤256k 语言建模（Table 5/7 p7）**：LongRoPE 两个版本在全部评估长度上 PPL 单调下降且几乎全面领先；ft=256k 版本在 262144 处 LLaMA2 达 1.87、Mistral 达 1.84，比 128k 微调版略优（二次扩展比更小：8× vs 16×）。
- **Mistral 异常分析**：Mistral 版在 >256k 后 PPL 超 7 且 2048k 达 12.78——原因是其 128k/256k 微调沿用 YaRN 的 16k 训练长度设定，限制了继续外推能力；故 Mistral 在 ft=128k（二次比 16×）反而略好于 ft=256k（8×），与 LLaMA2 结论相反（§4.2 p6-7）。
- **passkey（Fig.4 p7）**：现有模型 128k 后准确率归零；LongRoPE-LLaMA2 全程 ≥90%，Mistral 到 1800k 满分、2048k 掉到 60%。
- **标准基准（Table 8 p8）**：LLaMA2 版相对原版小幅回退（MMLU −3.2），其中 ft=256k 版回退更大（39.6）；Mistral 版几乎持平甚至 TruthfulQA +0.5。
- **消融汇总（Table 9-11 p8）**：三个机制各自必要——二次插值（C8）、短窗恢复（C9）、维度非均匀性为主 + 起始 token 为辅（C10，但 2048k 处起始 token 不再起作用，作者留作 future work）。

## §6 局限

- 论文内证据显示的限制：① Mistral 版极端长度性能受损（微调用 16k 序列长的折衷所致，Table 6 p7）；② 2048k 处 PPL 相比 1024k 有边际回升（LLaMA2 6.35→7.08），未完全平坦；③ 起始 token 免插值在极长上下文（2048k）不再有收益，机理待研究（Table 11 p8）；④ ft=256k 的 LLaMA2 版在原窗口标准基准上回退更明显（MMLU 46.6→39.6，Table 8a）。
- 方法适用边界（论文声明与隐含）：仅适用于基于 RoPE 的模型；搜索需多次困惑度评估（虽有两项加速，>512k 目标仍需缩减搜索预算）；短窗恢复要求推理时按长度动态维护多套因子。
- 定位限制（§5 p8-9）：与检索式外部记忆方案相比不提供显式记忆管理；与 attention-manipulation 类方法（StreamingLLM 等）互补而非替代。
