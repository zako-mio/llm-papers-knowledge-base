## §4 方法
- 架构：LLaVA 式三件套（SigLIP 视觉编码器 + 2 层 MLP adaptor + DeepSeekMoE LLM）。动态分块：按最小 padding 选 m:n 比例，切 m×n 个 384² tile + 1 张全局缩略图；tile 间加 <tile_newline> 行尾 token，全局图前插 <view_separator>；>2 张图时关闭动态分块控上下文
- 相对 DeepSeek-VL 的演进：旧版混合编码器 SigLIP(384² 粗粒度)+SAM-B(1024² 细粒度)双路融合，受固定 1024² 上限约束；新版单编码器+分块支持任意高分辨率/极端长宽比（InfographicVQA、密集 OCR、精确定位），且局部注意力避免二次方计算膨胀
- 语言端：MLA 将 KV cache 压缩为潜向量降推理成本；DeepSeekMoE 稀疏激活降训练/推理 FLOPs——两者共同支撑"少激活参数打稠密大模型"
- 数据管线：caption 重写（OCR 提示+元信息+原 caption 作 prompt，in-house captioner）→ DeepSeek Chat 打分过滤重复/低质；OCR 数据 = LaTeX OCR + 12M RenderedText + 自建中英文档；VQA 覆盖表格/图表/文档（PubTabNet、FinTabNet、Docmatix）、web-to-code（Websight）与 plot-to-Python（DeepSeek V2.5 增强去噪）、视觉提示 QA（箭头/框/圈覆盖标注）
- 图文交错数据：WIT + WikiHow + OBELICS 随机 30% 子采样（比例经 Tiny 初步实验定）；中文补充自 Wanjuan；另建 in-house 真实世界知识集
- 视觉定位（grounding）：检测框数据转 <|ref|>query<|/ref|><|det|>[[x1,y1,x2,y2]]<|/det|> 格式，prompt 从候选池随机采样，新增 GUI 感知能力
- SFT 数据（§3.3）：多模态对话+纯文本对话混训以保对话能力，监督仅答案与特殊 token，system/user prompt 全掩码

## §5 实验要点
- 三阶段训练：Stage1 冻结 LLM 只训 ViT+MLP（Cosine LR 5.4e-4/4.2e-4/4.5e-4，ViT LR×0.1）；Stage2 全参数解冻（Step LR 在 50%/75% 步数除以 √10，batch 2304–3360，seq 4096，sequence packing + pipeline parallelism）；Stage3 SFT 恒定 LR 3e-5/1.4e-5/2e-5，仅对答案与特殊 token 计算 loss
- 优化：AdamW(β1=0.9, β2=0.95)，weight decay 0.1，grad clip 1.0，aux loss 0.001（最大模型 0.0001 且启用 BF16 optimizer 与 expert bias correction）
- 基建：HAI-LLM 平台训练；Stage2 起启用 sequence packing 与 pipeline parallelism 提升吞吐；最大模型全三阶段用 BF16 optimizer 状态，中小模型保持 FP32 优化器状态
- 评测覆盖 DocVQA/ChartQA/InfoVQA/TextVQA/OCRBench/AI2D/MMMU/MMStar/MathVista/MME/MMBench(-V1.1)/MMT-Bench/RealWorldQA + RefCOCO 系列 grounding；结论：以更少激活参数达到与 InternVL2、Qwen2-VL 同级或 SOTA 表现
- 对照锚点：GPT-4o（MMStar 63.9, MMMU 69.1）仍领先开源；VL2-Small(2.8B 激活) MMStar 57.0 已超 GPT-4V(56.0)；Figure 1 以 6 基准均值 vs 激活参数作散点展示家族性价比
- 定位任务：RefCOCO/RefCOCO+/RefCOCOg 上与专用 grounding 及通用 VLM 对比（§5.1 表格）；定性研究（§5.2）展示文档/图表/grounding/GUI 案例

## §6 局限（§6 Limitations and Future Work + 正文自述）
1. 上下文窗口限制单会话多图交互（下版扩展）；2. 模糊图像与未见物体鲁棒性不足（VLM 通病）；3. 感知识别强但推理能力待加强；4. OCR in-house 数据仅中英文，他语言留未来工作；5. 动态分块在 >2 图场景被禁用，超高分辨率与多图不可兼得。
