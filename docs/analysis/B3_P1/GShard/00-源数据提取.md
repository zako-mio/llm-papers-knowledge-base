## §3 关键数字
- **参数规模**：600B+（600,000,000,000+，超 6000 亿）稀疏 MoE Transformer
- **硬件**：2048 块 TPU v3 加速器
- **训练时长**：4 天（约 96 小时）
- **任务**：100 语种 → 英语的多语言机器翻译（NMT）
- **门控**：top-2 稀疏门控（每个 token 路由到 2 个专家），多语言 MoE 层的专家数量随语种扩展
- **分片模式**：4 种——data sharding、dense (model) sharding、dot-product sharding、efficient (d2d) sharding
- **MoE 设计四项原则**：① 成规模地增加专家数量（scaling capacity）② 随机路由选择（random routing）③ 负载均衡辅助损失（auxiliary loss）④ 专家容量上限（expert capacity）
- **质量收益**：对比当时最优（prior art），600B 模型在 100→en 翻译上取得显著更优的 BLEU 分数（论文 Fig/Table 详列，见解读报告证据链）
- **通信/开销**：重点分析 device-to-device (D2D) 通信在 MoE 稠密-稀疏切换中的占比与优化（用于说明自动分片的核心价值）
