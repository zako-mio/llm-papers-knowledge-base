## §4 方法
三大技术（§3）：
1. **Producer-Consumer asynchrony**（§3.1）：warp-specialized software pipelining——producer warpgroup 用 TMA 异步搬运 Q/K/V 到 s-stage circular SMEM buffer，consumer warpgroup 用 WGMMA 做 GEMM；setmaxnreg 动态重分配寄存器。**pingpong scheduling**：两个 consumer warpgroup 用 bar.sync 交错调度，使一方的 softmax（多函数单元执行）与另一方的 GEMM（Tensor Core）重叠。
2. **GEMM-softmax 2-stage 流水线**（§3.2）：跨迭代打断 softmax↔GEMM 串行依赖——第 j 迭代第二个 WGMMA（P·V）与第 j+1 迭代 softmax 重叠；Snext 额外驻留寄存器（Br×Bc×float/CTA），与 tile size 权衡；另有寄存器压力更大、收益更高的 3-stage 变体（附录 B.3）。SASS 分析确认编译器保留重叠（B.2）。
3. **FP8 低精度**（§3.3）：FP8 WGMMA 仅支持 k-major 且 accumulator/operand 寄存器布局不一致 → 用 LDSM/STSM 在 producer 内做 V tile in-kernel 转置（藏在 WGMMA 影子中，免 GMEM 预转置的额外全局访存），用 byte-permute {d0 d1 d4 d5 d2 d3 d6 d7}（每 8 字节复制）转换累加器布局，并让转置按匹配的行置换写出 V tile。精度侧：**block quantization**（Q,K,V 按 Br×d/Bc×d 块级 scale；S 的块级缩放零算力开销，量化可融合进 memory-bound 的 rotary embedding）+ **incoherent processing**（Q,K 左乘随机正交阵 M=±1对角×Hadamard，O(d log d) 复杂度，MM⊤=I 不改变输出，QM/KM 各元素成为随机化和从而摊平 outlier）。

补充背景（§2）：Hopper 异步性来自 TMA（专用搬运单元）与 WGMMA（Tensor Core 可直接从 SMEM 取数、异步执行）；线程层级 thread→warp(32)→warpgroup(4 warps)→CTA→threadblock cluster(Hopper 新增)→grid。MQA/GQA 变体沿用 FA-2 的索引调整避免 K,V 在 HBM 重复。

## §5 实验要点
- 硬件：H100 80GB SXM5；seq 512–16k（总 token 数固定 16k），headdim 64/128/256；对比 Standard attention、FA-2、FA-2-Triton（Hopper 版）、cuDNN 9。FLOPs 计算式：4·seqlen²·headdim·nheads（causal 减半）；backward FLOPs=前向×2.5（前向2个 matmul+重算下反向5个）。
- FP16 前向（Figure 5）：中长序列（≥1k）超过 cuDNN；d=128 无 causal 16k 达 648 TFLOPs/s（FA-2 仅 370），causal 达 616（vs FA-2 335）；d=64 causal 16k 达 473（vs FA-2 299）；d=256 无 causal 16k 达 756。对标准实现最高 3-16× 加速。
- FP16 反向（Figure 6）：d=128 无 causal 16k 达 561 TFLOPs/s（FA-2 为 322）；d=64 达 474（vs FA-2 291）。
- FP8 前向（Figure 7，d=256）：无 causal 16k 达 1171 TFLOPs/s（cuDNN 903）；有 causal 达 1024（cuDNN 663）。脚注2：d=64 时 FA-3 FP8 领先 cuDNN，d=128/256 无 causal 持平、有 causal 落后。
- Ablation（Table 2，{batch,seqlen,nheads,hdim}={4,8448,16,128} 非因果）：完整 FA-3 3.538ms/661 TFLOPs；仅去 GEMM-softmax 流水线 4.021ms/582；仅去 warp-specialization 4.105ms/570——两项技术各自贡献约 90 TFLOPs/s 且近似可叠加。
- 数值验证（Table 3）：Q,K,V ~ N(0,1)+N(0,100)·Bernoulli(0.001) 模拟 outlier，以 FP64 参考实现测 RMSE；FP8 baseline 用 per-tensor scaling+FP32 累加器+FP16 中间 softmax；block quant 与 incoherent processing 缺一不可（去掉任一退回 2.4e-2）。

## §6 局限（§5 自述）
1. 未针对 LLM 推理优化；2. persistent kernel 设计尚未整合进 FP8 kernel；3. 低精度注意力在大规模训练中的影响未知。附注：FP8 在 causal mask 场景落后于 cuDNN（脚注2）；算法虽不绑定 Hopper 但依赖足够强的异步执行与低精度硬件能力。

补充：backward 算法见附录 B.1；3-stage 流水线评估显示收益受寄存器容量制约，tile size 与流水线深度需按 profiling 权衡（§3.2/B.3）；实现基于 CUTLASS 的 WGMMA/TMA 抽象，in-kernel transpose 思路致谢 cuDNN 团队。历史脉络：FA-1（Dao et al., tiling 融合消除 HBM 中间读写）→ FA-2（沿序列维并行+KV 内循环）→ FA-3（异步性+低精度）。
