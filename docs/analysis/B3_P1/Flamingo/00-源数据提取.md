## §4 方法细节

**总体架构**（Fig.3, §2）：冻结的预训练视觉编码器（对比学习预训练的 NFNet-F6）→ Perceiver Resampler → 插入冻结 LM 层之间的可训练 GATED XATTN-DENSE 层。建模 p(y|x)=∏ₗ p(yₗ|y<ₗ, x≤ₗ)（Eq.1），x 为交错的图像/视频序列。

**Perceiver Resampler**（§2.1, A.1.1）：接收视觉编码器输出的可变长时空特征（视频 1FPS 采样帧独立编码+学习型时间嵌入），通过固定数量的可学习 latent query 交叉注意输出**固定 64 个 visual token**，降低视觉-文本交叉注意力开销。latents 的 K/V 与输入特征 K/V 拼接（区别于 Perceiver/DETR）。仅用时间位置编码无空间编码（NFNet 通道隐含空间信息）。三个模型统一使用约 200M 参数的 Resampler。

**GATED XATTN-DENSE**（§2.2, Fig.4）：在每（或每 k 个）冻结 LM block 前插入新块：先 gated cross-attention（Q=语言特征 y，K=V=视觉特征 x），再 gated FFW，随后接原冻结 self-attention+FFW。tanh gating：新层输出乘 tanh(α) 再加入残差流，α 初始化为 0——初始时模型输出与原 LM 完全一致，保证训练稳定性。消融显示去掉 gating 掉 4.2 分且训练不稳定。新增层激活用 Squared ReLU（优于冻结 LM 的 GeLU）。FFW 隐层 4D。

**per-image/video attention masking（§2.3, A.1.3）**：图像因果建模——每个文本 token 只交叉注意到其前方最近一张图的 visual tokens（函数 φ 映射文本位置→最近前图索引），对更早图像的依赖经 LM 自注意力隐式传播。训练序列最多 5 张图即可泛化到推理时 32 shots。消融：只注意最近一图比注意所有前图高 7.2 分。

**训练数据与目标**（§2.4, Eq.2）：三类网络数据混合——交错图文 M3W（HTML DOM 顺序插入 `<image>` 标签与学习的 `<EOC>` token，随机采样 L=256 token、≤N=5 图）、图文对（ALIGN+LTIP）、视频文对（VTP）。多目标加权负对数似然，跨数据集**梯度累加**优于 round-robin（62.9 vs 70.7）。M3W 图像放置增广：p_next=1/2 随机决定文本关联前图或后图（有数据增广收益）。LTIP/ALIGN 与全部基准做视觉嵌入近邻去重。

**少样本适配**（§2.5, A.2）：支持样例 (image/video, text) 与查询交错成 prompt；开放式任务 beam search（beam=3）生成至 `<EOC>`；封闭式任务对各候选答案按 log-likelihood 打分排序。零样本 = 用两条纯文本示例构造 prompt（一条效果差，两条以上边际收益小）。支持集过大时用 RICES（按冻结视觉编码器相似度检索 top-N 样例并按相似度升序排列）+ prompt ensembling（6 组随机排列平均 log-likelihood）。

## §5 实验结果要点

- **评测协议**（§3, B.1.4）：16 基准分 DEV 集（COCO/OKVQA/VQAv2/MSVDQA/VATEX，设计决策可能过拟合于此）与 11 个未参与任何调参的 held-out 基准（无偏估计）；全基准共用一套评测超参/prompt。
- **Few-shot 结果**（Table 1）：大幅领先全部此前 zero/few-shot 方法（4 examples 即显著）；32-shot 时 6 任务超 FT SOTA；随模型规模与 shot 数性能单调提升，且最大模型更会利用更多 shots。
- **微调结果**（Table 2/B.2.2）：短 schedule 小 lr、解冻视觉骨干适配更高分辨率，再夺 5 个 SOTA。
- **消融要点**（Table 3/Table 10）：
  - 数据组合至关重要：去 M3W 掉 17%+（few-shot 能力主要来自交错数据）；ITP→LAION-400M 轻微退化；去视频对伤全部视频任务。
  - 冻结 LM 防 catastrophic forgetting：从零训 −12.9%，解冻微调预训练 LM 也掉 −8.0%；替代方案"混入 MassiveText 协同训练"两种初始化均更差且更贵。
  - 架构对比：GATED XATTN-DENSE > VANILLA XATTN > GRAFTING；Perceiver Resampler > Transformer > MLP（等参预算下均更快更好）。
  - 强视觉骨干重要：NFNet-F6 比 CLIP ViT-L/14 高 5.8%、比 NFNet-F0 高 8.0%。
  - LM 预训练质量重要：MassiveText→C4 使 overall 掉 7.9%，语言理解型任务（VQA 类）受损最重。
  - 对比预训练中 LTIP（比 ALIGN 小 6×但质量更高）单独训练即胜过 ALIGN 单独——数据质量>数量；Accumulation 混合策略最优（Table 11）。
- **定性能力**（Fig.1, Appendix C）：多图视觉对话、OCR、算术、知识问答、视频时序理解等开箱即用。

## §6 局限

1. **继承 LM 缺陷**：幻觉与无根据猜测（LM prior 所致）；对超过训练长度的序列泛化差（VisDial 因 2048 token 上限只能报 16 shots）；预训练样本效率低。
2. **分类任务落后对比范式**：ImageNet/Kinetics700 上不及 CLIP 类对比模型，甚至低于自家作为视觉编码器训练的对比模型——语言建模目标不直接优化检索式分类。
3. **in-context learning 固有短板**：对示例选择/顺序高度敏感；shot 数超出低数据区间后推理开销线性增长而绝对性能扩展性差；作者提出未来可结合梯度式少样本方法互补。
4. **去重覆盖不全**：VizWiz/HatefulMemes/TextVQA 未做训练集去重（论文论证风险很低）；M3W 未整体去重（抽查 185M 图发现 1314 候选重复、125 精确重复）。
5. **闭源不可复现**：M3W/LTIP/VTP 与模型权重均未公开，社区只能借 LAION400M+CLIP 近似复现（Table 10 row vii 显示该配置明显更弱）。
6. **社会影响风险**：输出冒犯内容、放大社会偏见与刻板印象、泄露隐私；视觉输入引入性别/种族偏见新维度（Appendix D.2 有缓解讨论）。
