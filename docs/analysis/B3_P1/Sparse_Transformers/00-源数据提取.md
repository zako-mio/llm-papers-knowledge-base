## §4 方法细节

**动机与观察（§4.1, p.4）**：可视化 128 层全注意力网络在 CIFAR-10 上学到的注意力模式（Figure 2），发现大多数层呈现稀疏模式——早期层局部连接（类似卷积），第 19–20 层自发分解为行注意力+列注意力，部分层全局数据依赖访问，64–128 层高度稀疏。据此假设引入预定稀疏性不会显著损害性能。

**因子化自注意力形式化（§4.2, p.4）**：注意力层由连接模式 S={S₁,...,Sₙ} 参数化。因子化版本使用 p 个注意力头，第 m 头定义子集 Aᵢ⁽ᵐ⁾⊂{j: j≤i}，要求：(a) 每个 |Aᵢ⁽ᵐ⁾| ∝ ⁿ√n；(b) 跨 p 步注意力所有位置保持连通（任意 j≤i 存在长度 ≤p+1 的路径）。本文取 p=2。

**两种二维分解模式（§4.3, p.4–5）**：
- **Strided attention**（Figure 3b）：Aᵢ⁽¹⁾={t,...,i}, t=max(0,i−l)；Aᵢ⁽²⁾={j: (i−j) mod l=0}，stride l 取接近 √n。适合图像、音乐等有周期结构的数据。
- **Fixed attention**（Figure 3c）：Aᵢ⁽¹⁾={j: ⌊j/l⌋=⌊i/l⌋}（块内）；Aᵢ⁽²⁾={j: j mod l∈{t,...,l}}, t=l−c。每个块内 c 个位置汇总信息并向所有后续位置传播。例：l=128, c=8 时，所有 >128 的位置可看 120–128，>256 看 248–256，依此类推。c∈{8,16,32}、l∈{128,256} 表现良好；c=1 会显著限制表达力；fixed 比 strided 多 c 倍计算。多头时让各头注意同一 l 块内不同 c 子块更优。
- 文本等无周期结构数据用 strided 会失败（空间坐标与相关性不对齐），改用 fixed。

**架构改造（§5, p.5–6）**：
- 因子化头的三种整合方式：逐残差块交替（Eq.6）、merged head 合并模式（Eq.7）、多头并行（Eq.8）；通常多头效果好，但极长序列注意力占主导时逐个串行更划算。
- **深网络训练**：采用 He et al. 2016 pre-activation 残差块（Hₖ = Hₖ₋₁ + resblock(Hₖ₋₁)，Eq.9–14），W₂ 与 Wₚ 初始化按 1/√(2N) 缩放以保持跨层数的尺度不变；激活函数 GELU 近似 f(X)=X⊙sigmoid(1.702X)；FFN 输出维度 4d。
- **多数据类型嵌入**（§5.3, Eq.15）：图像用 d_data=3 维数据嵌入（行/列/通道），文本与音频用 d_attn=2 维注意力嵌入（按 stride 宽度矩阵的行列索引）。
- **显存优化**（§5.4）：反向传播时重算 attention 与 FFN 块（gradient checkpointing，Chen et al. 2016）；为简化实现不在注意力块内 dropout，只在每次残差相加末尾施加。
- **block-sparse GPU kernels**（§5.5）：从 Q/K/V 切子块分块计算；softmax 融合进单一 kernel 并用寄存器避免重复加载；从不计算注意力矩阵上三角（免去负偏置项并减半运算量）。
- **混合精度**（§5.6）：权重 FP32 存储，激活/梯度 FP16（V100 Tensor Core 加速），动态 loss scaling 防下溢，采样时 query-key 乘积转 FP32 防溢出。

**训练配方（§6, p.7）**：Adam、5000 迭代线性 warmup、梯度裁剪 1.0、weight decay 0.01、cosine 学习率衰减；嵌入维度 d∈{256,512,1024}；权重初始化 N(0, 0.125/√d_in)，logits 输出权重初始化为 0。

## §5 实验结果要点

- **CIFAR-10**（§7.1）：3072 字节序列；2 头 / 128 层 / d=256 / half-size FFN 与 QK 投影 / 120 epochs / lr 3.5e-4 / dropout 0.25；48000 训练+2000 验证。strided 达 2.80 bpd，超过稠密注意力的 2.82 且收敛更快。
- **Enwik8**（§7.2）：上下文 12,288（长于以往方法）；30 层 fixed / 8 heads / d=512 / dropout 0.40 / stride 128 / c=32 / merged heads / 80 epochs；90M tokens 训练。0.99 bpd 追平参数量两倍以上的 Transformer-XL 277M。
- **ImageNet 64x64**（§7.3）：48 层 strided / 16 heads / d=512 / 152M 参数 / stride 128 / dropout 0.01 / 70 epochs / 64 V100 × 7 天 → 3.44 bpd（前 SOTA 3.52）。300M 参数模型的无条件采样视觉上无稀疏伪影且具长期结构。
- **原始音频古典音乐**（§7.4, Table 4）：序列长与容量的权衡规律——序列 ×4 需模型容量 ÷8；65,536/152M→1.97，262,144/25M→2.17，1,048,576/3M→2.99 bits/byte；65,536（约 5 秒 @12kHz）样本展现全局连贯性与多样演奏风格；更长序列因容量缩减质量快速退化。
- **总体结论**（Table 1/2, §8）：稀疏模式不仅更快，在被比较的数据集上还收敛到更低误差——作者推测是稀疏模式的归纳偏置或稠密注意力存在潜在优化问题。

## §6 局限

1. **Strided 对无周期数据失效**：文本等数据的元素空间坐标与其未来相关位置不对应，strided 模式无法正确路由信息（Enwik8 上 strided 仅 1.13 vs dense 1.00，Table 2），需退回计算量高 c 倍的 fixed 模式。
2. **固定稀疏模式牺牲表达能力**：预定的稀疏性无法学习 Figure 2 中全局/数据依赖型注意力模式；c=1 时网络表达力被严重限制。
3. **超长序列容量瓶颈**：音频实验中序列增至百万级时参数被迫缩至 3M，采样质量随长度增加快速退化（§7.4）。
4. **工程复杂度**：需要定制 GPU kernel、混合精度与重计算等配套工程才能实际落地，通用性受限。
