## §4 方法
- **架构（GLM-4）**：除 QKV 外去 bias（略提升长度外推）；RMSNorm+SwiGLU 替代 LayerNorm/ReLU；二维 RoPE 适配 GLM 的 2D 位置编码；GQA 替代 MHA 减 KV cache，d_ffn=10/3·d_model 维持参数量。上下文 2K→32K→128K/1M（位置编码扩展+长文续训+LongAlign 长上下文对齐）。
- **预训练数据**：网页/Wikipedia/书籍/代码/论文多源；三段流水线（精确+模糊去重→过滤→BPE 分词），对高质量源重加权。
- **对齐**：多阶段 SFT+RLHF；发现真实人类 prompt 优于模板/模型生成；RLHF 缓解拒答、安全、双语混杂、多轮连贯问题。标注维度：安全/事实性/相关性/有用性/人类偏好。
- **子技术族**：涌现能力重新定义为"预训练 loss 低于阈值"（同 loss 不同规模性能一致）；LongAlign；ChatGLM-Math 自评数据选择；ChatGLM-RLHF（PPO+DPO）；Self-Contrast 免反馈负样本自生成；AgentTuning+AgentInstruct 轨迹数据；APAR 并行自回归生成提速；自建基准 AgentBench/LongBench/AlignBench/HumanEval-X/NaturalCodeBench。
- **All Tools**：意图理解→逐步规划→自主调用浏览器/Python 解释器/CogView 文生图/用户自定义函数；GLMs 平台支持用户自定义智能体。

## §5 实验要点
- 时间线（Figure 1）：GLM(2021-03 自回归填空目标+开源 GLM-10B)→GLM-130B(2022-08 开源，HELM 2022-11 追平 GPT-3 davinci)→ChatGLM-6B/ChatGLM-130B 上线 chatglm.cn(2023-03-14)→ChatGLM2-6B(2023-06)→ChatGLM3-6B(2023-10，起支持 function call/code interpreter/复杂 agent 任务)→GLM-4(0116)(2024-01-16 API)→GLM-4(0520)/GLM-4-Air(0605)/GLM-4-9B 系列(2024-06)。
- 开源三代演进（Table 1，Base 版）：ChatGLM-6B→GLM-4-9B，MMLU 25.2→74.7，GSM8K 1.5→84.0，BBH 0.0→76.3，HumanEval 0.0→70.1，C-Eval 23.7→77.1，DROP 3.9→77.2。
- ChatGLM-6B 设计动机：6.2B 参数便于快速迭代预/后训练与数据选择技术，且 INT4 量化可在消费级显卡本地部署。
- CodeGeeX 系：CodeGeeX2-6B 增训 600B code tokens，HumanEval-X Pass@1 较 CodeGeeX-13B 提升 Python +57%/C++ +71%/Java +54%/JS +83%/Go +56%。
- GLM-4-9B 预训练 ~10T 多语 token（8K 上下文），与 GLM-4(0520) 同一 post-training 管线/数据，用更少算力超 Llama-3-8B；另有 1M 上下文实验版 GLM-4-9B-Chat-1M（约 200 万汉字）。评测均以 BFloat16 部署。
- All Tools 实测（Table 9，Web 端 0116 版 vs GPT-4 Web 0110 版）：Python 解题 GSM8K 91.59 vs 92.72、MATH 63.60 vs 65.00、Math23K 88.50 vs 88.40；浏览器信息检索 78.08 vs 67.12 明显占优。
- 安全：预训练敏感关键词+黑名单清洗；对齐阶段逐样本安全评估剔除风险样本；无危害性作为偏好对齐重要判据；红队持续构造刁钻问题收集有害 QA 并人工改进后再用于对齐。SafetyBench 七维度中文子集（剔除易被审查的高敏题以规避 API 安全策略干扰）聚合 87.2。

## §6 局限
- 中文数学推理落后 GPT-4 Turbo（§3.3，差距集中在 Mathematics 维度）。
- AgentBench 上 OS、知识图谱、横向思维谜题环境落后 GPT-4 系（§3.7）。
- SafetyBench Physical Health 维度低于 GPT-4 家族（§4）。
- 数据工程尚无根本性原理指导采集/清洗/筛选，仍依赖经验（§2）。
- 基线分数部分引自各家技术报告而非统一复测，跨报告可比性受限；模型未开源权重（仅 6B/9B 小型版开源）。
