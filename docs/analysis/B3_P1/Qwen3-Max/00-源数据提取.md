## §4 方法要点

1. **规模路线**："Just Scale it" —— 在 Qwen3 MoE 设计范式上直接放大至 >1T 总参，验证 scaling law 的持续有效性。
2. **global-batch load balancing loss**：团队自研（"Demons in the Detail", ACL25）的负载均衡损失，用于 MoE 训练稳定性，是全程零 loss spike 的关键。
3. **工程栈三件套**：
   - PAI-FlashMoE 多级流水线并行（MFU +30%）；
   - ChunkFlow 长上下文训练策略（ICML25，吞吐 3×、1M 上下文）；
   - 稳定性套件 SanityCheck + EasyCheckpoint + 流水线调度优化（故障损失降至 1/5）。
4. **Instruct 后处理**：正文未披露 SFT/RLHF 细节，仅给出结果性描述（coding 与 agent 能力提升显著）。
5. **Thinking (Heavy) 路线**：推理增强 = 模型原生思考 + 代码解释器集成 + 并行测试时计算（test-time compute scaling），当时处于"仍在训练"状态。

## §5 评测结果要点

- **人类偏好**：Preview 版即登 LMArena Text 全球第 3（超 GPT-5-Chat）；正式版进一步提升。
- **编码**：SWE-Bench Verified 69.6（真实 GitHub issue 修复），居全球第一梯队。
- **Agent 工具调用**：Tau2-Bench 74.8，超 Claude Opus 4 与 DeepSeek-V3.1，为当时该榜突破性成绩。
- **数学推理（Thinking 预告）**：AIME25、HMMT 双满分（100%），条件为代码解释器 + 并行测试时计算。
- **覆盖维度**（官方自述）：知识、推理、编码、指令遵循、人类偏好对齐、agent 任务、多语言理解全面 SOTA。
- **可用性**：Qwen Chat 直接体验；API model name `qwen3-max`（Alibaba Cloud Model Studio，OpenAI 兼容）；第三方分发 OpenRouter。
