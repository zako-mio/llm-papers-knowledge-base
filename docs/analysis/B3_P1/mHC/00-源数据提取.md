## §4 方法要点（公式均出自 p7-8）
- HC 基线：残差流宽度由 R^d 扩至 R^(n_hc×d)；三线性映射 input mapping A∈R^(1×n_hc)、residual transformation B∈R^(n_hc×n_hc)、output mapping C∈R^(n_hc×1)
- Eq.(1)：X^(l+1) = B_l·X^l + C_l·F(A_l·X^l)，F 为第 l 层（如 MoE），实际层输入 A_l·X^l 仍为 d 维 → 残差宽度与隐藏维解耦的互补 scaling 轴
- Eq.(2) 流形约束：B_l ∈ M := {M∈R^(n×n) | M·1=1, 1ᵀM=1, M≥0}；推论 ‖B_l‖₂≤1（non-expansive，前向/反向稳定）+ M 对乘法封闭（深层堆叠仍稳定）
- Eq.(3)-(5) 动态参数化：输入经 RMSNorm(vec(·)) 后生成原始参数 Ã/B̃/C̃ = α·(动态项 X̂W 或 Mat(X̂W_res)) + S(静态可学偏置)；门控因子 α 小值初始化
- Eq.(6)(7) 参数约束：A_l = σ(Ã_l)；C_l = 2σ(C̃_l)（Sigmoid 非负有界，避免信号相消）
- Eq.(8) Sinkhorn-Knopp 投影：M⁰=exp(B̃_l)，迭代 M^(t)=T_r(T_c(M^(t-1)))（行/列归一化交替），收敛到 B_l∈M
- 训练配方（p14）：mHC 的静态偏置 S 与门控因子 α 用 AdamW，其余模块用 Muon

## §5 效果证据
- 稳定性动机（p8）：标准 HC 多层堆叠时训练频繁数值不稳定、阻碍 scaling；mHC 以流形约束解决（报告层面为定性主张）
- 工程证据（p20）：fused kernel（训练+推理）+ 选择性重算 checkpoint + DualPipe 1F1B 重叠调整 → wall-time 开销压至 6.7%
- 确定性证据（p19）：小 batch 下 split-k 非确定 → 分片输出+后续 kernel 确定性归约，性能与确定性兼得
- 规模验证（p24-25）：Flash（13B 激活/32T tokens）与 Pro（49B 激活/33T tokens）双模型统一启用 n_hc=4、t_max=20，作为默认架构组件交付

## §6 局限与开放问题
- 本报告未提供 mHC 端到端性能收益数字（无 ablation 表）；收益量化需查专文 arXiv:2512.24880
- 代价：相较常规残差，激活内存与流水线阶段间通信量增加，依赖工程优化缓解（p20）
- 小输出维度 GEMM（仅 24）在小 batch 场景被迫 split-k，需额外确定性归约内核（p19）
- t_max=20 为经验值，收敛裕度/迭代截断误差未讨论（p8）；n_hc 固定 4 无敏感性分析（本报告范围内）
