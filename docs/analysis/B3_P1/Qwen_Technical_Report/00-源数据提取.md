## §4 方法细节

### 4.1 数据与预处理（§2.1, p4–6）
- 公共 web 文档 + 百科 + 书籍 + 代码，中英为主的多语种混合；总量 up to 3T tokens。
- 清洗流水线：HTML 抽取 → 语言识别 → 去重（归一化后精确去重 + MinHash/LSH 模糊去重）→ 质量过滤（规则 + 多个打分模型：语言模型分、文本质量分、冒犯内容识别）→ 人工抽检 → 高质量源上采样；预训练混入高质量指令数据提升 zero/few-shot；对评测集做 13-gram 重叠过滤防泄漏。

### 4.2 架构（§2.3, p6–7；Table 1, p7)
- 基于 LLaMA 式修改的 Transformer：untied embedding/output projection（实验证明更优，代价是显存）；RoPE 位置编码且**逆频率矩阵用 FP32 精度**；多数层去 bias 但 **QKV 层加 bias**（增强外推能力）；Pre-Norm + RMSNorm；SwiGLU 激活（FFN 隐层由 4×h 缩至 8/3×h）。
- 规模：1.8B（hidden 2048/16 头/24 层，2.2T tokens）、7B（4096/32/32，2.4T）、14B（5120/40/40，3.0T）；峰值 lr 均 3e-4，batch 4M tokens/step。

### 4.3 训练（§2.4, p7）
- 标准自回归 LM，上下文 2048；Flash Attention；AdamW（β₁=0.9, β₂=0.95, ε=1e-8）；cosine lr 衰减至峰值 10%；BFloat16 混合精度。

### 4.4 免训练长上下文扩展（§2.5, p7–8）
- **Dynamic NTK-aware interpolation**：改 RoPE base 而非等比缩放各维，按 chunk 动态调 scale；
- **LogN-Scaling**：按上下文长度/训练长度之比缩放 query·value 点积，稳定注意力熵；
- **分层窗口注意力**：观察到低层对长度扩展更敏感 → 低层短窗、高层长窗。

### 4.5 对齐流水线（§3, p9–11；§A.1.1, p36）
- **SFT**：多风格人工标注对话（含安全类数据），剔除模板化格式；采用 **ChatML** 元语言格式；loss mask 掉 system/user 输入；seq len 2048、batch 128、4000 步、peak lr 2e-6、weight decay 0.1、dropout 0.1、grad clip 1.0。
- **RM**：先做 PMP（preference model pretraining，海量比较对预训练）再高质量比较对微调；约 **6600 个细粒度标签**的分类体系 + 兼顾多样性/复杂度的均衡采样；多尺寸多采样策略生成候选回答降低标注难度；RM 在同尺寸预训练底座上加 pooling 层取 end-token 句级奖励；lr 恒定 3e-6、batch 64、单 epoch。
- **PPO**：policy/value/reference/reward 四模型；先冻结 policy 单独预热 value model 50 步；每查询采 2 个回答；KL 系数 0.04、reward 按运行均值归一化；policy lr 1e-6 / value lr 5e-6；value loss clip 0.15；采样 top-p 0.9；引入**预训练梯度（pretrained gradient）缓解对齐税**（非代码/数学基准上 KL 惩罚已足够，系数过大阻碍对齐、过小无效）。

### 4.6 工具使用与 Agent（§3.4, p13–15）
- Self-instruct 迭代式造数：用 Qwen 自身 ICL 能力生成 ReAct 格式样本 → 规则 + 人工清洗 → 混入通用 SFT 数据再训 → 循环扩充，最终约 **2000 条高质量工具调用样本**（不设独立训练阶段以保留通用能力）。
- 自建并开源两套基准：ReAct 中文工具调用基准、Code Interpreter 基准（数学/可视化/通用三类，可视化正确性用 Qwen-VL 判图）。

### 4.7 专用模型（§4–§5, p16–20)
- **Code-Qwen**：不从零代码预训，而是 base model 继续预训约 **90B tokens** 代码（上下文扩到 8192）；lr 6e-5(14B)/3e-5(7B)，3% warmup 无衰减；SFT 采用多阶段策略效果最佳，lr 2e-6(14B)/1e-5(7B) cosine 至峰值后恒定。
- **Math-Qwen-CHAT**：直接在增强数学指令集上 SFT；因数学数据平均较短，seq len 1024 加速；mask 系统/用户输入加速收敛；lr 2e-5，50000 步。

## §5 实验结果要点

- **基座横评（Table 2, p8）**：7 大基准上 Qwen-14B 全面超过此前 13B 级 SOTA（Baichuan2-13B、InternLM-20B 等），C-Eval 72.1 领先第二名 Baichuan2-13B(59.0) 达 13 点；1.8B 小模型也具竞争力（MMLU 44.6 超 LLaMA-7B 的 35.6）。
- **长上下文（Table 3, p9）**：三项技术叠加后 7B/14B 在 16k 长度 PPL 分别 4.32/3.42，几乎无退化；未加则爆炸（2645+/3168+）。
- **对话对齐（Table 5, p12）**：Qwen-14B-CHAT 除 ChatGPT 与 LLaMA2-Chat-70B 外全面领先开源 chat 模型；HumanEval 0-shot 43.9 显著高于所有开源对手（LLaMA2-Chat-70B 仅 32.3）。作者同时质疑传统基准对 chat 模型的度量力，主张人工评测（300 条中文指令，Figure 4, p13）。
- **Agent 能力（Table 6–9, p13–15）**：工具选择/输入生成随规模单调提升；Code Interpreter 上通用模型反超专职代码模型（Code Llama 因凭文件名幻觉列名而在可视化任务翻车）；HF Agent 上 14B-CHAT Run Mode 代码正确率 87.0% 平 GPT-3.5。
- **代码（Table 10/11, p18–19）**：Code-Qwen-Chat-14B HumanEval 66.4 为当时开源同规模最强梯队，但仍落后 GPT-4（86.6）与更大规模闭源；HumanEvalPack 平均 51.9% 大幅领先 OCTOCODER/WizardCoder-15B。
- **数学（Table 12, p19）**：Math-Qwen-14B-CHAT GSM8K 69.8 追近 Minerva-62B/GPT-3.5；MATH 24.2 超越 Minerva-8B(14.1)、WizardMath-70B(22.7)；中文向 Math401/Math23K 反超 GPT-3.5/GPT-4 部分（85.0 vs GPT-4 83.5；78.4 vs GPT-3.5 60.0）。

## §6 局限

1. **与闭源仍有差距**：无论人工评测（Figure 4）还是代码/数学基准，Qwen 系均明确落后 GPT-4，作者自认"仍落后 GPT-4"，且承认现有基准难以精确刻画与专有模型的差距（§3.3 p12–13；§4.3 p17）。
2. **技术报告性质、缺消融**：多数架构选择（untied embedding、QKV bias 等）仅引"初步实验"结论，无系统消融数据；训练数据配比、RLHF 数据规模等关键细节未公开。
3. **长上下文方案为推理期补丁**：NTK/LogN/窗口注意力均为免训练技巧，训练长度仍为 2048，超长依赖外推而非原生训练；且分层窗口为经验性设定（§2.5 p7–8）。
4. **自建基准的公平性风险**：工具调用与 Code Interpreter 基准为自家构建（虽排除训练集插件、开源基准），中文为主的设定对 GPT-3.5 不利，作者亦承认该基准"相对简单需迭代升级"（§3.4 p15）。
5. **对齐税问题未彻底解决**：pretrained gradient 方案系数敏感（过大阻碍对齐、过小无效），属经验性缓解（§3.2.2 p11）。
