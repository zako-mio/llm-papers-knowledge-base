## §4 方法细节

**三模型模块化架构（§3）：**
- **Actor M_a**：LLM 按状态观测生成文本与动作；实例化可选 CoT 或 ReAct prompting；配 memory 作为额外上下文；
- **Evaluator M_e**：给轨迹 τ 打标量奖励 r = M_e(τ)。三种实现——推理任务用 exact match (EM)；决策任务用启发式（同一动作+相同响应循环 >3 次，或动作数 >30 即判低效触发重置）；决策/编程也可用另一个 LLM 实例做二元分类打分；
- **Self-Reflection M_sr**：输入 {τ_t, r_t, mem}，产出言语化反思 sr_t——把稀疏奖励"放大（amplify）"为具体改进方向（如"第 i 步应改选 a_i′"），充当 **'semantic' gradient signal**；
- **Memory**：轨迹历史 = 短时记忆；sr 序列 = 长时记忆（episodic memory buffer），滑动窗口上限 Ω（实践取 **1–3 条**）以防超出上下文。

**迭代流程（Algorithm 1）：** 初试 → 评估 → 反思 → 写入 mem → 重置环境再试，循环直到 Evaluator 判定通过或达 max trials。

**三组实验设定：**
1. **ALFWorld**（134 个 TextWorld 家务任务 ×6 类）：ReAct 作动作生成器，GPT-3 few-shot，memory 截断至最近 3 条反思；基线组触发反思条件时只重置不反思；
2. **HotPotQA**（113k 多跳问答）：CoT 6-shot（Q→A 及 Q,C_gt→A 两口径）、ReAct 2-shot（Wikipedia API 检索）、self-reflection 2-shot，EM 判分，memory=3；允许连续 3 次失败后放弃该题；
3. **Programming**：Python/Rust。Rust 用 MultiPL-E 把 HumanEval 最难 50 题 + MBPP 翻译过去；**Leetcode HardGym**（本文新基准）：40 道 2022-10-08 之后发布的 hard 题（晚于 GPT-4 预训练截止）。测试套件由 CoT 生成多样测试 → AST 校验过滤语法非法项 → 抽样 ≤6 条组成 T；全程不用 ground-truth 测试，故可合法报告 pass@1。

## §5 实验结果要点

- **ALFWorld（Fig 3）**：ReAct+Reflexion(Heuristic) 前 2 试急升、随后 11 试稳步爬升至近满分（130/134）；失败归因分析显示 Reflexion 几乎消除两类典型错误——"以为持有物品实际没有"的幻觉与低效规划；
- **HotpotQA（Fig 4）**：Reflexion 三变体全面领先；CoT(GT)+Reflexion 最高但受限于 39% 无法推理出的问题；关键消融证明 self-reflection > 单纯 EPM 记忆重放（+8%）；
- **编程（Table 1）**：除 MBPP Python 外全部刷新 SOTA；Rust 结果证明框架语言无关性（编译型语言同样适用）；
- **测试质量分析（Table 2）**：TP/FN/FP/TN 四象限统计表明 FN（好代码被误判错）优于 FP（坏代码蒙混过关）——前者可通过自我反思识别错误测试并保留原解，后者导致提前提交错误答案；MBPP PY 高 FP 率（16.3%）直接拖累成绩；
- **贡献清单**：①verbal RL 新范式（策略 = agent's memory encoding + LLM 参数选择）；②LLM 自反思涌现性质的首批系统验证；③Leetcode HardGym 新环境；④多任务 SOTA。

## §6 局限（论文自述 §5 Limitations）

1. 本质是用自然语言做策略优化，仍可能陷入**非最优局部极小**；
2. 长时记忆仅为滑动窗口（Ω≤3），作者建议未来接向量数据库或 SQL 等更高级结构；
3. 测试驱动开发的固有限制：非确定性函数、含 API 副作用的 impure 函数、硬件相关输出、并行/并发行为都难以用输入-输出映射准确指定测试；
4. （§6 Broader impact 补充）依赖 LLM 自评能力、无成功的形式化保证；自动化增强的双刃剑效应需要安全与伦理配套，但言语化 RL 也让策略更可解释、可诊断（如工具调用前可审计反思文本）；
5. 复现提示（§8）：自主写码实验务必在隔离执行环境中运行（生成代码未经校验即执行有风险）。
