# §0 摘要速览

本文提出一项**免从零训练即可提速 LLM 解码**的技术路线：把一个已经训练好的 multi-head attention (MHA) checkpoint 转换成 multi-query attention (MQA) 或 grouped-query attention (GQA) 模型，只需**原预训练计算量的 5%** 做"继续预训练"，便能获得接近 MHA 的质量和接近 MQA 的速度。核心贡献是 (1) 一种 checkpoint 转换 + uptraining 配方，与 (2) GQA 这一 MHA/MQA 之间的插值方案。实验基于 T5.1.1 的 Large/XXL，在 7 个数据任务上验证：GQA-8-XXL 平均质量 47.1（对标 MHA-XXL 47.2），推理时间 0.28s（对标 MQA 0.24s、MHA 1.51s）。

# §4 方法细节

1. **Uptraining 两步骤**：
   - 第一步：将 multi-head checkpoint 的 K/V 投影矩阵按 head **mean-pooling** 成单组（或 G 组）矩阵。均值池化优于选单个 head 或随机初始化新 head。
   - 第二步：在原始预训练设置与数据集上，再用原预训练计算量的一小比例 α=0.05 继续预训练，让模型适应新结构。

2. **Grouped-query attention (GQA)**：
   - 将 H 个 query heads 分成 G 组，每组共享单个 key head 和 value head。
   - 相比 MHA（H 个 KV head）与 MQA（1 个 KV head），GQA 是二者插值。
   - **仅在 decoder self-attention 和 cross-attention 应用 GQA，不应用于 encoder self-attention**——因 encoder 表示并行计算，内存带宽通常不是瓶颈。

3. **训练细节**：Adafactor 优化器，与 T5 相同超参/学习率调度；评估用于摘要（CNN/DailyMail、arXiv、PubMed、MediaSum、MultiNews）、翻译 WMT2014 En-De、QA TriviaQA。微调用固定学习率 0.001、batch 128、dropout 0.1。CNN/DailyMail 和 WMT 用输入 512/输出 256；其余摘要 2048/512；TriviaQA 2048/32。greedy decoding。

4. **动机来源**：因 KV-cache 随模型维度缩放、FLOP 与参数随维度平方缩放，大模型 MQA 削减更激进；标准切分会复制单 KV head 到各分区（Pope et al., 2022）。

# §5 实验结果要点（详细数值）

**Table1：各数据集完整性能与推理时间（P3）**

| 模型 | T_infer | Average | CNN | arXiv | PubMed | MediaSum | MultiNews | WMT | TriviaQA |
|---|---|---|---|---|---|---|---|---|---|
| MHA-Large | 0.37 | 46.0 | 42.9 | 44.6 | 46.2 | 35.5 | 46.6 | 27.7 | 78.2 |
| MHA-XXL | 1.51 | 47.2 | 43.8 | 45.6 | 47.5 | 36.4 | 46.9 | 28.4 | 81.9 |
| MQA-XXL | 0.24 | 46.6 | 43.0 | 45.0 | 46.9 | 36.1 | 46.5 | 28.5 | 81.3 |
| GQA-8-XXL | 0.28 | 47.1 | 43.5 | 45.4 | 47.7 | 36.3 | 47.2 | 28.4 | 81.6 |

（表头顺序与原文 Table1 一致：Time / Average / 各数据集。数值全部抄录自原文；其中 Average 列与 CNN 等列为不同字段，故 Average=46.0 而 CNN=42.9 等。注意：WMT 与 TriviaQA 是 BLEU 类指标，其值较高（如 78.2）。T_infer 为平均 time/sample。）

- 逐项观察：GQA-8 在 arXiv(43.5)、MediaSum(47.7)、MultiNews(36.3) 上甚至**略高于或等于 MHA-XXL**（43.8/47.5/36.4），在 TriviaQA 与 WMT 与 MHA-XXL 持平（28.4/28.4），仅 CNN 略低（47.1 vs 47.2）。avg 列 GQA-8 47.1 非常接近 MHA-XXL 47.2，而推理时间 0.28s 接近 MQA 0.24s（远低于 MHA 1.51s）。
- 说明：T5-XXL 的 MHA/baseline 平均比 T5-Large 高约 1 分，GQA-8 复现了大部分增益的同时速度提升显著。

**图3（P3）速度-质量伞形图**：横轴 average inference time，纵轴平均性能。uptrained MQA 相比 MHA-Large 落在"右上"（质量更高、速度更快）；GQA-8 相对 MQA 质量再上一个台阶，贴近 MHA-XXL 水平，但速度仍接近 MQA。

**图4（P4）checkpoint 转换方法对比**（T5-Large → MQA, α=0.05）：Mean-pool（均值池化）最好，First（选第一个 head）次之，Random（随机初始化新 head）最差。结果排序与"从预训练模型保留信息程度"直观一致。

**图5（P4）uptraining 比例 α**：0~0.1（对应 0.02/0.04/0.06/0.08/0.1）。MQA 与 GQA-8 均在 5%（0.05）时性能已较接近基线，随 α 增大性能持续上升但 10% 后收益递减——即收窄为 small fraction。

**图6（P4）分组数 vs 推理时间**（输入 2048/输出 512）：从 1 组（=MQA）增到 8 组再到更多，推理时间线性上升，但 1→8 的增量较小（"modest overhead"），8 组被选为有利折中。对更大模型，KV-cache 带宽开销占比变小、减容更锐利，因此越大的模型增加分组数的代价相对越低。

**附录A（P7）训练稳定性**：从零训练多个 T5-Large + MQA，每次预训练都频繁出现 loss spikes，且在长输入任务微调时模型立即发散。uptrained MQA 更稳定但仍显示高方差（不稳定任务报告 3 次运行平均）。uptrained GQA 明显稳定（故未深究 MQA 不稳定性根因）。

# §6 局限

1. 仅聚焦缓解加载 keys/values 的内存带宽开销，该开销在生成长序列时最显著，而长序列质量本就难以评估。
2. 摘要采用 ROUGE score，作者自知是"有缺陷的评估"，难以确切地说明 trade-off 是否正确。
3. 受算力限制，未将 XXL GQA 模型与**从零训练**的对比模型比较，无法确定 uptraining vs 从零训练的相对优劣。
4. 仅在 **encoder-decoder** 模型上评估 uptraining 与 GQA；预测 decoder-only 模型（无独立 self/cross-attention）上 GQA 相对 MQA 优势更强，但未直接实验验证。
