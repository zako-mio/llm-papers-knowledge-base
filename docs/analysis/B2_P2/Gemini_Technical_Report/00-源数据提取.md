## §4 方法细节

- **架构**：decoder-only Transformer；支持 32K 上下文；使用高效注意力（如 multi-query attention, Shazeer 2019a）。
- **原生多模态**：文本与图像/音频/视频交错输入，可输出文本与图像（离散 image tokens）。视觉编码受 Flamingo/CoCa/PaLI 启发，但从一开始即多模态联合训练。视频=大上下文窗口内帧序列；可变输入分辨率；音频以 16kHz 的 USM 特征直接用（非文本转写）。
- **训练基础设施**：TPUv4（Ultra，多数据中心大量加速器）/ TPUv5e（按规模）；TPUv4 以 4096 芯片 SuperPod 部署，optical switch 约 10s 动态重构 4x4x4 到任意 3D torus。JAX + Pathways 'single controller' 单 Python 进程编排；GSPMD 分区 + MegaScale XLA 调度 collective。冗余内存副本恢复（替代传统 checkpoint 到持久存储），goodput 85%→97%；SDC 用确定性重放+主动扫描+热备机处理。
- **预训练数据**：多模态且多语言（web 文档/书籍/代码 + 图像/音频/视频）；对非拉丁脚本有更高效 tokenizer；质量过滤（启发式+模型分类器）；安全过滤；删除评测泄露数据；阶段化调整数据配比（训练后期增加领域数据权重）。
- **后训练（Post-training，§6.3）**：四步——(1) 预训练基础上后训练；(2) SFT on Demonstration Data（人工/模型+人工复核）；(3) RM Training on Feedback Data（相对偏好打分）；(4) RLHF（迭代优化）。Figure 7 展示数据飞轮。
- **AlphaCode 2**：基于专门在竞赛编程数据上调优的 Gemini Pro，大规模搜索程序空间 + 过滤/聚类/重排；Gemini Pro 同时作 coding 模型与 reward model。Codeforces 77 道题（12 场 div1/2），解 43%。
- **安全（Resp. Deployment）**：Impact Assessment（模型级+产品级）、通过 Google AI Principles 框架；Safety Policies；Mitigations（数据清洗、SFT、RLHF）；Safety Evaluations（Development/Assurance/External 三种）+ Red Teaming。

## §5 实验结果要点

- **文本 Table 2**（Gemini Ultra）：MMLU 90.04% CoT@32；GSM8K 94.4% Maj1@32；MATH 53.2% 4-shot；BIG-Bench-Hard 83.6% 3-shot；HumanEval 74.4% 0-shot(PT)；Natural2Code 74.9%；DROP 82.4 F1；HellaSwag(validation) 87.8% 10-shot；WMT23 74.4 BLEURT。Gemini Pro 对多个核心指标与之接近。PaLM 2-L / GPT-4 / Claude 2 / Grok 1 / LLaMA-2 作对照。
- **Nano Table 3**（vs Pro 归一化）：Nano-2 MMLU 55.8%(0.78)、Nano-1 MMLU 45.9%(0.64)；Big-Bench-Hard Nano-2 42.4%(0.58)。
- **图像理解 Table 7/8**：MMMU(val) Ultra 62.4% Maj@32 / 59.4% pass@1（GPT-4V 56.8%）；TextVQA 82.3%、DocVQA 90.9%、ChartQA 80.8%、InfographicVQA 80.3%、MathVista 53.0%、AI2D 待补。分学科 Art&Design 74.2、Business 62.7、Science 49.3、Health 71.3、Humanities 78.3、Tech 53.0。
- **视频 Table 10**（16 等距离帧）：VATEX 62.7（Flamingo 56.0）、VATEX ZH 51.3、YouCook2 135.4（Flamingo 74.5）、NextQA 29.9（0-shot, Flamingo 26.7）、ActivityNet-QA 等。
- **音频 Table 11**：见 §3 语音行。
- **后训练能力**：Instruction following、Tool use、Multilinguality、Multimodal vision、Coding（Table 18：Gemini-Advanced w/Ultra SxS 优于 Gemini w/Pro +0.13±0.02）。

## §6 局限

1. **幻觉与可信度**：明确承认 LLM 的 hallucination 问题，需持续研究使输出更可靠可验证（§8）。
2. **高逻辑推理短板**：对因果理解、逻辑演绎、反事实推理等高阶推理仍显不足，即便考试基准表现出色（§8）。
3. **基准污染/泄露**：执行泄露数据检测，但仍有 minor issues；如 LAMBADA 因泄露不报；HellaSwag 仅报去污染 10-shot 数值（p7 明示结果对预训练数据组成敏感）。
4. **音频评测有限**：Gemini Ultra 未做音频评测（预期随规模提升）；FLEURS 因含其训练数据有明显增益（无 FLEURS 训练时 WER 15.8）。
5. **未知模型实际规模/算力**：Model Card 明示 Compute Requirements / Model Stats "Not reported"（p72）。
6. **表示性伤害评测饱和**：多数代表伤害数据集 accuracy 接近 99%，方法有局限，需开发新评测（p34）。
