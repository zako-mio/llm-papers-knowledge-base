## §1 元数据
- **标题**：Visual Instruction Tuning（视觉指令微调）
- **作者/机构**：Haotian Liu、Chunyuan Li、Qingyang Wu、Yong Jae Lee —— **University of Wisconsin-Madison（UW-Madison）与 Microsoft Research（合作；Chunyuan Li 属 Microsoft）**，正文亦提到 related work 与 Wisconsin/微软联合
- **发布**：arXiv:2304.08485 [cs.CV]，初版 2023-04-17，更新至 v2 2023-12-11；NeurIPS 2023 Oral；共约 15-20 页
- **DOI**：无（NeurIPS 会议论文，会议论文集无 DOI；常用引用为 arXiv 2304.08485）
- **许可证**：论文附「我们公开 GPT-4 生成的视觉指令微调数据、模型与代码库」；代码/权重以后续开源许可证分发（LLaVA 项目页 llava-vl.github.io）
- **产品线定位**：B2_P2（视觉指令微调 VLM 的奠基作——开源「视觉编码器 + 投影层 + LLM」范式代表）
- **核心主张**：**首次**用纯语言版 GPT-4 生成「多模态语言-图像」指令跟随数据，再以指令微调训练出 **LLaVA（Large Language and Vision Assistant）**，一个端到端训练的大多模态模型，把视觉编码器与 LLM 连接起来做通用视觉语言理解。在合成多模态指令跟随数据集上达到 GPT-4 的 **85.1% 相对得分**；微调到 Science QA 后，LLaVA+GPT-4 取得新 SOTA 精度 **92.53%**。

## §3 关键数字
- **指令微调数据**：158K 条语言-图像指令跟随样本（三种标注模式：conversation 对话 / detailed description 详细描述 / complex reasoning 复杂推理）
- **数据来源**：GPT-4（纯语言输入）生成；基于 COCO 等图文对扩展出「图文指令对」
- **预训练对齐数据**：约 595K（或按配置取 CC3M/concept caption 子集，具体取数随版本配置）——用于第一阶段投影层对齐（推断字段，以正文表为准）
- **结构**：CLIP 视觉编码器（ViT-L/14）→ 线性投影层（即 `W`，把视觉 token 映射到LLM词嵌入空间）→ 语言模型（LLM，采用 Vicuna / LLaMA 系，7B/13B）
- **训练成本**：论文强调「训练成本很低」（单块计算即可支撑，相对后来的大 VLM 而言）
- **评测一**：合成多模态指令跟随数据集上 LLaVA 达 GPT-4 的 **85.1% 相对得分**（GPT-4 为 100%）
- **评测二**：Science QA 上 LLaVA 单模型约 90.92%，**与 GPT-4 协同达 92.53%**（新 SOTA，超过当时 SoTA 方法）
- **发布物**：GPT-4 生成的视觉指令数据、模型、代码全部公开（开源多模态预设）

## 备注
- 最初尝试用语言模型生成**多模态**指令数据（扩展现有 InstructBLIP-style 思路），并提出 LLaVA 的简洁可复现的两阶段训练管线，成为后续 LLaVA-1.5、LLaVA-NeXT 等一系列工作与开源 VLM 生态（LLaVA 派生 MiniGPT-4、Qwen-VL、LLaVA-Bench 等）的奠基。
