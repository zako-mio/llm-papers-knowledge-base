## §3 核心主张与关键数字（含表注出处）

**核心主张**：①线性注意力可同时拥有并行训练形式与 RNN 推理形式（2D 矩阵隐态），但缺 I/O 感知实现与表达性门控；本文给出硬件高效的 chunkwise 训练算法 **FLASHLINEARATTENTION**，并推广到**数据依赖门控**的 GLA 层；②GLA Transformer 在中等规模语言建模上与强 LLaMA 基线（Transformer++）、RetNet、Mamba 竞争力相当，且在长度外推与 recall-intensive 任务上居线性模型之首，训练吞吐高于同尺寸 Mamba（摘要、§1 p1–2）。

## §4 方法细节

### 4.1 背景：线性注意力的三种形式（§2, p2–3）
- 并行形式 O=(QKᵀ⊙M)V 复杂度 O(L²d)（因果 mask 阻止结合律降维）；递归形式 Sₜ=Sₜ₋₁+kₜᵀvₜ, oₜ=qₜSₜ 即"fast weights"式 2D 隐态线性 RNN，推理 O(Ld²) 线性复杂度；
- **Chunkwise 并行形式**：块内并行（intra-chunk O(C²d)）+ 块间递推（inter-chunk），训练复杂度 O(LCd+Ld²)，L>d 时优于二次；C=L 退化为并行形式，C=1 退化为递归形式。

### 4.2 FLASHLINEARATTENTION（§3, p3–4；Algorithm 1/Figure 1）
硬件三原则：高 SM 占用率（时间维并行）、张量核 matmul（半精度约 16× 加速）、SRAM/HBM 内存层级（减少 HBM I/O）。
- 两个版本：**non-materialization**（S 留 SRAM 顺序算，省显存但无序列级并行）与 **materialization**（先存全部块级 S[n] 到 HBM 再并行算输出，多耗 10–20% 显存）；
- 默认采用 materialization + **反向重计算**（前向后丢弃隐态、反向重算），运行时开销小、显存占用大幅下降。

### 4.3 GLA 门控设计（§4.1–4.2, p4–6；Table 1, p5）
- 递归式：Sₜ = Gₜ⊙Sₜ₋₁ + kₜᵀvₜ，其中 Gₜ∈(0,1)^{dk×dv} 为 2D 遗忘门；
- 参数化谱系对比（Table 1）：Mamba 全秩 A+数据依赖 αt（无法转 matmul、需 SRAM 物化限制状态扩展 ≤16×）；Mamba-2/mLSTM 标量门 γt（可用张量核但过粗）；DFW 全低秩 αᵀβt；**GLA 取折中 Gₜ=αₜᵀ1**（Diag(αt) 行门控），兼顾细粒度与张量核友好；
- 并行形式的数值稳定性：累积乘积 bₜ=∏αⱼ 会下溢 → 对数空间计算 P_ij=Σₖ Q_ik K_jk exp(logB_ik−logB_jk)，类似数据依赖相对位置因子；
- chunkwise 形式引入 Λ（块首累计衰减）/Γ（块尾衰减）/γ（整块衰减）三组因子做块间递推与块内修正。

### 4.4 硬件高效 GLA 的两项关键技术（§4.3, p6）
1. **二级分块（secondary-level chunking）**：chunk 内再切 sub-chunk——子块间交互用半精度 matmul（张量核），仅子块内部小部分用全精度 log 空间算，大幅降低非半精度 FLOPs；
2. **dαₜ 闭式梯度**：推翻 Mao (2022)"必须物化 L×d×d 隐态求梯度"的做法，给出 dlog bₜ = qₜ⊙dqₜ − kₜ⊙dkₜ、dlog αₜ=Σ_{i≥t} dlog bᵢ，无需物化全部隐态。

### 4.5 GLA Transformer 层与参数分配（§4.4, p6）
- 多头：每头独立 S^h_t∈R^{d'k×d'v}；各头输出先 LN 再 concat；输出经 Swish 输出门 rₜ 与 W_O 投影；整体夹在 Pre-LN + SwiGLU FFN 的 LLaMA 式 block 中；
- 参数效率：αₜ 经低秩两层 σ(xW¹αW²α)/τ（rank 16，温度 τ=16 减缓遗忘速率）；设 dk=d/2、dv=d 扩大状态容量；(W_Q,W_K,W_V,W_O,W_r) 全秩——**单层总参数 ≈4d²，与标准 softmax 注意力持平**。

### 4.6 训练配置（§5.1, p7）
- 数据：SlimPajama 100B 子集，Mistral tokenizer；
- 规模：340M（batch 0.5M tokens × 15B tokens）与 1.3B（batch 2M × 100B tokens）从零训练；
- AdamW lr 3e-4，cosine 至 3e-5，warmup 0.5B/1B tokens，weight decay 0.01，grad clip 1.0；
- 基线：Transformer++（LLaMA 架构+RoPE+SwiGLU+RMSNorm）、RetNet（FFN 也换 SwiGLU 保公平）、Mamba（官方开源码），同数据同 token 数。

## §5 实验结果要点

- **主基准（Table 2, p7）**：340M 档 Mamba 平均最佳（41.8%）但 GLA(41.5%)>Transformer++(41.2%)>RetNet(41.0%)；1.3B 档 GLA(51.0%) 最佳，超过 Mamba 与 Transformer++，HellaSwag norm-acc 49.8 显著高于 Mamba 的 40.1。
- **Recall 能力（Table 3/Figure 4, p7–8）**：信息抽取类任务上所有次二次模型大幅落后 Transformer，但 GLA 是最好的次二次模型；作者归因于比 Mamba 更大的循环状态 + 比 RetNet 的选择机制更强的数据依赖门。
- **长度外推（Figure 5, p8）**：2K 训练时 GLA 外推最好（SlimPajama 测试至 18K 平稳；Transformer 无法超出训练长度）；所有模型经 8K 直接训练或 TBPTT 后均改善；TBPTT(12×2K)≈直接 8K 训练效果而开销近 2K 训练。
- **效率（Figure 2/6, p4/8–9）**：层级速度上 FlashLinearAttention 全长度区间快于 FlashAttention-2；模型级吞吐 GLA > Transformer++ > Mamba（长序列差距拉大）；三者显存均为线性且差异极小。
- **消融（Table 4, p9）**：门控粒度阶梯（无门 23.21→标量静态 16.55→标量动态 15.56→细粒度动态 14.77）证明"数据依赖"+"细粒度"缺一不可；头数 4 为质量/显存平衡点。

## §6 局限

1. **规模上限未验证**：作者明言受算力限制只做到 1.3B/100B tokens，GLA 向更大模型/数据集的可扩展性未知（仅推测 >7B 时凭张量核与张量并行兼容性会反超 Mamba）（§5.4, p9）。
2. **recall 差距仍在**：即便 GLA 是最优次二次模型，FDA/SWDE 等抽取任务与 Transformer++ 差距仍大（19.9 vs 27.4；50.6 vs 66.6）——线性注意力固有的固定状态容量瓶颈未消除（Table 3, p8）。
3. **模态单一**：实验仅覆盖语言建模，长程依赖更强的其他模态（视觉等）留作 future work（§5.4, p9）。
4. **外推依赖评测条件**：长度泛化结论基于 2K 训练/中等长度测试，且 PG19 与 SlimPajama 表现有分化的位置桶，非严格"无限长"证据（Figure 5, p8）。
5. **数值稳定性代价**：log 空间计算使部分运算无法用半精度 matmul，需二级分块技巧补救，实现复杂度高于普通线性注意力（§4.1/§4.3, p5–6）。
