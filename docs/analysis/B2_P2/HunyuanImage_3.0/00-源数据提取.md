## §4 方法细节

- **统一架构**：decoder-only MoE LLM 骨干 + 预训练 vision encoder + VAE，各配投影层对齐到与词嵌入兼容的联合空间。混合离散-连续建模：文本走自回归 next-token 预测，图像走 diffusion 式预测（承 Transfusion/JanusFlow 思路）。
- **Dual-Encoder**：条件图像输入将 VAE 潜特征与 vision encoder 特征拼接进同一序列——与以往"理解用 ViT 特征、生成用 VAE 特征"的分任务隔离不同，支持交错对话、生成、编辑在同一连续上下文内完成。
- **Generalized Causal Attention**：文本 token 仅注意此前所有多模态 token；图像 token 注意所有前序多模态 token 及同图像段内全部后继图像 token（段内全注意力）。训练含多个 Gen Image 时对上下文中已生成图像打掩码洞；推理时每次至多一个 Gen Image，无需该掩码。
- **Generalized 2D RoPE**：将 1D 图像位置重排为 2D 各向异性频率 [cos(xθ0), cos(yθ1), ...]；文本保持标准 1D RoPE（可视为对角线 2D），无图像时精确退化为 1D RoPE，保证与预训练 LLM 完全后向兼容；多 Gen Image 训练序列做位置平移对齐。
- **Automatic Resolution**：词表扩展 <img_size_*>(256/512/768...) 与 <img_ratio_*>(1:4~4:1 共 33 档) 两组特殊 token，模型依上下文自预测尺寸与宽高比。
- **Captioning 管线**：分层 schema（4 级描述长度 + 风格属性 + 事实实体 IP 字段）；组合式合成长度与模式多样性；OCR Agent 提取图内文字、Named Entity (IP) Agent 识别现实实体，经 Bidirectional Verification Loop 双向核验后才入训。
- **推理数据**：T2T（真实文生图 prompt 语料强化逻辑推理）、T2TI（prompt→推理迹→图像端到端 CoT）、TI2TI（编辑对 + 将复杂指令分解为原子操作的编辑迹）。
- **四阶段预训练**：I 冻结 ViT 训 Transformer（256px，T2I+LM+MMU）→ II 冻结 Transformer 微调 ViT（MMU）→ III 联合训练（512px+，加 INTL）→ IV 高分辨率子集（VAE ≥1024px 短边，ViT 仍 512px，加 CoT）。全程保持原始宽高比的多分辨率生成。
- **后训练链**：SFT（人标高质量 T2I + 编辑对 + 推理数据，多阶段渐进高保真）→ 两阶段 DPO（先稳采样/编辑一致性再精修真实感）→ MixGRPO（ODE-SDE 混合采样的在线 RL，多奖励模型联合：美学/防畸变/人脸 ID 保持）→ SRPO（噪声先验注入潜空间的单步去噪优化）+ ReDA（自研 Reward Distribution Alignment：任务特定投影器压缩空间 + 参考图 transition 向量差目标）。

### 补充：数据过滤三阶段明细（§2.1）

- **阶段一（技术缺陷）**：剔除低分辨率（<512px）、损坏文件、过曝/欠曝、过饱和图像，按 MD5 去重。
- **阶段二（主筛选）**：两类算子——客观过滤器（水印/logo/大段文字[hy-OCR]/拼贴/明显边框/AIGC 检测器；AIGC 图像会扭曲自然数据分布妨碍收敛，除检测外还整源移除高 AIGC 占比来源）与主观评分算子（清晰度模型按锐度/噪声/动态范围打分；美学模型由艺术家定义色彩/光影/构图三要素标准后构建）。全类型统一阈值 + 特定题材差异化阈值供后期训练阶段选料。
- **阶段三**：基于 embedding 聚类再去重（移除约 0.5%），并定向补充知识增强、文字相关、风格化、平面设计等专题数据集扩展语义广度。
- **图像对构造双路径**：(1) 图像聚类路径——从 >20 亿簇中取代表性簇抽相似对，经图像关系判别算子保留显著编辑关系，再用图像复杂度模型滤除过度复杂样本；(2) 视频挖掘路径——镜头边界检测→相机运动分类剔除过度运镜→目标检测+语义分割定位规范变换关系关键帧→运动模糊检测终筛。

### 补充：评测协议细节

- **SSAE 12 个细粒度字段**：主/次主体的名词、主要属性与动作、主体其他属性、场景名词与属性，以及镜头（camera shot）、风格、构图；LLM 先做点抽取→一致性核验滤除幻觉点→人工修正，之后固定不动以保证跨模型公平；MLLM 按 CoT 做 0-1 匹配打分。
- **GSB 公平性控制**：每 prompt 单次推理、禁止 cherry-picking、所有对比模型用默认设置、>100 名专业评审盲评 Good/Same/Bad 三档。

## §5 实验结果要点

- **SSAE**：针对 GenEval/T2I-CompBench "短模板 prompt + CLIP Score 与人类判断脱节"两大缺陷设计；LLM 结构化解析关键点并滤除幻觉点，MLLCoT 打分做 0-1 匹配；报告 Mean Image Accuracy 与 Global Accuracy 两级总体指标。结果：各细粒度字段均与领先模型持平（数值见原文 Figure 6）。
- **GSB**：1,000 prompt、每模型单次推理不挑样、>100 名专业评审。核心结论是开源首次追平闭源头部（Seedream 4.0/Nano Banana/GPT-Image）。
- **MoE 发现**：随机抽 1,000 prompt 做 T2I 统计专家激活——随层数加深，图文两模态的专家激活分布 KL 散度增大且趋分散，表明 MoE 通过专家模态特化增强多模态建模。

## §6 局限

- 本发布仅含 text-to-image 能力；image-to-image（编辑等）训练仍在进行，后续才放出。
- SSAE/GSB 均依赖 MLLM 打分或内部评审团，未提供第三方榜单交叉验证；GSB 相对胜率数字较小（对闭源模型 +1.17%~+5.00%），优势幅度有限。
- 参数量与算力开销大：完整 80B 模型部署门槛高，20B 压缩版为解法但质量"competitive"而非无损。
- hy-OCR 等 data operator 部分组件标注 to be released，数据管线不完全可复现。
- 未披露预训练总 token 数/GPU 时等训练成本细节。
