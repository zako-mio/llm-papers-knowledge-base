## §4 方法细节

Model Card 未公开架构与训练配方，方法性内容限于：
- **统一 agentic 接口**：搜索（信息聚合+证据合成）、代码中心执行（结构化计算/工具编排）、原生视觉感知（截图/文档/图表/视频直接操作 GUI，覆盖无 API 场景）。
- **可配置思考模式**：以测试时计算换质量；并行思考路径（increased test-time compute）聚合中间结果提升难题上限（Table 7）。
- **VideoCut 工具**：模型指定起止时间戳与 FPS(1–5) 重采样回放片段，实现高帧率细节捕获与慢动作审视；CGBench 62.4→65.9、LVBench 73.0→78.9、自建 ZeroVideo（101 道超难长视频题）6.9→18.8（反超 G2.5-P 8.9 / G3-P 14.3）（Table 6）。
- **流式视频交互**：1FPS 连续流上三种状态切换（即时应答/静默跟踪/视觉主动介入），生成可被新帧打断并动态续写（§3.6）。
- **评测体系三原则**（Appendix A）：用户体验优先（对标 ChatGPT 用例分布）、转向真实场景（Economically Valuable Fields）、推进智能边界（BeyondAIME/SuperGPQA 等）。
- **自研基准群**（Appendix B）：MM-BrowseComp（224 题多模态浏览）、WideSearch（200 题，一致性导向）、AInstein-SWE-Bench（科研级代码：量子化学/量子计算/天体物理/HPC 生产库 fail-to-pass）、U-Artifacts（199 例 GUI artifact）、DiscoX（篇章级中英翻译）、XpertBench（200+领域专家、140+真实任务类型、rubric 评审）、WorldTravel（150 题"多模态×运筹级"旅行规划，单题 10–20+ 耦合约束，人类专家均值 1.5h，hard-to-solve/easy-to-verify 自动判分）等。

## §5 实验结果要点

1. **语言**（Table 1，think-high，无工具）：数学与代码居第一梯队但非全面第一（AIME-25 94.6 vs G2.5-P 95.0；LCB v6 87.0 vs 90.7）；IMO-AnswerBench（带代码工具）76.0 超 Claude 57.5；复杂 IF 全面强势（Collie-Hard 99.0*）。
2. **视觉**（Table 2）：整体逼近 Gemini-3-Pro，在 ZeroBench/VLMsAreBiased/MUIRBench/DA-2K/MMSI/NIAH 反超登顶；GUI grounding ScreenSpot-Pro 36.2，启用 crop-box 工具后 73.1。
3. **视频**（Table 3）：Motion & Perception 与 Streaming 两域 SOTA 密集；学科知识类（VideoMMMU 82.7 vs G3-P 87.6）仍落后。
4. **Agentic**（Table 4）：深度研究写作三项全第一（DeepConsult 57.2 / DRB 48.7 / DiscoX 75.1）；金融/法律/教育/人文专家任务多数第一；agentic coding 中游（SWE-V 74.9 vs GPT-5 77.2；TerminalBench2.0 35.2 vs G2.5-P 54.2）。
5. **GUI**（Table 5）：OSWorld 62.9 创家族新高（+26.2 vs Seed1.5-VL）；移动端 AndroidWorld 56.0 落后 Claude 69.7 / O3 70.7，但官方强调内部移动评测集一致占优。
6. **效率**（§2.4）：同 token 预算下全面优于 Seed1.6，Pareto 前沿占优；BrowseComp 上 unlimited 档随步数稳步升至 67.6@150 步，低/中档 <50 步得 45.0/55.0。
7. **安全**：AIR-Bench 较前代提升，XSTest 保持高可用性。

## §6 局限

1. **正文叙述与表格数字系统性错位**：Agentic Search 段落声称 GAIA "highest score (93.2)"、BrowseComp-en 67.6、BrowseComp-zh 78.5、MM-BrowseComp 46.3 等，但 Table 4 中 Seed1.8 对应列为 76.7 / 54.9 / 63.0 / 27.7，正文数值恰与竞品列（如 Gemini-3-Pro 87.4/67.6/81.3/46.3）部分重合；Education/CustomerSupport "best performance" 声明亦与 Table 1 数据不符（表中 Gemini 更高）。引用本文数字时应一律以表格为准并交叉核对。
2. **知识型视频理解落后**：VideoMMMU/MMVU/VideoSimpleQA 显著低于 Gemini-2.5/3-Pro；TOMATO 60.8 与人类 95.2 差距大（作者自认）。
3. **agentic coding 非第一梯队**：TerminalBench2.0、BFCL-v4、Multi-SWE-Bench 均落后至少一个竞品。
4. **纯评测型 Model Card**：无参数量/架构/数据/训练成本披露，可复现性有限；内部基准（ZeroVideo/U-Artifacts/XpertBench/WorldTravel 等）缺乏外部可验证性。
5. 部分最佳成绩依赖工具增强（crop-box、VideoCut）或 * 号外部转引设置，跨模型可比性受限。
