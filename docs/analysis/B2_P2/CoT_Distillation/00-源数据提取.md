## §4 方法细节

**两步 pipeline（§3 Method）：**

1. **Step 1 — CoT 数据标注（teacher annotation）**
   - 用 PaLM 540B 或 GPT-3 175B 作为教师，对已有监督数据集做 **8-shot few-shot prompting** 生成 CoT；
   - 关键修改①：在 prompt 的 Question 之后、示例 CoT 之前插入该题的 **target answer**——观察发现这让 LLM 能修正 CoT 中的小错误；
   - 关键修改②：基于 target answer **过滤掉所有 CoT 推理错误的样本**（防止学生学习 bad examples）。
2. **Step 2 — 学生微调（teacher forcing, Williams & Zipser 1989）**
   - 输入 = 问题；输出 = CoT + 答案；训练后无需 prompting。

**评估细节：**
- 算术任务额外报告 **external calculator** 口径：遍历输出、重算等式左边并替换右边（如 `5+5=11` 中把 11 替换为 10），避免算术小错污染整链判断；
- GSM8K 用官方 split（train 最后 10% 作验证）；MAWPS/ASDiv 用 5-fold cross validation；StrategyQA 按 80/10/10 切分且不打乱以保证可复现；
- 符号任务在长度 2 上训练、长度 3/4 上测 OOD 泛化（各 1000 训练/测试例）；因模板刚性，PaLM 能近乎完美复刻模板，故符号任务改用模板生成 CoT；
- Baseline：未微调 T5 XXL（原始 target 微调版作为 Base 对照）；PaLM 540B 不参与微调，仅 8-shot CoT 参考值。

## §5 实验结果要点

- **算术（Table 1，T5 XXL）**：
  | 数据集 | Baseline | CoT Finetuned | +Calc | PaLM 8-shot | 数据量 |
  |---|---|---|---|---|---|
  | GSM8K | 8.11 | 21.99 | 38.21 | 56.90（+calc 58.60） | 6725→用 5337 |
  | MAWPS | 54.15 | 70.41 | 88.22 | 93.00（93.66） | 1590 |
  | ASDiv | 39.64 | 42.12 | 60.73 | 73.9（72.6） | 1844→1544 |
- **常识（Table 3）**：StrategyQA 68.12 → 71.98（PaLM 蒸馏）；golden CoT 微调反而最好（71.98 同档），归因于该数据集最大而 PaLM/GPT-3 都有出错样本。GPT-3 蒸馏版 63.77 低于 baseline（负向结果被如实报告）。PaLM 8-shot 参考 77.8。
- **符号（Table 2）**：Last Letter Concatenation OOD 完全失败（0.00 vs baseline 30.0/40.0）；Coin Flip OOD:3 从 13.10 跃升至 86.70；OOD:4 反而低于强 baseline（70.50 vs 73.80），作者解释为 4-flip 任务长度是训练任务的 2 倍。
- **模型规模消融（Fig 3，p5 图数据）**：随 T5 尺寸递增收益单调上升（small 4.40/4.17 → xxl 21.99/38.21，baseline/CoT-w-calc 口径）。
- **数据规模消融（Table 4）**：4%（213 例）6.29 / 20%（1067 例）11.22 / 100% 21.99（+calc 分别 12.28 / 20.47 / 38.21）。
- **讨论要点**：蒸馏本质是 imitation knowledge；小模型也能学到"如何接近此类任务"；pipeline 允许 model-size ↔ dataset-size ↔ accuracy 三方权衡。

## §6 局限（论文自述 §8 Limitations + §9 Ethics）

1. 仅英语实验，且每次单任务训练，非多任务设定（与 LLM few-shot 设定不完全可比）；
2. 复现需访问非公开模型（PaLM 540B），且要在大量数据上跑推理，成本高；
3. 只探索了原始 CoT prompting，未纳入后续改进如 self-consistency（Wang et al. 2022）；
4. 收益 task-dependent：需要特定事实知识的 StrategyQA 提升有限——小模型容量不足以记住 imitation 之外的知识；
5. 伦理：师生模型都可能生成 non-factual/offensive 输出（输入为同行评审基准任务，风险受控但非零）。
