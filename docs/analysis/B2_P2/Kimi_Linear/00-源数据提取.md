## §4 方法细节

- **KDA 核心**：将 GDN 的标量遗忘门 αt 细化为逐通道对角门 Diag(αt)（每维独立遗忘率，粒度同 GLA），更新式 S_t=(I−β_t k_t k_t^T)Diag(α_t)S_{t−1}+β_t k_t v_t^T。视角：线性注意力=在线学习，DeltaNet=重构损失梯度下降，GDN=权重衰减，KDA=细粒度衰减的可学习位置编码（§6.1 论证 gated delta rule 可写成与 RoPE 类似的乘性位置编码形式，转移矩阵数据依赖且放松正交约束）。
- **DPLR 特化**：把广义 DPLR 的 a,b 两变量都绑定为 k，使 chunkwise 算法免于对数域计算与二级全精度分块，配合 WY 表示、UT transform、前代消元求三角逆，实现半精度 matmul 全利用。
- **参数化**：q/k/v 经 ShortConv+Swish（q,k 再 L2Norm 保特征值稳定）；门控 α 经低秩投影 W↓α/W↑α（秩=头维）；输出端 head-wise RMSNorm + 低秩 Sigmoid 数据依赖输出门（缓解 Attention Sink）。头维 dk=dv=128。
- **混合架构**：层间混合（整层交替）优于层内混合——系统简单、训练稳；3 KDA + 1 Full MLA 周期重复。MLA 层用 NoPE（位置信息完全交由 KDA 承担）：便于推理时转纯 MQA、免去 RoPE base/YaRN 调参、利于长上下文扩展。
- **Scaling law 设置**：Moonlight 架构 MoE（64 专家激活 8 个），Muon 优化器，653M~1.7B 五档激活参数。
- **预训练配方**：4096 上下文、MuonClip 优化器、WSD 学习率调度、lr=1.1e−3、全局 batch 32M tokens，沿用 K2 的退火与长上下文激活阶段。
- **后训练配方**：SFT 在 K2 SFT 数据上加推理任务，多阶段（先通用后推理密集）；RL 用 K1.5 算法 + 截断重要性采样缓解 rollout/训练精度失配 + 动态 KL 惩罚与 mini-batch 调整防熵坍缩，PTX loss 并行 SFT 防通用能力退化。

### 补充：注意力机制统一视角（§6.1/Table 6/Table 7）

- 报告将各注意力机制改写为统一的循环形式 o_t = Σ_i [q_t^T (Π_{j=i+1..t} A_j) k_i] v_i：SA/RoPE/LA/Mamba2/GLA/DeltaNet/GDN/Comba/RWKV7 等均为该框架特例（差异只在转移矩阵 A_j 的形式）；RoPE 对应正交旋转矩阵的累积乘积（绝对位置自动转相对位置），而 gated delta rule 的转移矩阵数据依赖且可学习，放松了 RoPE 的正交约束，被视为更强大的乘性位置编码，并为 RoPE 外推问题（固定频率对训练长度过拟合）提供潜在解法。
- TTT（test-time training）视角（Table 7）：LA 对应无界相关损失（只积累不遗忘），RetNet 对应带 L2 正则的目标（衰减 α），DeltaNet/GDN/KDA 对应重构损失的在线梯度下降并引入门控遗忘——gating 与 decay 是缓解干扰、稳定优化的可学习判据。
- 纯线性注意力的根本短板仍是精确复制与极端长程检索（有限状态容量理论限制），这正是混合架构与结构化更新（delta rule）的动机。

### 补充：@5.7T vs Moonlight 关键数字（Appendix D）

同为 3B 激活参数、5.7T tokens 训练下，Kimi-Linear-Base(48B) 对 Moonlight-Base(16B)：TriviaQA 75.2 vs 66.2、SimpleQA 10.1 vs 5.6、MMLU-Pro 54.8 vs 42.4、MMLU-redux 79.7 vs 73.8、WinoGrande 81.5 vs 74.6、GPQA-Diamond 40.4 vs 35.2、MATH 58.5 vs 45.3、GSM8K 86.3 vs 77.2、GSM8k-platinum 89.6 vs 79.4、CMATH 85.5 vs 79.6、CRUXEval-I-cot 61.0 vs 45.9；RULER@1M 达 94.8。注：该对比同时改变了总参数（48B vs 16B）与注意力架构两个变量。

## §5 实验结果要点

- **合成任务**：Palindrome/MQAR/Stack 上 KDA 全部领先 GDN/Mamba2，收敛更快；纯乘性衰减、无 delta rule 的 Mamba2 在该设置下全部任务失败。
- **消融**（同 FLOPs 同超参，16 heads/16 layers）：Sigmoid 输出门优于无门/swish 门；depthwise conv 仍有贡献；3:1 比例 train/val PPL 双最低；NoPE 版在长上下文显著优于 RoPE 版（RULER 84.3 vs 78.8），短上下文相当。
- **性能层级**：预训练/SFT 阶段 Kimi Linear > GDN-H > MLA；长上下文阶段 GDN-H 跌至 MLA 之后，Kimi Linear 保持第一；RL 阶段 Kimi Linear 收敛更快更高。
- **效率**（batch=1）：prefill 在 ≥128k 后拉开差距；decode TPOT 全程低于 MLA 且随长度稳定。

## §6 局限

- 结论基于 48B-A3B 规模与 Moonlight 式架构，更大规模外推未验证（作者自认更细致调参可获更好 scaling 曲线）。
- 少数基准仍落后：EvalPlus（60.2 vs GDN-H 63.1）、MATH500 SFT（81.2 vs MLA 80.8/GDN-H 83.0）、LongBench V2 与 Frames 未夺魁。
- MRCR@1M（Table 3 口径）等极端检索仍是线性注意力短板，需靠 25% 全注意力层兜底。
- 1.16× scaling law 优势幅度温和，且为拟合外推。
- 5.7T 最终版与 1.4T 实验版的训练配置不同（token 数不同），公开对比需注意口径差异。
