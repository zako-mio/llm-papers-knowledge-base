## §3 关键数字
以下数字均转引自论文摘要/正文：

**模型规模与扩展（转引自摘要）**
- 训练超 **100B 参数** 模型，在 **400 GPUs** 上获得超线性加速
- 达到 **15 Petaflops** 吞吐
- 相比 SOTA：**模型规模 8x 提升**、**可实现性能 10x 提升**
- 无需模型并行即可训练高达 **13B 参数**（超过 Megatron GPT 8.3B 与 T5 11B）
- 支撑创建当时世界最大语言模型 **Turing-NLG，17B 参数**（打破记录准确率）

**显存优化三阶段（转引自正文核心机制）**
- **ZeRO-1（优化器状态分片）**：将优化器状态（Adam：fp32 master weights + m + v，约占训练显存的 40% 以上）分片到 N 个设备，显存随 N**线性下降**
- **ZeRO-2（梯度分片）**：在 ZeRO-1 基础上进一步将梯度张量分片（约再降 20% 显存）
- **ZeRO-3（参数分片）**：在 ZeRO-2 基础上将模型参数本身分片（合计仅保留每设备一份），实现「可用显存随维数线性扩展」，理论支撑 **1 万亿参数**

**显存分解比例（转引自正文，训练大模型典型分布）**
- 在一次典型训练中，显存消耗主要成分（约）：**模型参数 与 梯度** 各占若干、**优化器状态占比最大（≤40%+）**、激活值按需
- 三者分片后，ZeRO 对比标准数据并行（DDP）的内存冗余大幅消除

<summary>补充说明（来源标注）</summary>
> 「优化器状态占比约 40%+」「梯度/参数各占约 20%」等数值是论文对典型大规模训练（如 Adam 优化器 + 混合精度 + 激活重计算）显存构成的经验拆分。精确的显存公式（每设备 = 参数 + 梯度 + 优化器状态，各随分片数 N 线性下降 1/N）是 ZeRO 的核心数学基础，01-深度解读报告会在「概念内核」节给出完整推导。
