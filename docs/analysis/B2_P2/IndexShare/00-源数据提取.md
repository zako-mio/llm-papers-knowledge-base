## §4 方法细节

**问题背景**：DSA 用轻量 lightning indexer（多头 ReLU 门控点积 + FP8 + 低秩，每 FLOP 成本比 MLA 低一个量级）对全部前文打分选 top-k（k=2048），将核心注意力由 O(L²) 降至 O(Lk)；但 indexer 自身仍需在每层独立运行，总成本 O(NL) 随上下文二次增长，且 profiling 显示其在 prefill 中占比随长度急剧上升。

**核心机制**：将 N 层划分为 F（Full，保留自己的 indexer）与 S（Shared，复用最近前置 F 层缓存的 top-k 索引，即 T←T_f(ℓ)，f(ℓ)=max{j<ℓ:c=F}）。推理循环只增加一个条件分支；缓存仅是覆盖式临时张量，**无额外显存开销**。首层恒为 F。

**Training-free Index Cache**（§3.1）：
- 均匀交错（每 r 层留一个 indexer）次优——网络早期/过渡区某些层对 indexer 移除远比其他层敏感。
- Greedy 层选择（Algorithm 1）：从全 F 出发，每步试探将某 F 层翻转为 S，取校准集 LM loss 最小者提交，共 K 步（如 K=3N/4）。流水线并行下按 P 个 stage 分块可将前向次数减少约 P×。
- 经验性质：搜出的模式显著优于同保留率 uniform；loss 曲线区分"easy 层"（前 20 步）与"critical 层"（35 步后）；结果对校准集稳定。
- 负结果（Appendix C）：基于注意力输出相似度/top-k 重叠度的 DP 精确搜索效果与 uniform 相当——局部相似度指标无法预测扰动级联，必须端到端 loss 评估。

**Training-aware Index Cache**（§3.2）：
- 多层蒸馏损失：L_multi = Σ_j KL(p_t^(ℓ+j) ‖ q_t^(ℓ))，令每个保留 indexer 对其服务的 m+1 层联合负责。
- Proposition 1：该损失梯度等价于对各服务层注意力分布取平均后的单目标蒸馏（蒸馏到"质心"分布），非启发式正则。
- 两阶段训练沿用 DSA 流程：warm-up 只训 indexer（冻结其余参数），sparse phase 联合训练并加 LM loss。
- 关键发现：训练后模型会主动适应共享——uniform 模式即可追平甚至超过搜索模式（51.6 vs 50.6），层特异性敏感性完全消失。

**跨层重叠度实证（Appendix A）**：对 47 层 30B DSA 模型在 200K 校准集（768 样本）上计算所有层对的 top-k 索引重叠率 |T⁽ⁱ⁾∩T⁽ʲ⁾|/k，热力图呈现四个规律：①对角线附近高重叠——相邻层重叠 0.7–1.0；②块状结构——模型组织为功能块（如层 3–5、6–8、17–30、31–36），块内选择高度一致；③不均匀衰减——跨界处重叠骤降，少数"过渡层"大幅转移注意力焦点；④早晚层分化——热力图左下/右上角明显暗淡（≤0.4），早期与晚期层关注根本不同的 token 子集。另发现 greedy 搜索的共享块与自然重叠簇并不完全重合：重叠是聚合指标，只计共享数量不计哪些 token 不同，冻结权重下少量错配关键 token 即可级联放大，故必须端到端 loss 搜索。

**搜索到的模式示例（Appendix B）**：GLM-4.7-Flash 30B 保留 1/4 时为 `FSFSFSSSSFSSSFSSFFSSFSSFS SSSFSSSFSSSSFSSSSSSSSS` 形式的 F/S 串——可见 F 层并非严格周期分布，且前段密后段疏（深层更可共享）。

## §5 实验结果要点

- **实验底座**：以 GLM-4.7-Flash（30B-A3B MoE、MLA、47 层）为基座做两阶段 DSA 化训练（1000 步 dense warm-up + 4000 步 sparse training，SFT 数据、200K 上下文）。
- **评测套件**：长上下文 5 项（MRCR v2、GraphWalks、LongBench v2、RULER、AA-LCR）+ 通用推理 4 项（AIME2025、GPQA-Diamond、LiveCodeBench v6、IFBench）。
- **部署测量**：SGLang + dp attention（dp=8），单节点 H100；报告 prefill TTFT、单并发 decode 吞吐、KV 打满总吞吐三视角。
- **结论链**：①保留哪些 indexer 比保留多少更关键（training-free 下）；②重训后"怎么分"不再敏感（training-aware 下）；③跨层蒸馏贡献实质增益（消融 −1.8 Long Avg）。
- **规模化验证**：GLM-5 上趋势一致，1/2 保留 Long Avg 78.1≈基线 78.4，searched pattern 78.7 略超；ArtificialAnalysis Index 全测与原 GLM-5 几乎无差。

## §6 局限

1. **极限稀疏退化**：1/8 保留率即使配合搜索仍明显损伤长上下文能力（Long Avg 46.1 vs 50.2），方法的安全稀疏边界约在 75% 移除以内。
2. **Training-free 对关键层脆弱**：权重冻结下少量错配的关键 token 即可沿深层传播放大；greedy 搜索计算不便宜（全搜需 N(N−1)/2 次前向，虽可并行化 P×）。
3. **局部相似度代理失效**：无法用更便宜的相似度指标替代端到端 loss 搜索（Appendix C 负结果），限制模式的快速求解。
4. **GLM-5 上尚未应用 training-aware 变体**（作者称"近期计划"），生产级模型的进一步收益待验证。
5. 方法前提是"动态 token 选择型"稀疏注意力；对固定稀疏模式的方法不直接适用（作者指出可推广至 MoBA/NSA 类块选择，但未实验）。
