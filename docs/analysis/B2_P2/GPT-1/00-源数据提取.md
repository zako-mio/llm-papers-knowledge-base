## §4 方法细节

### 4.1 两阶段框架（§3, p.3）

**阶段一：无监督预训练（L₁）**
标准语言建模目标，最大化上下文窗口 k 内的条件似然：

```
L₁(U) = Σᵢ log P(uᵢ | u_{i−k},…,u_{i−1}; Θ)
```

- 骨干：multi-layer **Transformer decoder**（引 Liu et al.[34] 的 variant，源自 Vaswani et al.[62]）
- 计算：token embedding Wₑ + position embedding Wₚ → 逐层 transformer block（multi-headed self-attention + position-wise FFN）→ softmax(h·Wₜ)

**阶段二：监督微调（L₂ 与 L₃）**

```
P(y|x¹,…,x^m) = softmax(h_l^m · W_y)
L₂(C) = Σ log P(y|x¹,…,x^m)
L₃(C) = L₂(C) + λ·L₁(C)     （λ=0.5）
```

- 新增参数仅为线性输出层 W_y 与分隔符 embedding——**迁移时架构改动最小化**是全文卖点
- 辅助 LM 目标的作用：(a) 改善监督模型泛化 (b) 加速收敛（消融见 §5）

### 4.2 任务特定输入变换（§3.3, p.4, Figure 1）

traversal-style 思路[52]：把结构化输入拍平成单一连续 token 序列，统一走 linear+softmax 头：

| 任务类型 | 变换方式 |
|---|---|
| Textual Entailment | premise p 与 hypothesis h 用分隔符 `$` 拼接：`⟨s⟩ p $ h ⟨e⟩` |
| Similarity | 两种句序各拼一份（`$` 分隔），分别过模型得到两个 h_l，**element-wise 相加**后进输出层 |
| QA / Commonsense Reasoning | `[z; q; $; a_k]`（文档z+问题q+每个候选答案a_k），每条独立前向，softmax 归一化选答案 |
| 分类（SST-2 等） | 直接 `⟨s⟩ text ⟨e⟩` 微调 |

所有变换共用随机初始化的 start/end token（⟨s⟩, ⟨e⟩）。

### 4.3 预训练配置（§4.1, p.4–5）

| 项 | 配置 |
|---|---|
| 语料 | **BooksCorpus**[71]：7000+ 本未出版书籍（Adventure/Fantasy/Romance 等体裁）；选择理由=长连续文本利于长程依赖学习；对比 ELMo 所用 1B Word Benchmark 句级打乱、破坏长程结构 |
| 分词 | BPE（byte pair encoding）**40,000 merges**[53]；ftfy 清洗 + spaCy tokenizer |
| 优化器 | Adam，max lr **2.5e-4**；前 2000 updates 线性 warmup，余弦退火至 0 |
| 训练轮次 | **100 epochs**，batch = 64 条 × 512 token 连续序列 |
| 初始化 | N(0, 0.02)（LayerNorm 广泛使用使简单初始化即可） |
| 正则 | residual/embedding/attention dropout 均 0.1；modified L2（Loshchilov & Hutter[37] 式 weight decay）w=0.01（作用于非 bias/gain 权重） |
| 激活函数 | **GELU**[18] |
| 位置编码 | learned position embeddings（弃用原版 sinusoidal） |

### 4.4 微调配置（§4.1, p.5）

- 复用预训练超参，分类器加 dropout 0.1
- lr **6.25e-5**，batch size 32，多数任务 **3 epochs** 即收敛
- 线性 lr decay + warmup 占训练 0.2%
- 辅助目标权重 **λ = 0.5**

### 5.4 迁移深度与零样本（Figure 2, p.7）

- **层数迁移曲线**（MultiNLI/RACE）：仅迁移 embedding 即有提升，逐层叠加单调改善，全 12 层迁移在 MultiNLI 上累计最高 +9% → 预训练每一层都携带可迁移功能
- **Zero-shot 行为学**：四种免微调启发式（CoLA=平均 token log-prob 阈值判决；SST-2=追加 "very" 后比较 positive/negative 概率；RACE=候选答案平均 log-prob 取最大；DPRD/Winograd=代入指代后比较剩余序列 log-prob）性能随预训练更新数**稳定上升**，说明生成式预训练自发习得任务相关功能；同设置下 LSTM 方差显著更大 → Transformer 的 inductive bias 更利迁移

## §6 局限

**论文自陈的局限（原文明确承认）：**
1. **小数据集失守 RTE**：2490 例的 RTE 上 56.0 低于 multi-task biLSTM 的 61.7；作者推测多任务训练可缓解但"we have not explored this currently"（p.5–6）
2. **MRPC 未夺冠**：相似度三集中 MRPC F1 82.3 未超过基线（Table 4/5 对照）
3. **辅助 LM 目标非普适**：消融显示其收益集中于大数据集，小数据集无益甚至略负（p.8）
4. **多任务联合训练未探索**：结论与正文均留白（p.6, p.8）

**结构性局限（由内容合理推断，标注为推断）：**
5. **单向因果注意力**：decoder-only masked self-attention 只看左文，天然弱于双向编码（此缺口正是 ELMo/BERT 双向路线的立论点；BERT 论文随后以双向弥补并在同样 11 项任务上反超）
6. **QA 类推理开销大**：每个候选答案需独立完整前向（`[z;q;$;a_k]` 逐条计算），k 个答案 k 次前向，工程效率低
7. **语料域窄且规模有限**：仅 BooksCorpus 约 7000 本书（≈1GB 级文本），体裁偏小说叙事，后续工作（GPT-2 WebText 等）证明规模与域多样性是继续涨点的第一杠杆
8. **评测口径混杂**：部分结果取自 GLUE leaderboard 口径、部分来自各自数据集文献，ensemble 基线（5x/9x）与单模型混比，跨表可比性有限（论文自己也以脚注声明 5x/9x）

**历史影响锚点（供 B2_P2 综述引用）：**
- 确立 "pre-train once, fine-tune everywhere" 范式与 minimal-architecture-change 迁移原则
- 12 层/768 维/12 头的 GPT-1 规格成为 GPT-2（48 层）扩缩路线的原点
- zero-shot 启发式一节是 GPT-2 "language models are unsupervised multi-task learners" 叙事与 GPT-3 in-context learning 的思想先声
