## §4 方法要点

1. **Thinking Agent 范式**："reasons step by step *while* using tools"——思考与工具调用深度交错，而非先想完再调用。执行 `think → search → browser use → think → code` 动态循环，持续生成/修正假设、验证证据（Agentic Search 节）。
2. **Test-time scaling 双轴扩展**：同时扩展 thinking tokens 与 tool calling steps 两类推理时算力，是官方对能力来源的核心归因（开篇）。
3. **长程自主性**：200–300 顺序工具调用无需人工介入，依赖 long-horizon planning + adaptive reasoning 将模糊开放问题分解为可执行子任务（Agentic Search 节）。
4. **INT4 QAT（Quantization-Aware Training）**：
   - 问题背景：thinking 模型解码长度过长，常规训练后量化（PTQ）损失显著；
   - 方案：post-training 阶段做 QAT，对 **MoE 组件施加 INT4 weight-only 量化**；
   - 效果：原生 INT4 推理，生成速度约 **2x 提升**，且保持 SOTA 性能；
   - 关键披露：**所有基准成绩均在 INT4 精度下报告**（Inference Efficiency 节）。
5. **上下文管理策略**：工具结果累积超 256k 上限时，隐藏全部历史工具输出（Footnote 4.e）。
6. **Heavy Mode**：8 条轨迹并行 rollout + 反思式聚合（区别于单轨迹长思考）（Footnote 6）。

## §5 评测结果要点

- **协议透明度高**（Footnote 2/4/5）：temperature=1.0（SciCode 除外，按官方用 0.0）；AIME/HMMT 无工具 avg@32、带 Python avg@16、IMO-AnswerBench avg@8；BrowseComp-ZH/Seal-0/FinSearchComp-T3 avg@4；编码任务 5 次独立运行取平均。
- **裁判模型**：o3-mini 作 judge，配置与提示词逐字沿用 HLE 官方仓库（Footnote 4.c）。
- **防泄漏措施**：测试时封锁 Hugging Face 访问（否则 HLE 可刷至 51.3）；CoQA 式重叠风险被显式管理（Footnote 4.f）。
- **基线纪律**：GPT-5/Claude/Grok-4/DeepSeek-V3.2 分数优先引用各家官方发布（GPT-5 posts/system card、claude-sonnet-4-5、grok-4、deepseek-v3.2 news）；无公开分的基准由官方同条件重测并加 \* 号；GPT-5 统一设 reasoning effort = high（Footnote 3.a）。
- **HLE 口径澄清**（Footnote 3.b）：GPT-5 全集 w/ tools 官方 35.2、Grok-4 38.6；text-only 子集内部重测 GPT-5 41.7、Grok-4 38.6（Grok-4 发布稿曾称 text-only 41.0）；GPT-5 全集无工具 24.8（引 Scale.ai 榜）。44.9 的对比口径是 text-only 子集 w/ tools。
- **IMO-AnswerBench 口径**（Footnote 3.c）：基准论文中 GPT-5 为 65.6，官方 API 重测得 76——博客选择自测值 76 作为对比项。
- **优势面**：agentic search 全面领先（BrowseComp/Frames/Seal-0/FinSearchComp-T3 四项第一或并列第一）；数学竞赛类（IMO-AnswerBench 78.6 第一）；相对自家前代 K2 0905 提升幅度巨大（BrowseComp 7.4→60.2，HLE 21.7→44.9）。
- **非优势面**：SWE-bench Verified、LiveCodeBench、OJ-Bench、Terminal-Bench、HealthBench、Longform Writing、MMLU-Pro/Redux、GPQA-Diamond 均不敌 GPT-5 (High) 或 Claude Sonnet 4.5 (Thinking) 中至少一家；BrowseComp-ZH 微弱落后 GPT-5（62.3 vs 63）。
- **通用能力定性评估**：创意写作（意象联想更深）、实用写作（指令遵循更系统）、个人情感（共情与可执行建议）三类有主观提升描述，未附量化分数。

## §6 局限与未披露项

**博客文本明示的限制**
- kimi.com chat mode 为快速体验刻意裁剪了工具子集与调用轮数，**聊天端表现不能复现榜单成绩**；完整 agentic mode 当时未上线（Footnote 1）。
- 编码类多项成绩落后 Claude Sonnet 4.5 (Thinking)（SWE-bench Verified 71.3 vs 77.2、Terminal-Bench 47.1 vs 51.0、Multi-SWE-bench 41.9 vs 44.3）与 GPT-5 (High)（LiveCodeBench 83.1 vs 87.0、OJ-Bench 48.7 vs 56.2）。
- 纯知识型基准（MMLU-Pro/Redux、GPQA-Diamond）无领先优势，定位差异明确——强项在 agentic 场景而非静态知识。
