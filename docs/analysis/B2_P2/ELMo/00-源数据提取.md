核心机制：ELMo 是对 biLM 全部内部层加权和的函数，`ELMo_k = γ Σ s_j h_{k,j}`,其中 `s_j` 为 softmax 归一化权重、γ 为标量缩放、h 含 token 层 + 前向/后向每层拼接，共 2L+1 个表示。

# §4 方法细节

- **双向语言模型 (biLM)**：前向 LM 由序列起始预测下一 token，后向 LM 反向预测前一 token，联合最大化两者似然（式 p(t)=∏p(t_k|t_1:t_{k-1})·p(t_k|t_{k+1}:t_N)）。
- **每 token 的表示集合**：`R_k = {x_k, h_{k,j}^{fwd}, h_{k,j}^{bwd} | j=1..L}`，其中 x_k 为 token 层（卷积字符 CNN + highway 输出），h 为每层 biLSTM 前/后向拼接。
- **ELMo 融合公式**：下游任务对全部 biLM 层做任务特定加权 `ELMo_k = γ Σ_j s_j^task h_{k,j}^LM + δ`（论文式(1)），而非只取顶层 LSTM。
- **下游集成**：将 ELMo 向量与 x_k 拼接成 `[x_k; ELMo_k]` 送入任务 RNN；部分任务（SNLI、SQuAD）还在任务 RNN 输出端再拼一次（`[h_k; ELMo_k]`，引入另一组输出专用线性权重）；其余监督模型不变。
- **自监督信号分层**：高层 LSTM 状态捕捉上下文依赖的词义（可用于无修改的词义消歧），低层状态建模句法（可用于 POS 标注）；暴露全部层让下游模型自行挑选最有效的半监督信号。
- **正则化**：对 ELMo 权重加 dropout，并对权重加 `λ‖w‖²` 损失，形成逼近所有 biLM 层平均的归纳偏置。
- **预训练模型**：双向联合训练 + 层间残差连接；为平衡困惑度与计算量，将单一最强模型 CNN-BIG-LSTM 的嵌入与隐藏维全部减半；最终 L=2、每层 4096 单元、512 投影。
- **任务计算细节**：见表注，性能指标随任务不同——accuracy（SNLI/SST-5）、F1（SQuAD/SRL/NER）、平均 F1（Coref）；NER 与 SST-5 因测试集小，报告 5 个随机种子的均值±标准差。

# §5 实验结果要点

- **普适性**：在六类异构任务与架构（QA、推理、SRL、共指、NER、情感）上，仅添加 ELMo 即全部刷新 SOTA，相对误差降低 6%-20%，是「跨架构、跨任务」的普遍结果。
- **SQuAD**：基线 81.1 → +ELMo 85.8（+4.7 绝对 / 24.9% 相对），刷新单模型 SOTA；11 成员集成达 87.4。相比同一基线加 CoVe 仅 +1.8%，ELMo 优势显著。
- **样本外覆盖**：因纯字符输入，能对训练集外 token（含 OOV）提供表示，优于固定词表词嵌入。

**§5 分析（Ablation）要点**

- **用全部层 vs 仅顶层（§5.1，Table 2）**：对比 SQuAD/SNLI/SRL 的 LastOnly（仅顶层）/ λ=1（平均全部层）/ λ=0.001（允许学层权重）。SQuAD 仅顶层改善 dev F1 3.9%（80.8→84.7）；平均全部层再 +0.3%（→85.0）；允许学层权重再 +0.2%（→85.2）。SNLI 88.1→88.9→89.3→89.5；SRL 81.6→84.1→84.6→84.8。结论：深层内部状态优于仅顶层，且允许学层权重（λ 较小）最优。
- **ELMo 注入位置（§5.2，Table 3）**：input-only / input+output / output-only 三处。SQuAD 85.1/85.6/84.8、SNLI 88.9/89.5/88.7、SRL 84.7/84.3/80.9——SNLI、SQuAD 含 attention 层，输出端也注入 ELMo 有益（模型可直接 attend biLM 内部表示）；SRL/coref 仅在输入端注入最稳。
- **句法 vs 语义分层（§5.3）**：内在评测显示低层 LSTM 状态更擅句法（POS 标注），高层状态捕获上下文词义——WordNet 1st sense 基线 65.9；GloVe 对 "play" 的最近邻是词形近邻（game/games/played），而 biLM 呈上下文语义近邻（"signed to do a Broadway play"等），与 MT 编码器观察一致。
- **与 CoVe 对比**：ELMo 综合表示比 CoVe 更丰富；BCN 模型用 ELMo 替代 CoVe 得 1.0% 绝对准确率提升，刷新 SST-5 SOTA。
- **训练集规模敏感性（§5.4）**：小训练集任务（如 NER）对 λ 不敏感；低资源场景下预训练 ELMo 的数据效率收益更明显。

# §6 局限

- **规模开销**：需预训练大型双向 LSTM 语言模型并维护其内部状态，推理和存储成本高于轻量词向量；文中未给出精细效率对比。
- **任务特定加权依赖**：需要为每个下游任务学习融合权重 s_j^task 与缩放 γ，引入额外参数与调参成本。
- **仍是「词表示」而非端到端预训练模型**：ELMo 作为表示注入现有架构，未像后来 BERT/T5 那样预训练并微调全部参数，覆盖语言理解能力相对有限。
- **单语言/单语料**：基于 1B Word Benchmark 英文语料，跨语言泛化未在原文充分实验。
- **评测歧义**：部分任务（NER/SST-5）测试集小，需报均值±标准差；GLUE/SuperGLUE 等统一基准尚未出现（该文早于 GLUE 成熟期），跨论文直接可比性有局限。
