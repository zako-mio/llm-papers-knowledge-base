## §3 核心主张与关键数字表

**核心主张**: 直接对图像块序列应用标准 Transformer（不依赖 CNN 的归纳偏置），当在大规模数据上预训练后，ViT 在现代图像识别基准上达到或超越 CNN 最优效果，且计算成本显著更低。

## §4 方法细节

- **输入处理**: 图像 x∈R^(H×W×C) 切分为扁平化 2D 块 xp∈R^(N×(P²·C))，N=HW/P² 为 effective 序列长度；块经可训练线性投影 E∈R^((P²·C)×D) 映射到统一隐向量 D。
- **Transformer 结构**: 标准 Vaswani 编码器，交替 MSA 与 MLP 块（MLP 含 GELU 非线性、两层）；每个块前用 LayerNorm，块后残差。
- **分类 token**: 类似 BERT 的 [class] token z0_0=x_class，编码器输出 z0_L 作为图像表示 y（Eq. 4）；预训练时分类头为一隐层 MLP，微调时为单线性层。
- **位置嵌入**: 采用标准可学习 1D 位置嵌入（未观察到更复杂 2D-aware 嵌入的显著收益，见 Appendix D.4）。
- **归纳偏置**: ViT 的图像相关归纳偏置远少于 CNN——仅 MLP 层局部且平移等变，attention 层全局；2D 邻域结构仅在切块与微调分辨率调整时少量使用。
- **混合架构**: 输入序列可由 CNN 特征图形成（patch embedding 投影 E 施加于 CNN 特征图的块）；特例 1x1 空间尺寸即直接展平特征图。
- **微调与高分辨率**: 微调移除预训练预测头，接零初始化 D×K 前馈层（K 为下游类数）；常在高分辨率微调（比预训更高），保持块大小不变导致更长有效序列；对预训练位置嵌入按其原图位置做 2D 插值。
- **训练**: 全部用 Adam（β1=0.9, β2=0.999），batch size 4096，高权重衰减 0.1；线性 LR warmup 与 decay。微调用带 momentum 的 SGD，batch 512。ImageNet 微调分辨率 512 (ViT-L/16) / 518 (ViT-H/14)。
- **基线 CNN**: ResNet（BN 换 GroupNorm，标准化卷积 → "ResNet (BiT)"）与混合模型。
- **度量**: fine-tuning accuracy 为主；few-shot 用正则化最小二乘回归（线性 few-shot，闭式解）用于快评。

## §5 实验结果要点

1. **SOTA 对比**（Table 2, P6）: ViT-H/14（JFT 预训练）在全部数据集上超越 BiT-L（同数据集预训练），且算力 2.5k vs 9.9k TPUv3-core-days；ViT-L/16（JFT）也优于 BiT-L。ViT-L/16（ImageNet-21k 预训练，27.9k... 实际 0.23k days）也能在多数数据集表现好，用标准云 TPUv3 8核约 30 天可训练。
2. **VTAB 分解**（Fig 2, P6）: ViT-H/14 在 Natural 与 Structured 任务组超越 BiT-R152x4 等方法；Specialized 组前两名相近。
3. **预训练数据需求**（§4.3, Fig 3&4）: 小数据集（ImageNet）下大 ViT（Large）反不如 Base；ImageNet-21k 时相近；仅 JFT-300M 才见大模型全部收益。ViT 比 ResNet 在更小数据集时过拟合更严重，但数据集变大后超越（图 4 线性 few-shot）。
4. **缩放研究**（§4.4, Fig 5）: ViT 在性能/算力权衡上全面占优（平均省 2-4× 算力）；混合架构在小算力下略优于纯 ViT，但差距在大模型下消失；ViT 在所测范围内未见饱和——暗示可继续扩展。
5. **注意力可解释性**（§4.5, Fig 7）: 第一层投影学到的滤波器类似低频基函数；位置嵌入学到相似性与图像内距离相关（同行/同列接近，有时出现正弦结构）；部分 head 在最底层即关注全图（全局整合），其他 head 低层保持局部（类似 CNN 早期卷积），attention 距离随深度增加。
6. **自监督**（§4.6）: 掩码块预测预训练下，ViT-B/16 达 ImageNet 79.9%，比从头训练提升 2%，但仍落后监督预训练 4%；对比预训练留作未来工作。

## §6 局限

- 未在检测/分割等下游任务验证（仅分类）；作者在结论中列为挑战。
- 自监督与大规模监督预训练之间仍有较大差距（4%）。
- 小数据下 Transformer 缺乏 CNN 归纳偏置导致过拟合，需要大量数据或强正则；"large scale training trumps inductive bias" 依赖数据规模。
- 作者指出预训练效率不仅受架构影响，还受训练 schedule、优化器、权重衰减等参数影响（说明计算对比并非完全受控）。
