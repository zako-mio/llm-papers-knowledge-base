## §4 方法要点

1. **RSP 分级发布决策流程**（§1.2）：训练过程中对多个快照做迭代式灾难风险能力评测（helpful/honest/harmless 快照并行测试），按自主性与 CBRN 两大域分别对照 ASL 阈值，最终由 RSO + CEO 裁定 ASL-3 部署。
2. **ASL-4 rule-out 判定方法**（§1.2.4.1）：基准任务分数接近 ASL-4 排除阈值时不机械判定，而是引入内部重度用户调研（长时程复杂任务的真实表现）与定性评估联合裁决——体现了从"单点基准"向"基准+实地证据"组合判定的方法论转变。
3. **effort 参数**（§1.1.2）：将 extended thinking 预算暴露为用户可控旋钮，绘制 accuracy-vs-output-tokens 的 Pareto 前沿（Figure 1.1.2.A），使同一模型可服务高智能与低成本两种场景。
4. **评测去污染**（§2.2）：对能力评测执行 decontamination 流程后再报告分数。
5. **自动化行为审计**（§6.2）：以 metrics 化的行为审计 + 自主后续调查（autonomous follow-up investigations）+ 外部 Petri 工具对比，覆盖 sycophancy、deception-by-omission、sandbagging、codebase sabotage 等对齐风险面。
6. **可解释性介入的对齐调查**（§6.4.2）：对"省略型欺骗"用 feature activation monitoring 与 non-assistant persona sampling 做机制层归因，而非仅停留在行为层。
7. **CBRN 评估矩阵**（§7.2)：长程病毒学任务、多模态病毒学、DNA 合成筛查规避、LAB-Bench 子集、创意生物学、短时程计算生物任务、生物信息学评测，外加 ASL-4 virology uplift trial 与专家红队。
8. **Agentic 安全面**（§5）：针对 Claude Code 滥用、computer use 恶意操作、跨 surface（coding/browser/computer use）自适应攻击者的 prompt injection 鲁棒性测试。

## §5 评测结果要点

- **编码/Agent 主场优势显著**：SWE-bench Verified 80.9%、Terminal-Bench 2.0 59.3%、τ²-Bench Telecom 98.2%、MCP Atlas 62.3%（领先第二名 18+ 个百分点）、OSWorld 66.3%，构成"agentic SOTA"叙事的核心证据链。
- **流体智力基准**：ARC-AGI-1 80.0% / ARC-AGI-2 37.6%（均排除 deep-thinking 模型的 SOTA），且 ARC-AGI-2 无针对性训练，被用作泛化推理能力的证据。
- **知识/科学类非全面领先**：GPQA Diamond 87.0% 低于 Gemini 3 Pro 91.9%；HLE 亦非第一——卡片如实呈现了能力短板维度。
- **安全侧量化基调**：错位行为率"低于近期任何前沿模型"、过度拒绝率不升、sabotage/sandbagging/reward hacking 各专项均给出与前代模型的对照。
- **自主性临界信号**：SWE-bench Verified hard subset 与两个内部 AI research suite（Kernels、时间序列预测、文本 RL、LLM 训练、四足 RL、新编译器共 6 类任务）用于逼近 ASL-4 自主性阈值判断，是 RSP 评估中最受关注的部分。

## §6 局限与未披露项

1. **未披露架构与训练细节**：无参数量、数据构成、算力规模、训练 FLOPs 等信息（system card 一贯不披露）。
2. **评测自评性质**：绝大多数评测为 Anthropic in-house 运行，第三方仅覆盖少数项目；竞品分数（GPT-5.1、Gemini 3 Pro）为引用值，实验设置未必完全对齐。
3. **SWE-bench Verified "首破 80%" 表述**：卡片本身只报告 80.9% 及对比表 SOTA，未使用"first above 80%"字样；该说法主要见于外部报道与后续第三方榜单语境，引用时应注意口径。
4. **ARC-AGI 半私有分数依赖外部机构**：ARC 成绩由 ARC Prize Foundation 在其私有验证集上报告，Anthropic 无法独立复现细节；且 11-24 Changelog 显示该数字曾因口径问题更正过一次。
5. **ASL-4 rule-out 的判断空间**：自主性维度承认"接近阈值但未触发"，rule-out 依赖用户调研等主观输入，存在解释弹性（卡片自身亦称 required careful judgment）。
6. **快照数量与中间结果不完全公开**：迭代评测的具体快照数、各快照分数曲线未完整披露。
7. **长时程自主任务的覆盖上限**：卡片承认未来模型将能解决所有良定义短时程任务，当前评测对真正 long-horizon 自主性的测量仍有限。
