## §4 方法要点

1. **MoE 稀疏化（首个 MoE 的 Llama 代际）**：每 token 仅激活部分参数。Maverick 采用 dense/MoE 层交替布局，MoE 层含 128 routed expert + 1 shared expert；每 token 命中 shared + 1 个 routed expert，全部参数驻留内存但只激活子集，降低服务成本与延迟。（出处：官方博客 Pre-training 节）
2. **iRoPE 长上下文架构**：多数层用旋转位置编码（RoPE），交错插入无位置嵌入（NoPE 式）的全局注意力层；配合推理时注意力温度缩放实现长度外推。vLLM 侧披露实现为 1:3 的"无 RoPE 全局注意力 : 带 RoPE 分块局部注意力"，局部层用非重叠 chunk 控制 Attention 二次复杂度。（出处：官方博客；vLLM 博客）
3. **Mid-training 两阶段范式**：预训练后追加"mid-training"，用专门长上下文扩展数据集同时提升核心能力并解锁 Scout 10M 输入上下文——将长上下文能力显式做成独立训练阶段而非纯外推技巧。（出处：官方博客）
4. **原生多模态 early fusion**：文本与视觉 token 在统一骨干联合预训练（可用大量无标注文本/图像/视频）；vision encoder 基于 MetaCLIP、与冻结 LLM 联训适配。支持多图输入的时序活动理解。（出处：官方博客）
5. **MetaP 超参迁移技术**：可靠设定逐层学习率与初始化尺度，且跨 batch size/宽度/深度/token 数良好迁移——服务大规模稀疏模型的超参搜索成本压缩。（出处：官方博客）
6. **后训练配方重构**：放弃重 SFT + DPO 路线，改为 lightweight SFT → online RL → lightweight DPO；核心洞察是过强 SFT/DPO 会过度约束策略、抑制 online RL 阶段探索（尤其推理/编码/数学域）。配套手段：以 Llama 作 judge 剔除 >50% 简单数据、连续在线 RL 交替训练与难度筛选、轻量 DPO 处理回复质量边角案例。（出处：官方博客 Post-training 节）
7. **Codistillation 蒸馏**：以 Behemoth 为教师对 Maverick 做预训练期共蒸馏；新蒸馏损失动态加权 soft/hard target；教师前向开销通过对多数训练数据的摊销控制，增量新数据才现算 target。（出处：官方博客 Behemoth 节）
8. **超大模型 RL 工程**：2T 参数级 RL 重写基建——MoE 并行设计优化 + 全异步在线 RL 框架 + 模型按算力灵活分配到独立 GPU，训练效率较上一代约 10x；RL 配方含 pass@k 难度采样、零优势 prompt 动态过滤、多能力混批、多样 system instruction 采样。（出处：官方博客）
9. **安全体系**：三层纵深（预训练数据过滤 / 后训练安全数据 / 系统级 Llama Guard·Prompt Guard·Code Shield）；GOAT（Generative Offensive Agent Testing）自动化红队模拟中等攻击者多轮交互；CBRNE、儿童安全、网络攻击助益三大重点风险专项评估。（出处：Model Card Safeguards 节；官方博客）

## §6 局限与未披露项

**官方明示的局限（Model Card Considerations / Out-of-scope）：**
1. 输出不可预测：测试无法覆盖所有场景，可能产出不准确或不良响应；部署前需针对具体应用做安全测试与调优。
2. 图像理解仅在 ≤5 张输入图下测试；超出需开发者自担风险缓解与额外测试。
3. 12 种官方支持语言之外的语言使用由开发者负责安全合规（预训练虽覆盖 200 语言）。
4. 静态离线模型：知识截止 2024-08，无内置联网/记忆更新机制。
5. 许可限制：违反法律/AUP/License 的用途禁止；非 OSI 开源。

**未披露项（截至发布材料）：**
1. 无完整技术报告论文：MoE 路由细节（top-k 之外的负载均衡损失、router 类型）、专家容量因子、chunked attention 具体窗口尺寸等均未给出。
2. iRoPE 仅给原理性描述（NoPE 层比例、温度缩放公式未公开；1:3 比例来自 vLLM 博客而非 Meta 官方文档）。
3. 数据配比：文本/图像/视频具体混合比例、去重与清洗流程、图像与视频 token 化方案未披露。
4. Behemoth：发布时仍在训练，最终规格/成绩/权重均未定；后续亦未公开发布（第三方 2026 年综述确认权重始终未放出）。
5. MetaP、codistillation 损失函数只有概念描述，无公式与消融。
6. 评测口径风险：LMArena ELO 1417 出自"experimental chat version"（与最终发布版不同），该实验版本号/差异未公开，成为后续社区争议焦点。
7. 训练集群总规模（GPU 总数）、训练时长、总电耗仅以 Scout/Maverick 合计 7.38M H100 GPU 时披露，Behemoth 未披露。
