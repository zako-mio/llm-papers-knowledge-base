## §4 方法细节

### 数据（§3.1）
- 语料知识截至 2023 年底，多数据源。
- **Web 清洗**：PII/安全过滤、自定义 HTML parser（数学/代码内容保留结构、保留 image alt 文本）、去除 markdown（对 web 数据有害）、去重（URL 级 + 全局 MinHash 文档级 + line 级，line>6 次/桶内删除）、启发式（n-gram 重复覆盖率、dirty word 计数、token 分布 KL 散度）、模型质量过滤器（fasttext Wikipedia 引用分类器 + Llama 2 训练的 DistilRoberta）。
- **代码/推理数据**：DistilRoberta 分类器（数学推理、STEM、代码与自然语言交错），领域定制 HTML 提取。
- **多语**：fasttext 语言识别分 176 语言；语言内去重；多语 Llama 2 分类器排序。
- **data mix**：知识分类器降采样 web 过采样类别；scaling law 实验选 mix。

### 模型架构（§3.2）
- 标准 dense Transformer，相对 Llama/Llama 2 改动：① GQA 8 KV heads（提升推理、减 KV cache）；② attention mask 防止同序列内不同文档间 self-attention（对超长序列续训很重要）；③ 128K 词汇表；④ RoPE base=500,000。
- 各尺寸：8B=32 层/4096/14336 FFN/32 头；70B=80 层/8192/28672/64 头；405B=126 层/16384/53248/128 头。KV heads 皆 8，激活 SwiGLU。
- 405B 按 scaling law 近似 compute-optimal（针对 3.8e25 FLOPs）。

### 预训练配方（§3.4）
- 三阶段：初始预训练 → 长上下文预训练 → annealing。
- 训练中动态调整 data mix（提升非英语占比、上采样数学、近期 web 数据推进知识截止、下采样低质子集）。
- 长上下文：递增增量（6 阶段 8K→128K），成功判据 = 短上下文评估完全恢复 + 完美解到该长度的 needle-in-haystack。
- annealing 后取 checkpoint 平均（Polyak）。

### 后训练（§4）
- 每轮：SFT + DPO（人类标注或合成数据采集）；未见别用复杂 RL（PPO）因 DPO 在大模型上计算更省、性能更好（尤其 IFEval）。
- **Reward model**：去掉 Llama 2 的 margin term；三级偏好（edited > chosen > rejected）；提示+多响应拼单行训练。
- **SFT**：用 RM 做 rejection sampling；交叉熵只算 target tokens。
- **DPO 改进**：① mask 掉格式化/终止 token 稳定训练；② 加 NLL loss（系数 0.2）稳定。
- **Model averaging**：各阶段平均。

### 推理（§6）
- 405B BF16 单机 8×H100 放不下 → 16 GPU（2 机）并行，机内 NVLink 用 tensor parallelism、跨机用 pipeline parallelism；micro-batching 提吞吐。
- **FP8**：量化 FFN 层（约 50% 推理计算量），不量化 self-attention 层；动态 scaling factor；首尾层不量化；高 perplexity token（如日期）避开量化。

### 多模态（§8）
- 组合式（compositional）集成 image/video/speech，尚在开发未发布；图像任务可比 Gemini 1.0 Ultra 与 GPT-4 Vision。

## §5 实验结果要点

### Table 2（旗舰 405B 关键基准）
- General：MMLU 5-shot 87.3、MMLU 0-shot CoT 88.6、MMLU-Pro 73.3、IFEval 88.6。
- Code：HumanEval 0-shot 89.0、MBPP EvalPlus 88.6。
- Math：GSM8K 8-shot CoT 96.8。
- 对比：旗舰与 GPT-4(0125) 相当，接近 SOTA；小模型（8B/70B）为同规模 best-in-class。

### 人类评估（Figure 17）
- 405B 与 GPT-4(0125) 胜率在误差范围内相当；multiturn reasoning/coding 胜过 GPT-4；multilingual（Hindi/Spanish/Portuguese）不及 GPT-4；与 GPT-4o 英文相当，与 Claude 3.5 Sonnet 多语相当、超其单/多轮英文，但 coding/reasoning 落后。
- 结论：可公开获得的最佳模型。

### 安全（§5.4）
- 发布 Llama Guard 3（输入/输出安全）与 Prompt Guard（Table 28：jailbreaks TPR 99.9%/FPR 0.4%，AUC 0.997）。

## §6 局限

1. **组织上防污染**：预训练数据由独立团队采购处理（防止与外部 benchmark 污染）；人类评估仅限少数不参与模型开发的研究者（说明数据管线很关键）。
2. **残余安全风险**：仍可能生成有害内容（尤其英文以外语言 + 熟练红队对抗提示）；恶意开发者可能找出新 jailbreak；无法保证测试穷尽。
3. **多模态未发布**：image/video/speech 模型仍在开发中，未就绪发布。
4. **人类评估主观性**：人类评估受标注者个人偏好/背景影响，可能不一致不可靠。
5. **架构选择保守**：选择 dense Transformer 与简单后训练（SFT/RS/DPO）以最大化训练稳定性，牺牲了 MoE/复杂 RL 的潜在收益（明示探索过更复杂架构但收益未超复杂度）。
