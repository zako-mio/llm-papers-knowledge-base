## §4 方法细节

**替代解释的三因子分解（§2 末，p4）：**
1. 研究者选择了会**非线性或不连续地缩放 per-token error rate** 的指标；
2. 小参数区的**测量分辨率不足**（分辨率 = 1/测试集大小），导致小模型显得完全无能；
3. 大参数区**采样不足**。

**数学模型链条：**
- 假设每 token cross-entropy 按神经 scaling law 幂律下降：`L_CE(N) = c·N^α`（c>0, α<0）；作者强调此形式仅为示意，非必需；
- 单 token 正确概率 `exp(-L_CE(N))` 平滑趋近 1；
- 若指标要求 L 个 token 全部正确（如多位加法的 Exact String Match/Accuracy），独立假设下 `Accuracy(N) ≈ exp[-(N/c)^α]^(L num. of tokens)`——线性-对数坐标上即呈现陡峭"涌现"；
- 换 TokenEditDistance（per-token 误差随目标长度近线性缩放）或 Brier Score（连续 proper scoring rule）后曲线恢复平滑。

**三条实证路径（互为补充）：**
1. **GPT-3 族算术再测**：固定模型输出不变，仅改评分函数与样本量（2-shot prompt，公开 API 逐规模采样）；
2. **BIG-Bench 元分析**：用 Srivastava et al. 的 Emergence Score（Eqn 1，基于相邻尺度最大增益与中位增益之比）筛查 39 个首选指标 × 任务 × 模型族三元组；再用人工标注数据交叉验证；LaMDA 因输出公开而成为换指标个案对象；
3. **视觉域主动诱导**：自定义不连续指标（Reconstruction_c：重构误差 < c 的样本占比；Omniglot "全对才算 1"的子集准确率），在本来无任何已知能力突变的视觉网络上复现出"涌现"形态。

## §5 实验结果要点

- **算术任务（§3）**：Accuracy 口径下 GPT-3 族在目标长度 4-5 时呈现与 Wei et al./BIG-Bench 报道定性一致的突变曲线；TokenEditDistance 口径下同样这批输出呈平滑改进——证明"涌现存在于指标而非模型输出"；分辨率提升实验进一步表明小模型一直具备高于随机的部分能力；
- **元分析（§4）**：涌现与"特定指标"强相关而非与"特定任务-模型族"相关；多数指标下零涌现案例；ROUGE-L-Sum 等也被列入少数诱发涌现的非线性指标（App A.4）；
- **视觉诱导（§5）**：全连接（CIFAR100 重构）、自注意力（Omniglot 分类）、卷积（App B.1 MNIST）三种架构均成功诱导——说明该现象是度量学的普遍产物，与 LLM 特性无关；
- **相关工作对照（§6）**：Srivastava et al. 仅提出"可能与指标有关"的猜想，本文将其转化为精确预测并定量检验；Caballero et al. 用分段幂律解释（涌现"真实存在"于幂律拐点），Michaud et al. 认为强数据假设下涌现可能为真——本文立场：单一幂律 + 指标选择即可解释全部证据；
- **讨论四启示（§7）**：①benchmark 构建中任务与指标是两个独立且重要的设计选择；②选指标须考虑其对 per-token 误差的作用并配套足够数据量；③能力声明必须含多重比较控制；④模型与输出不对公众开放会阻碍科学的独立检验。

## §6 局限（基于论文自述内容的边界说明）

> 注：本文无编号 Limitations 章节，以下自 §7 Discussion 及正文限定语归纳：

1. **结论强度有明确边界**：仅论证"已报道的涌现很可能是 mirage"，不能排除真实涌现的存在（作者明示不否定涌现可能性）；
2. **算术再测依赖 API 可得性**：只有 GPT-3 族公开可查，其他模型族（PaLM、Chinchilla 等）只能做基于发表结果的元分析，无法固定原始输出重评；
3. **独立性近似**：Accuracy 推导采用 token 独立假设，作者承认假设不真但称定性结论吻合观测（脚注 1，p4）；
4. **元分析的间接性**：Emergence Score 只能"提示"涌现而非判定，故辅以人工标注集，但标注集本身来自他人（Srivastava et al. 2022 手工标注）；
5. **视觉诱导的外推限度**：视觉任务上"制造"出涌现形态证明了充分性（metric 可造涌现），但对"LLM 实际报道案例中指标因素占多大比重"只能给出 BIG-Bench 内的比例证据（>92%），不能机械外推至全部声称。
