## §4 方法要点
- **注意力混合架构**：线性注意力（`linear_attention`）通过**递归/状态建模**捕获局部依赖；稀疏注意力（`deepseek_sparse_attention`，DSA）通过**轻量级索引器召回全局上下文**。二者混合为 GLM 系列首次，精准长上下文能力得以保留。
- **IndexPool**：为降 1M 上下文下索引器的时延与内存开销，**加权池化将索引器的 4 个缓存向量压缩为 1 个向量**（config `index_kpool=4`, `index_kpool_compress=True`）。
- **IndexShare（缓存共享）**：config `index_share_for_mtp_iteration=True`，为 multi-token-prediction 迭代共享索引器缓存，避免重复构建。
- **mHC（Manifold-Constrained Hyper-Connections，流形约束超连接）**：提升 scaling 效率（`mhc=True`, hc_mult=4, sinkhorn_iters=20）。
- **MoE 稀疏化**：288 路由专家 + 每 token 8 专家激活 + 1 共享专家；`first_k_dense_replace=3` 前 3 层 MLP 保持 dense，后 42 层稀疏。
- **MLA（Multi-head Latent Attention）**：q_lora_rank=1536 / kv_lora_rank=512 低秩压缩；qk_nope_head_dim=256，qk_rope_head_dim=0（无独立 RoPE head 维度）。
- **视觉 Coding 数据合成管线**：聚焦"自我视觉判断 + 测试时改进"，生成轨迹要求模型与环境交互、检视自身输出、迭代改进（render→check→fix）。
- **环境反馈 RL**：前端 coding 探索基于环境反馈的强化学习 + 基于真实用户流程的 Agent 验证，强化 GUI 判断，将验证从功能正确性延伸至渲染与交互体验。
- **多模态编码器**：vision_config depth=24 / patch=14 / spatial_merge=2 / temporal_patch=2，支持 image+video 原生输入，视觉 out_hidden=4096 与文本对齐。
- **30T token 多模态预训练语料** + 架构/serving 三层次协同（capability←corpus←infrastructure）构成"用更少算力产出更多智能"。
- 国产芯片部署为"模型优化系统、系统承载模型"正循环：GLM-5.3 infra agent 协助算子开发、性能诊断、部署栈改进。

## §5 评测结果要点
- **成本-智能 Pareto**：Artificial Analysis Intelligence Index v4.1.1 得 **57 分 @ $0.045/task（discounted）**，官方称"此前同类智能约需 10× 成本"。
- **对 GLM-5.2 胜出（6 项编码/Agentic）**：DeepSWE +17.2、AutomationBench +22.6、Toolathlon +18.5、Terminal-Bench +3.3、NL2Repo +7.4、ALE +5.9、GDPval +269、HLE w/Tools +0.6——多数大幅领先，Agentic 维度提升最显著。
- **接近 Claude Opus 4.8**：综合六项编码/Agentic 基准整体接近；Z.ai Code Bench v1.0 max effort 29.0 vs 29.5。
- **Base 模型竞争力**：GLM-5.3-Flash-Base 整体超 GLM-4.5-Base，多数基准与 GLM-5-Base 竞争；LiveCodeBench-Base **37.6** 为四者最高（GLM-4.5 28.1 / GLM-5 34.4 / DeepSeek-V4-Flash 29.9）；MMLU 88.1、BBH 86.6、HellaSwag 87.1。
- **多模态/视觉**：OfficeQA Pro 62.4（超 DeepSeek-V4-Vision 57.9、Opus 4.8 48.9）、CharXiv 89.4、Chartography 78、MVBench 77.8、MMVU 80.5；BabyVision/MVBench/MMVU 弱于 Gemini 3.7 Flash。
- **自述案例**：在 Blender 中无外部素材自主运行 16 小时搭建约 400 平方米的主厨自宅与测试厨房；ZCode 中 2 小时电影 / 8 分钟成片；可交付白领专业文档（PDF/PPTX/DOCX/XLSX）。
- **评测基准配置脚注（博客明确）**：HLE w/Tools（T=1.0, p=0.95, max_gen 163,840, 300K ctx, GPT-5.6-luna 裁判）；NL2Repo（T=1.0, p=1.0, 64k new tokens, 1M ctx）；DeepSWE（mini-swe-agent, T=0.95, p=1.0, 6h, 400K ctx）；Terminal-Bench 2.1（Claude Code 2.1.207, T=1.0, p=1, 65,536, 6h）；ALE（官方协议, reasoning=max, 1M ctx, 64K 输出, 禁用 Tool Search）；Toolathlon Verified（官方服务, pass@1×3 次）；AutomationBench v1.0.6（含 PR #13 null 修复）；GDPval-AA v2（Artificial Analysis 评测）；BabyVision（T=1.0, p=0.95, 164K ctx, 短边≥1.5K px）；OfficeQA Pro（Treasury Bulletin PDF 语料, 无嵌入文本, 512K ctx）；CharXiv/Chartography/MVBench/MMVU（T=1.0, p=0.95, 256K ctx；原生视频直喂，否则默认 1fps 抽帧）。

- **别名仅为社区传闻**：`ox-alpha` 为官方博客确认的发布前匿名测试代号；"牛来"为社区/内部代号**未获官方确认**（HF 卡原文仅 320B/18B/混合架构/30T 语料，无任何别名说明）。

- **KV 缓存仍开销偏高**：官方明言 KV 缓存仍略高于 Kimi-K3 与 DeepSeek-V4-Flash，作为后续优化方向——非绝对最优。

- **评测口径不完全统一**：NL2Repo、HLE w/Tools、GDPval、Toolathlon 等多处竞品为 `null`/缺失（GPT-5.6 Terra、Gemini 3.7 Flash、DeepSeek-V4-Vision 等），跨模型可比性受限；GDPval 由第三方 Artificial Analysis 评测而非 Z.ai 统一。
