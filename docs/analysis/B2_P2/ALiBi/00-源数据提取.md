# ALiBi 源数据提取

## §1 元数据
- **标题**：Train Short, Test Long: Attention with Linear Biases Enables Input Length Extrapolation
- **作者/机构**：Ofir Press, Noah A. Smith, Mike Lewis（MosaicML / Allen Institute for AI / Meta AI）
- **发布**：arXiv:2108.12409 [cs.CL]，初版 2021-08-27；终版 v2，共约 12 页
- **DOI**：arXiv 预印本（发表于 ICLR 2022 / 相关会议）
- **许可证**：arXiv 预印本公开；ALiBi 方法以标量偏置实现，无额外训练参数，开源于 fairseq / MosaicML Composer
- **产品线定位**：P2 关键节点——位置编码的核心创新，用「零额外参数的线性偏置」实现免训练的长度外推（训练短、测长），与 RoPE（RoFormer，2021）形成两大主流位置编码路线

## §3 关键数字
以下数字均转引自论文摘要/正文：

**核心成果（转引自摘要）**
- 训练 1.3B 参数模型，训练序列长度 **1024**，外推（test）到 **2048**
- 达到与「正弦位置编码训练在 2048 上」相同的困惑度（perplexity）
- 训练**快 11%**，用**少 11% 内存**

**WikiText-103 效果（转引自摘要）**
- ALiBi 的「近因偏差（recency bias）」使其在 WikiText-103 上**优于多种强位置方法**

**机制关键值（转引自正文）**
- ALiBi 在 attention score 上叠加一个**线性衰减惩罚项**：`-m × |i - j|`（i、j 为 query 与 key 的位置，m 为依 head 不同的斜率）
- **零额外参数**（相较正弦/可学习位置嵌入）
- 每个 attention head 的斜率 m 不同；论文通常采用**指数几何级数**分配各 head 的 m 值（如 1/2, 1/4, 1/8 ...）
- 核心性质：**max position 长度不硬编码**，可在推理时外推到超过训练长度的序列
