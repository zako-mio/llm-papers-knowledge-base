# §4 方法细节

- **瓶颈分析（§2.4.1）**：增量自注意力每次生成都要重新加载历史 K/V 张量（大小 b·h·m·k = bn²）。跨 n 步的访存/算力比约为 Θ(n/d + 1/b)；当 n≈d 或 b≈1 时比值接近 1，内存带宽成为瓶颈（现代 GPU/TPU 算力可比带宽高约两个数量级）。
- **降低瓶颈的两类路线**：①减小 1/b——放大 batch size；②减小 n/d——限制序列长度 n、局部注意力（local attention，只 attend 当前与最近 31 个位置）、或压缩记忆位置。本文走「正交」新路：**去掉 K/V 的 heads 维**，同时保留 query 的 heads 维。
- **Multi-Query Attention 定义**：与 multi-head 完全一致，仅让所有 h 个头共享同一组 keys 与 values（即 P_k、P_v、K、V 不再有 heads 维 h，但 P_q、P_o、Q、logits 仍保留 h 维）。伪码见 `MultiqueryAttentionBatched` 与 `MultiquerySelfAttentionIncremental`。
- **增量 MQA 性能分析（§3.1）**：跨 n 步算力 Θ(bnd²)，访存 Θ(bnd + bn²k + nd²)；比值 Θ(1/d + n/(dh) + 1/b)。关键改进：将原本 Θ(n/d) 降为 Θ(n/(dh))——把「加载 K/V」的代价除以 head 数。
- **实验设置（§4.1）**：
  - 翻译（WMT 2014 En-De）：encoder-decoder Transformer，6 层，d_model=1024、dff=4096、h=8、dk=dv=128、学习位置嵌入、token-embedding 与输出层权重共享；全部变体 211M 参数；训练 100,000 步（20 epochs），每 batch 128 例（各 256-token 输入+目标，多句拼接）。
  - MQA 变体：所有注意力层（encoder-self、decoder-self、cross）换成 MQA；把前馈隐藏层从 4096 加宽到 5440 使总参数量与基线持平。
  - local 变体：decoder-self-attention 限制为当前 + 前 31 个位置，验证 MQA 与 local attention 正交。
  - 替代方案：减少 h 及 dk/dv 并加宽 dff 以平衡参数——h/dk,dv 取 1/128、2/64、4/32、8/16。
  - LM（Billion Word Benchmark）：基线 6 层、dff=8192、h=8、dk=dv=128，192M 参数；训练 136K 步（10 epochs），batch 64K tokens。
- **评测**：翻译用 sacrebleu（`sacrebleu -t wmt13/wmt14 -l en-de -tok intl`），dev 用 greedy，test 用 greedy + beam(4, α=0.6)；LM 报 per-word 困惑度；耗时在 1 个 TPUv2（8 cores）上测，增量解码 batch 1024 序列（每 core 128）、源/目标长 128（K/V 填充到最长 128 或窗口 32 以保证固定形状）。

# §5 实验结果要点

- **速度（核心卖点）**：增量解码 decoder 从 46µs/token（multi-head）降到 3.8µs/token（MQA），约 **12× 提速**；beam-4 从 203 降到 32µs/token。编码器仅 1.7→1.5µs/token（训练侧基本不变 13.2→13.0µs）。local 变体进一步降到 decoder 3.3µs/token、beam-4 16µs/token。
- **质量（轻微退化）**：
  - WMT14：MQA dev BLEU 26.5（base 26.7）、ln(PPL) 1.439（base 1.424）；test 上 MQA beam4 反而最高（28.5 vs 28.4）。MQA-local 27.6/28.2 也接近。
  - Billion-Word LM：MQA dev-PPL 30.2（base 29.9），仅小幅退化。
- **替代缩 head 方案质量受损更大**：h=1（dk=dv=128）时翻译 ln(PPL) 崩到 1.518、BLEU 25.8，LM dev-PPL 31.2——都比 MQA 差得多。证明「共享 K/V（保留 h 头）」优于粗暴「缩头数/缩 kv 维」。
- **与 local attention 正交**：MQA + local 组合在保住质量（28.2/27.6）的同时进一步提速，说明两种技术可叠加。
- **训练成本不受影响**：MQA 训练每 token 13.0µs vs 13.2µs，几乎无额外训练负担——优化只发生在推理路径。

# §6 局限

- **共享 K/V 引入容量限制**：所有头共享同一组 keys/values，理论上限制各头捕捉不同键值映射的表达能力，故导致轻微质量退化（dev 指标略降），对追求极致质量、不在意推理速度的场景非最优。
- **增量实现的经验细节**：受固定 shape 系统限制，K/V 被填充到最大长度（128）或窗口（32），因此每步耗时恒定，未受益于序列前段更小的张量——实际可进一步提速（作者自注）。
- **实验规模有限**：仅两个任务/领域（WMT14 EnDe、Billion-Word LM），未在更大模型（如今日数十 B）或更多语言/任务上验证；当时 TPUv2 为评测硬件，现代硬件的带宽/算力比变化可能影响结论。
- **只快自回归解码**：MQA 针对增量（自回归）解码瓶颈，对训练或高度并行编码收益极小（训练 13.2→13.0µs、编码 1.7→1.5µs 几乎不变）；非自回归或编码器主导的场景获益有限。
- **未系统消融的权衡边界**：未单独区分「共享 K/V」与「加宽 dff 保参数」各自贡献——实验中为保参数同时加宽了前馈层，两种因素的独立影响未完全解耦。
