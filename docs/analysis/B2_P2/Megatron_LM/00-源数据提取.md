## §3 关键数字
以下数字均转引自论文正文/摘要，标注来源：

**模型规模与评测**
- 最大训练模型：**8.3B（83 亿参数）** transformer 语言模型（类 GPT-2），使用 **512 GPUs**（摘要）
- 另训练 **3.9B** 参数类 BERT 模型（摘要）
- GPT-2 类模型 WikiText-103 perplexity：**10.8**（对比 SOTA 15.8）（摘要）
- GPT-2 类模型 LAMBADA 准确率：**66.5%**（对比 SOTA 63.2%）（摘要）
- BERT 类模型 RACE 数据准确率：**90.9%**（对比 SOTA 89.4%）（摘要）

**扩展效率与吞吐（转引自摘要与 Results 章节）**
- 整个应用维持 **15.1 PetaFLOPs** 吞吐
- 对比强单 GPU 基线（39 TeraFLOPs）的 **76% 扩展效率**
- 单 GPU 峰值 FLOPs 的 **30%** 利用率（39 TFLOPs 约为峰值 30%）
- 3.9B 模型在 512 GPUs 上可扩展到 **11.5 PetaFLOPs**（正文估算区）
