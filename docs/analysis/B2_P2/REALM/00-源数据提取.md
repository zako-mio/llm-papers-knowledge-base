## §3 核心主张与关键数字表（注明出处）

### 3.1 核心主张

**主张 A（隐式 vs 显式知识）**：语言模型如 BERT/RoBERTa/T5 隐式存储世界知识（在参数里），受网络容量限制、不可解释；REALM 用可学习检索器显式引用语料库，知识模块化、可解释（Abstract, p1）。

**主张 B（首次无监督训练检索器）**：REALM 首次把知识检索器以无监督方式端到端预训练，以 MLM 为学习信号，反向传播穿过考虑数百万文档的检索步骤（Abstract, p1）。

**主张 C（Open-QA 超 SOTA 4-16%）**：在三项 Open-QA 基准（NQ/WQ/CT）上超出所有此前方法 4-16% 绝对精度（Abstract, p1；§4.4, p7）。

**主张 D（比 T5-11B 小 30 倍却更优）**：REALM 以 330m 参数（约 3 亿）超越最大 T5-11B（11318m，约 113 亿），是 T5-11B 的约 1/34 参数规模（§4.4, p7）。对比：T5 Base→11B 模型增大 50 倍仅提升约 5 点。

**主张 E（仅检索 5 篇文档 vs 他法 20-80 篇）**：REALM 仅用 5 篇候选文档取得最佳性能，而其他检索系统常检索 20-80 篇（§4.4, p7）。

**主张 F（相对 ORQA 的提升纯来自预训练方法）**：REALM 与 ORQA 微调/超参/数据完全一致，提升纯粹源于更好的预训练（§4.4, p7）。

## §4 方法细节

### 4.1 生成过程建模（§3.1, p3）

REALM 将 p(y|x) 分解为"检索→预测"两步，把文档 z 视为**隐变量**并边缘化：

```
p(y|x) = Σ_{z∈Z} p(y|z,x) · p(z|x)        (式 1)
```

- 预训练任务：MLM——x 为掩码句子，y 为缺失 token 值。
- 微调任务：Open-QA——x 为问题，y 为答案。

### 4.2 模型架构（§3.2, p3-4）

**知识检索器（models p(z|x)）**——稠密内积模型：

```
p(z|x) = exp f(x,z) / Σ_{z'} exp f(x,z')
f(x,z) = Embed_input(x)ᵀ · Embed_doc(z)
Embed_input(x) = W_input · BERT_CLS(joinBERT(x))
Embed_doc(z)   = W_doc  · BERT_CLS(joinBERT(z_title, z_body))
```

- 使用 BERT-style Transformer；text 用 wordpiece 分词，[CLS]前缀 + [SEP]分隔。
- θ = 检索器全部参数（Transformer + 投影矩阵）。

**知识增强编码器（models p(y|z,x)）**——将 x 与 z 拼接送入独立 Transformer，做 x-z 交叉注意力：

- MLM 预训练：`p(y|z,x) = Π_j p(y_j|z,x)`，用 BERT_MASK 向量。
- Open-QA 微调：假设答案 y 是文档 z 中连续片段，`p(y|z,x) ∝ Σ_{s∈S(z,y)} exp(MLP([h_START(s); h_END(s)]))`，h_START/h_END 为答案 span 起止 token 的 Transformer 输出。
- φ = 知识增强编码器全部参数。

### 4.3 训练（§3.3, p4-5）

最大化 log p(y|x)，θ/φ 均可微，用 SGD 优化。关键计算挑战是式 1 对全语料求和：

1. **Top-k 近似**：只对 p(z|x) 下概率最高的 top-k 文档求和（多数接近 0 概率）。
2. **MIPS**：f(x,z) 是内积，可用 Maximum Inner Product Search 亚线性时间找 top-k。
3. **索引失效问题**：Embed_doc 参数更新后 MIPS 索引过时（stale）。解决：每隔几百步异步重嵌入、重建索引。
4. **异步刷新实现**：并行两个 job——主 trainer（梯度更新）+ 次 index builder（嵌入+索引）。trainer 把 θ' 快照发给 builder，builder 后台建新索引，完成后回传，循环重复。微调时只建一次索引、不更新 Embed_doc（但更新 Embed_input，从 query 侧更新检索）。

**检索器学到什么（梯度分析）**：

```
∇ log p(y|x) = Σ_{z∈Z} r(z) · ∇f(x,z)
r(z) = [p(y|z,x)/p(y|x) − 1] · p(z|x)
```

- r(z)>0 ⟺ p(y|z,x) > p(y|x)，即文档 z 表现好于期望（均值）时获正更新。

### 4.4 归纳偏置注入（§3.4, p5）

四项技巧，进一步引导有意义的检索：

1. **Salient span masking（显著片段掩码）**：只掩码需世界知识的片段（专名如 "United Kingdom"、日期如 "July 1969"）。BERT tagger（CoNLL-2003）+ 正则识别日期。显著优于其他掩码策略。
2. **Null document（空文档）**：把空文档 ∅ 加入 top-k，当无需检索时把功劳分配给一致的 sink。
3. **Prohibiting trivial retrievals（禁止平凡检索）**：X 与 Z 同语料时，若句子 x 来自文档 z，编码器可通过 x 的未掩码版平凡预测 y——排除该平凡候选，避免检索器退化为精确字符串匹配。
4. **Initialization（初始化防冷启动）**：用 Inverse Cloze Task (ICT) 预热 Embed_input/Embed_doc；编码器用 BERT-base（uncased，12 层/768 hidden/12 heads）预热。避免"编码器忽略检索文档→检索器无梯度→恶性循环"。

## §5 实验要点

- **基准**：NATURALQUESTIONS-OPEN (NQ, 79k train/4k test)、WEBQUESTIONS (WQ, 3k/2k)、CURATEDTREC (CT, 1k/1k)。NQ 只保留 "short answer type" ≤5 token 的问题；答案用精确匹配评估。CT 答案为正则表达式，无法训练生成式模型，故生成式模型不评估 CT。
- **对比阵营**：
  - 检索式（显式知识）：稀疏检索（TF-IDF/BM25，DrQA/HardEM/GraphRetriever/PathRetriever）+ 稠密检索 ORQA。
  - 生成式（隐式知识）：T5 Base/Large/11B（Roberts 2020）。
- **关键对比**：REALM vs ORQA（微调/超参/数据完全相同），提升纯因预训练方法。
- **消融结论**（Table 2）：
  1. 检索器与编码器分别受益于 REALM 预训练，但最佳需两者协同。
  2. Salient span masking 对 REALM 关键（standard BERT 中不重要，但对隐变量学习敏感）。
  3. 过旧 MIPS 索引（30× stale）显著伤害训练（Exact Match 38.2→28.7）。
- **案例证据**（Table 3）：REALM 检索到 "257 is...a Fermat prime" 后，边缘概率从 1.1×10⁻¹⁴ 提升到 0.129，证明无监督下能检索文档补词。

## §6 局限（作者角度 + 客观补充）

**作者自述局限**：

1. **仅 Open-QA 验证**：REALM 仅在 Open-QA 上微调评估，未覆盖更广下游任务。
2. **仅单种归纳偏置组合**：论文为 minimal instantiation，偏置注入与架构未充分探索。
3. **微调未刷新索引**：微调阶段不更新 Embed_doc（只更新 query 侧），作者指出进一步刷新索引可能提升性能。
4. **语料选择**：X 用 Wikipedia（与 Z 相同）或 CC-News；未用 SQuAD 阅读理解数据（作者指出 REALM 也可受益）。

**客观补充/时代局限**：

1. **计算资源需求高**：预训练 200k 步需 64 TPU + 16 TPU 并行索引 + 异步 MIPS 刷新，工程复杂度与算力门槛高。
2. **间接依赖强监督**：用 CoNLL-2003 训练的 NER tagger 做 salient span masking，注入了一定外部标注信息（非纯无监督）。
3. **检索与编码解耦**：文档库固定（Wikipedia 2018-12-20 快照），推理时无法更新知识库，知识时效受限。
4. **后续局限**：REALM 为 RAG 前身，但检索失败时无生成兜底（对比 RAG 的 seq2seq generation）；稠密检索依赖预计算文档嵌入，升级语料需全量重建索引。
