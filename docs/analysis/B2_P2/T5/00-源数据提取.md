# §4 方法细节

- **框架**：把每个问题建模为 text-to-text，输入为文本串、输出为目标文本串；不同任务仅通过输入前缀区分（如 "mnli premise hypothesis"、"summarize:"、"translate En to De: ..."）。同一模型、损失函数（交叉熵）、解码过程适用于所有任务。
- **模型（Transformer encoder-decoder）**：多层 stack，编码器 fully-visible self-attention、解码器 causal self-attention，编码器-解码器注意力连接；层归一化 + 残差跳连 + dropout；输出投射层与输入 embedding 共享权重。
- **相对位置嵌入**：用简化形式，每层共享位置嵌入参数，但层内每个 attention head 用不同的可学习位置嵌入（标量加到 logit）。
- **C4 数据集构建（§2.2）**：下载 Common Crawl 2019 年 4 月 web 抽取文本，按启发式清洗——仅保留以终止标点结尾的行、丢弃少于 3 句的页面且行需含至少 5 词、删除含脏词/源码/占位符等页、去除 HTML 警告，约得 750GB 干净英文文本，作为 TensorFlow Datasets 发行。
- **去噪预训练目标（§3.1）**：受 BERT mask 与 word dropout 启发，随机采样丢弃 15% token；连续被丢弃 span 用单个唯一 sentinel token（<X>、<Y>…）替换；目标序列为被丢弃的 span，以 sentinel 分隔并以 <Z> 结尾。（示例见 Table 3/Fig.2）
- **目标消融**：对比 BERT-style（mask token）、MASS-style、Deshuffling（对调）、i.i.d. noise replace spans、drop tokens、random spans；结论「replace corrupted spans」(即基线目标) 与「drop corrupted tokens」表现最好。
- **架构消融（§3.2）**：比较 encoder-decoder、decoder-only LM、prefix LM 与参数共享/层数变体；用 P 表示 BERT-sized 12 层 stack 参数量、M 表示 encoder-decoder FLOPs，据此对照（L+L 层、P 参数、M FLOPs 等）。结论：encoder-decoder 最优，LM-only 明显最差。
- **训练超参**：AdaFactor 优化器；预训练 at 恒学习率 0.01 预热 10^4 步 → 逆平方根衰减（`1/sqrt(max(n,k))`）；微调用恒定学习率；dropout 正则；词表共享。
- **规模缩放**：从 T5-Small(60M) 到 T5-11B(11B)，在 24 个任务上评估，模型越大越好（表 14）。

# §5 实验结果要点

- **预训练强大收益**：基线平均分远超「无预训练」（如 GLUE 83.28 vs 66.22、SuperGLUE 71.36 vs 53.04），证明 transfer learning 在低资源任务上增益巨大并提升 data efficiency。
- **架构结论**：encoder-decoder（Denoising）最优；decoder-only LM 明显劣于 encoder-decoder；prefix LM 接近但略低；参数共享会小幅损失（83.28→82.81）。
- **目标结论**：text-to-text 框架下，「replace corrupted spans / drop corrupted tokens」类去噪目标优于 BERT-style、MASS-style 与 Deshuffling；`drop corrupted tokens` 甚至更高（GLUE 84.44）。
- **规模结论**：T5-Small/Base/Large 性能逐级上升；T5-11B 在几乎所有任务最佳，也是刷新 18/24 任务 SOTA 的关键；T5-3B 在个别任务已超前一 SOTA。
- **最终 test 成绩（T5-11B）**：GLUE 90.3（前 SOTA 89.4）；SQuAD EM91.26/F1 96.22；SuperGLUE 88.9（前 84.6）；MultiRC F1 88.1、ReCoRD F1 94.1、WMT EnDe 32.1、CNN/DM ROUGE-L 40.69。BLEU 类指标（EnDe/EnFr）个别略低于前一 SOTA（33.8/43.8）。
- **run-to-run 方差**：大多任务 std < 基线的 1%；CoLA/CB/COPA 等低资源任务例外（如 CB F1 91.22±3.237，验证集仅 56 例），故用 GLUE/SuperGLUE 均分比较需谨慎。

# §6 局限

- **算力门槛高**：需 1024 个 TPUv3 大规模训练；T5-11B 推理/评测受基准服务器资源限制（如 SQuAD 无法在评测服务器跑最大模型，只能报验证集）。
- **纯英文单一框架**：C4 为英文文本，跨语言（除 WMT En-X 外）与多语种能力未系统覆盖。
- **统一框架牺牲部分专精**：部分任务 BLEU（EnDe/EnFr）仍低于专精 SOTA，说明「一句话适配所有任务」并非在每一项都最优；表 14 显示个别指标未破前纪录（如 EnDe BLEU 前 33.8 对 T5-11B 32.1、EnRo 前 38.5 对 28.1）。
- **消融结论依赖特定预算**：预训练仅用 34B token（远小于 RoBERTa 2.2T），多任务与更多步数的收益可能被低估；作者也指出更长的预训练（§3.6/3.7）带来额外增益。
- **指标可比性问题**：主要报验证集（除 Table 14 报 test 且 SQuAD 例外），跨论文的「state-of-the-art」比较需谨慎；部分任务依赖 GLUE/SuperGLUE 官方评测服务器。
- **未启用更前沿组件**：论文未探索稀疏注意力、MoE 或条件计算（同期 Switch/Conditional 论文随后出现），聚焦标准密集 Transformer。
