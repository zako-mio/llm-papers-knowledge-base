## 摘要

本文解读 Google（Colin Raffel、Noam Shazeer、Adam Roberts 等）发表于 JMLR 21 (2020) 1-67 的《Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer》，通称 **T5**。论文的核心动作有两个：其一，提出统一的 **Text-to-Text Transfer Transformer** 框架——把所有 NLP 任务（分类、回归、摘要、问答、翻译）一律改写为「文本进、文本出」的序列转换问题，任务之间仅靠输入前缀（如 `"mnli premise hypothesis"`、`"translate English to German:"`）区分，同一模型、同一交叉熵损失、同一解码过程通吃全部任务；其二，在此统一框架上进行**系统化消融**——逐一扫过去噪目标形式、架构变体（encoder-decoder / decoder-only LM / prefix LM）、数据集构成、预训练步数、模型规模、多任务与微调策略，每个变量都在受控条件下单独评估。配套产出还有 **C4**（Colossal Clean Crawled Corpus，约 750GB 清洗后 Common Crawl 英文文本）这一开源预训练语料。最终以 1024 块 TPUv3 训出的最大 11B 参数模型在 24 项任务中的 **18 项刷新当时 SOTA**：GLUE 平均 90.3（前纪录 89.4）、SuperGLUE 平均 88.9（前纪录 84.6）、SQuAD EM/F1 91.26/96.22（前纪录 90.1/95.5）。本报告按「问题—概念—方法—证据—批判—启示」六层结构逐层拆解，并着重讨论一个历史性问题：这篇 2019 年的论文如何在无意间为随后整个 LLM 时代（instruction tuning、scaling law、数据工程）写下蓝图。

## 一、问题定位：2019 年迁移学习的「碎片化繁荣」

### 1.1 论文要解决的问题

到 2019 年，NLP 迁移学习已取得统治性成功，但领域呈现一种**碎片化繁荣**：BERT 用双向 masked language model 加 encoder-only 结构，GPT 系用因果语言模型加 decoder-only 结构，XLNet 引入排列语言模型，各家的预训练目标、架构选择、下游适配方式（分类头微调 / 语言模型头续写）互不相同。每一篇新论文都宣称自己的组合更好，但这些比较**无法归因**——两个模型的差异往往同时混杂着目标函数、架构、数据、规模、微调方案五组变量，谁也无法回答「到底是哪个设计选择真正起了作用」。

论文标题里的 "Exploring the Limits" 正是对此的系统回应：**要想知道迁移学习的极限在哪里，先把所有变量放进同一个受控实验框架**。T5 的做法是把「任务表示」这个最大的不一致性先抹平（全部 text-to-text），然后在一个固定基线上逐个拨动其余开关。这不是单点创新的论文，而是一张**实验地图**。

### 1.2 双重贡献的内在关联

值得注意的是，「统一框架」与「系统消融」不是并列的两件事，而是**互为前提**：

- 没有统一框架，消融就无从谈起——如果换一个任务就要换一种输出头和损失函数，那么「只改预训练目标」的对照实验根本设计不出来；
- 反过来，消融结果又反过来论证了统一框架本身的合理性——正是通过消融才知道哪种架构、哪个目标是这条统一路线上的最优配置。

（推断）这种「先建度量衡、再做科学实验」的研究组织方式，本身就是本文对学界的方法论贡献之一，其影响不下于任何单项技术结论。

### 1.3 与同期工作的谱系关系

论文明确对标 BERT（~137B token 预训练量）与 RoBERTa（~2.2T token）：RoBERTa 已证明「不改架构只堆数据与调训法」能大幅超越 BERT，说明预训练配方远未被榨干；T5 则更进一步，问的是「如果把一切选择都重新审视一遍，最优组合是什么」。同时 T5 的预训练预算只有约 2^35 ≈ **34B tokens**——刻意用一个相对小的预算做消融（否则 1024 块 TPU 也烧不起全网格搜索），再把胜出配置放大到 11B 冲刺 SOTA。这个「小预算找方向、大预算收果实」的两阶段结构贯穿全文。

> **一句话小结**：本文解决的问题不是「再造一个更强的模型」，而是「终结各说各话的盲测时代」——用 text-to-text 统一度量衡，用系统消融分离变量，用规模放大兑现结论。

## 二、概念内核：五个核心概念逐一定义

### 2.1 Text-to-Text 统一框架

**定义**：把每个 NLP 问题建模为「输入文本串 → 输出文本串」；不同任务仅通过输入前缀区分，例如 MNLI 写作 `"mnli premise hypothesis"`、翻译写作 `"translate English to German: ..."`、摘要写作 `"summarize: ..."`；模型、损失函数（输出 token 上的交叉熵）、解码过程对所有任务完全一致。

**拆解**：这个设计的深意在于它把「任务的多样性」从**模型接口层**降维到了**数据格式层**。分类任务不再需要随机初始化的分类头（BERT 时代新增类别就要加参数、改结构），回归任务把分数转成字符串即可，QA 与摘要本来就是生成任务。于是「预训练—微调」的全流程对所有任务是同构的，这既是消融可行的前提，也是后来 instruction tuning 的雏形——（推断）今天大模型对话中 system/user 指令引导模型行为的机制，血缘上可以直接追溯到这里的任务前缀。

### 2.2 C4：Colossal Clean Crawled Corpus

**定义**：下载 Common Crawl 2019 年 4 月的网页抽取文本，经启发式清洗得到的约 **750GB** 干净英文文本，作为开源数据集随 TensorFlow Datasets 发行。

**拆解**：清洗规则朴素而务实——仅保留以终止标点结尾的行、整页少于 3 句则丢弃、行需至少含 5 词、剔除含脏词/代码痕迹/占位符的页面、去除警告文本。它的意义超出论文本身：GPT-2 的 WebText 不公开，学界长期缺少一个「够大又够干净」的可复现预训练语料；C4 填补了这个位置，（推断）此后 mC4（多语版）、各类 C4 变体成为无数论文的标准燃料，「发布可复现数据集」自此成为预训练研究的标配动作。

### 2.3 基线去噪目标（span corruption）

**定义**：受 BERT mask 启发的去噪目标——随机采样丢弃约 **15%** 的 token；连续被丢弃的 span 用单个唯一 sentinel token（`<X>`、`<Y>`……）替换；目标序列即被丢弃的那些 span，以 sentinel 分隔、`<Z>` 结尾。

**拆解**：与 BERT 逐 token 打 `<MASK>` 不同，这里把连续损坏区域**折叠成 sentinel**，使目标序列长度正比于损坏块数而非损坏 token 数——解码端只需重建少量连续片段，训练信号密度更高。（推断）这一「span 折叠」思想后来在 UL2 的 mixture-of-denoisers、以及各类 span-infilling 预训练（如 code infilling）中被反复继承。

### 2.4 相对位置嵌入（简化版）

**定义**：不用 Transformer 原版的正弦绝对位置或独立查表，而是让每层共享位置嵌入参数，但层内每个 attention head 持有一组不同的可学习位置嵌入，以**标量形式加到 attention logit 上**。

**拆解**：这是把 Shaw et al. 式相对位置编码做了大幅瘦身——参数量从「每层一套完整嵌入表」压到「每 head 一套共享标量表」，换取参数效率。（推断）位置信息以偏置形式注入注意力打分而非混入词向量空间，这一思路在后来 T5 系模型中长期沿用，也与今天不少模型用 bias 注入位置信号的做法遥相呼应。

### 2.5 Encoder-Decoder 基线架构

**定义**：标准 Transformer encoder-decoder——编码器 self-attention 为 fully-visible（双向可见），解码器 self-attention 为 causal（因果遮蔽），两者间由 encoder-decoder attention 连接；配层归一化、残差连接、dropout；输出投射层与输入 embedding 共享权重。

**拆解**：编码器对输入一次性建立全局表示，解码器再逐 token 生成输出——这个「理解与生成分工」的结构与 text-to-text 框架天然咬合：输入前缀与正文由编码器消化，答案由解码器吐出。它是第二章消融的「被检验对象」之一，也是最终胜出者。

> **一句话小结**：五个概念合成一台机器——text-to-text 是接口协议，C4 是燃料，span corruption 是预训练信号，相对位置嵌入与 encoder-decoder 是引擎本体；后续所有章节都是围绕这台机器做的受控变量实验。

## 三、方法拆解：一张系统消融的完整实验地图

### 3.1 实验基础设施：基线配方与预算

所有消融共用一个基线配置，先把它钉死：

| 项目 | 取值 |
|---|---|
| 优化器 | AdaFactor |
| 学习率 | 预训练恒定 0.01，预热 10^4 步后按 `1/sqrt(max(n,k))` 逆平方根衰减；微调用恒定学习率 |
| 批次规模 | 每批约 2^16 = 65,536 个 token |
| 训练步数 | 2^18 = 262,144 步（p12 记录） |
| 总 token 预算 | 约 2^35 ≈ **34B tokens**（对比 BERT ~137B、RoBERTa ~2.2T） |
| 微调 | 固定步数的微调流程，dropout 正则，词表共享 |

（推断）值得留意的是 34B 这个预算的「经济性」：它不到 BERT 的一半、RoBERTa 的六十五分之一，却支撑起整个消融网格——这是「用最小可信预算找方向」的设计自觉，也是全文结论的一个隐含边界条件（见第五章疑点①）。

### 3.2 架构消融：三种结构 × 三种注意力模式

**实验设计**：为公平比较不同结构的参数/算力效率，论文引入统一计量——P 表示 BERT-sized 12 层 stack 的参数量，M 表示 encoder-decoder 的 FLOPs，层数记 L/L+L；据此把 encoder-decoder、decoder-only 语言模型（LM）、prefix LM 三种结构与 fully-visible / causal / causal+prefix 三种注意力掩码交叉对照（图 3 给出掩码矩阵，图 4 给出结构示意）。

**结果**（Table 2，Denoising 目标下）：

| 结构 | GLUE | CNN/DM | SQuAD | SuperGLUE | EnDe | EnFr | EnRo |
|---|---|---|---|---|---|---|---|
| **Encoder-decoder**（基线） | **83.28** | **19.24** | **80.88** | **71.36** | **26.98** | **39.82** | **27.65** |
| Language model | 74.70 | 17.93 | 61.14 | 55.02 | 25.09 | 35.28 | 25.86 |
| Prefix LM | （介于两者，接近 encoder-decoder） |

**结论**：encoder-decoder 全面最优；prefix LM 接近但略低；decoder-only LM **明显最差**（GLUE 落后 8.58、SQuAD 落后近 20 分）。此外参数共享（编码器解码器共用权重）带来小幅损失（GLUE 83.28 → 82.81）。

（推断）历史注脚：这个结论在今天 decoder-only 一统天下的语境下常被引用为「T5 判了 GPT 死刑」，但这是一种误读——该实验是在**监督式预训练+微调**范式、固定参数与算力的条件下比较「预训练信号利用效率」，彼时尚无 in-context learning 与 few-shot 评测视角。GPT-3 随后展示的少样本能力改变了游戏规则，两种范式的优劣并非 Table 2 一张表所能终审。

### 3.3 目标消融：去噪形式的精细扫描

在固定 encoder-decoder 架构下，论文比较了多种自监督目标（Table 3 给出各目标的输入输出示例；Table 4/5 给出结果）：

| 目标 | GLUE | CNN/DM | SQuAD | SuperGLUE | EnDe | EnFr | EnRo |
|---|---|---|---|---|---|---|---|
| **Replace corrupted spans**（基线） | 83.28 | 19.24 | 80.88 | 71.36 | 26.98 | 39.82 | 27.65 |
| BERT-style（mask token） | 82.96 | 19.17 | 80.65 | 69.85 | 26.78 | 40.03 | 27.41 |
| Deshuffling（乱序还原） | 73.17 | 18.59 | 67.61 | 58.47 | 26.11 | 39.30 | 25.62 |

外加 i.i.d. noise、replace spans、drop tokens、random spans 等变体。**结论**：「replace corrupted spans」与「drop corrupted tokens」表现最好——后者在 GLUE 上甚至达到 84.44，高于基线的 83.28；BERT-style 接近但整体略逊；Deshuffling 这类不含「内容重建」的目标大幅落后（GLUE 差 10 分以上）。

**解读**：(1) 最好的目标都是「破坏文本内容、要求重建内容」的去噪形式，说明**重建语义本身**是预训练信号的核心来源；(2) BERT-style 与 span-replace 差距不大（GLUE 仅 0.32），说明目标函数的边际收益有限——相比之下架构选择的差距（8~20 分）大得多，这是一个重要的优先级排序：**选对结构比微调目标更重要**（推断）；(3) deshuffling 的惨败说明仅让模型学「顺序」而不学「内容产生」不足以迁移。

### 3.4 数据侧：C4 及数据集消融

C4 的构建已在 2.2 节给出。论文进一步在统一框架下考察了数据集选择问题（如 C4 与 Unsupervised/RealNews-like 等替代语料的对照，以及领域内 vs 领域外语料的影响，见 §3.3-3.8 系列）。源数据确认的总体走向是：数据集构成确有影响，且**更长的预训练持续带来额外增益**（§3.6/3.7）——即在当时 34B 预算下模型仍未「喂饱」。

### 3.5 规模缩放与多任务/微调策略

- **规模轴**：T5-Small(60M) → Base(220M) → Large(770M) → 3B → 11B，性能逐级单调上升（Table 13/14）；
- **多任务与微调策略轴**（§3.7/3.8）：考察多任务联合训练与各种微调方案的组合效果；
- **硬件底座**：1024 块 TPUv3 通过 2D mesh 互联完成大规模训练。

（推断）「越大越好」的单调曲线与「更久预训练仍有增益」这两条经验，正是四个月后 Kaplan et al. scaling law 论文（2020 年初）的直接经验前奏——T5 团队用自己的网格提前摸到了 scaling 曲线的形状。

### 3.6 最终配方与冲刺

胜出配方 = C4 预训练 + encoder-decoder + replace corrupted spans + 充分放大规模。以此训出的 T5-11B 在 SuperGLUE leaderboard 上平均 88.9，超过人类基线水平（89.8 的说法不在源数据中，不予引用），并拿下 18/24 任务 SOTA。具体成绩单见第四章。

> **一句话小结**：方法体系的骨架是「一个基线 + 五个消融轴」——架构（差距最大）、目标（差距其次）、数据集、训练时长、模型规模依次扫描，最后用 11B 放大兑现；这是一篇把「消融」做成主菜的论文。

## 四、证据链：从 Table 1 到 Table 14 的三层证据

### 4.1 第一层：预训练到底值多少（Table 1）

基线 vs 无预训练对照（均值±std 中的均值）：

| 任务 | Baseline | No pre-training | 差值 |
|---|---|---|---|
| GLUE | 83.28 | 66.22 | **+17.06** |
| CNN/DM (ROUGE) | 19.24 | 17.60 | +1.64 |
| SQuAD | 80.88 | 50.31 | **+30.57** |
| SuperGLUE | 71.36 | 53.04 | **+18.32** |
| WMT EnDe | 26.98 | 25.86 | +1.12 |
| WMT EnFr | 39.82 | 39.77 | **+0.05** |
| WMT EnRo | 27.65 | 24.04 | +3.61 |

**逐行解读**：预训练的红利分布**极度不均**——SQuAD 提升 30.57 分、SuperGLUE 18.32 分，而英法翻译只有 0.05 分，几乎为零。这说明 transfer learning 的真正价值集中在**低资源目标任务**上：目标任务自身监督信号越稀缺，预训练带来的先验越珍贵；而像 EnFr 这种本身拥有海量平行语料的任务，从头训练已经足够，预训练几乎无事可做。（推断）这一发现对今天仍有直接回声：大模型对小语种/垂直任务的价值，本质上仍是这条「资源稀缺度决定迁移收益」曲线的延伸。

### 4.2 第二层：架构与目标的受控对比（Table 2/4/5）

见 3.2/3.3 节表格。核心读数有三：

1. **架构 > 目标的杠杆排序**：encoder-decoder 与 decoder-only 的 GLUE 差 8.58 分，而最好与次好目标只差 0.32 分（推断：这是全文最容易被忽视却最有决策价值的结论之一）；
2. **prefix LM 是个接近的第二名**——它保留了「对输入双向、对输出因果」的折中掩码，暗示「理解端全局看、生成端顺序写」才是关键性质，而非「必须有独立编码器」本身（推断）;
3. 参数共享的小幅代价（−0.47 GLUE）说明 encoder-decoder 的性能优势部分来自其双倍深度（L+L 层对 L 层），论文用 P/M 计量控制这一点后优势仍在。

### 4.3 第三层：最终冲刺的成绩单与它的阴影（Table 14）

T5-11B 的 test 集成绩 vs 此前 SOTA：

| 任务 | T5-11B | 前 SOTA | 判定 |
|---|---|---|---|
| GLUE 平均 | **90.3** | 89.4 | ✓ 破纪录 |
| SuperGLUE 平均 | **88.9** | 84.6 | ✓ 大幅破纪录 |
| SQuAD EM / F1 | **91.26 / 96.22** | 90.1 / 95.5 | ✓ 破纪录 |
| MultiRC F1 | 88.1 | — | 领先项 |
| ReCoRD F1 | 94.1 | — | 领先项 |
| CNN/DM ROUGE-L | 40.69 | — | 领先项 |
| WMT EnDe BLEU | 32.1 | 33.8 | ✗ 未破 |
| WMT EnFr BLEU | — | 43.8 | ✗ 未破 |
| WMT EnRo BLEU | 28.1 | 38.5 | ✗ 差距显著 |

合计 **18/24 任务刷新 SOTA**。但成绩单自带三道阴影：其一，BLEU 类任务（尤其 EnRo，落后 10.4 分）明显不敌专精翻译系统，说明「一个模型打天下」在专精任务上有真实代价；其二，除 Table 14 外多数结果报的是验证集，且 SQuAD 因评测服务器资源限制跑不了最大模型、只能报验证集——跨论文的 SOTA 口径需谨慎对待；其三，run-to-run 方差在多数任务上 std < 1%，但 CoLA/CB/COPA 等低资源任务例外（CB F1 91.22 ± 3.237，验证集仅 56 例），作者自己提醒 GLUE/SuperGLUE 均分比较须谨慎。

> **一句话小结**：证据呈三层递进——Table 1 证明「迁移学习值多少、对谁值」，Table 2/4/5 证明「怎么搭、怎么练」，Table 14 证明「放大后能赢多少」；而 EnDe/EnFr/EnRo 三处未破纪录与 CB ±3.237 的方差，是这份漂亮成绩单上诚实标注的裂缝。

## 五、批判性分析：局限的深层含义与独立疑点

### 5.1 作者自述局限的深层含义

1. **算力门槛**：1024 块 TPUv3、最大 11B——「复现成本极高」的另一面是：**消融结论的可信度建立在别人无法轻易复核的基础上**。深层含义是 empirical study 类论文的可重复性问题在 2019 年就已显形。
2. **纯英文单一语系**：C4 为英文，除 WMT En-X 外未系统覆盖多语。深层含义：text-to-text 的「统一」只是**任务维度**的统一，语言维度留白——这个缺口由同团队的 mT5 补上。
3. **专精任务让步**：EnDe 32.1 vs 33.8、EnFr 前 43.8、EnRo 28.1 vs 38.5。深层含义：统一框架的代价是放弃任务特化结构的自由度，「通用 vs 专精」的权衡第一次在大规模实验中被定量呈现。
4. **消融结论绑定小预算**：34B token 的消融网格远小于 RoBERTa 的 2.2T；作者也承认更长预训练有额外增益。深层含义见疑点①。
5. **评测口径**：以验证集为主 + SQuAD 无法提交官方服务器。深层含义：leaderboard 时代的「SOTA」叙事天然带着口径摩擦。

### 5.2 独立观察到的四个疑点

**① 「小预算消融 + 大预算冲榜」的逻辑断层**：全部架构/目标消融都在 ~220M/34B 的尺度完成，而 SOTA 由 11B 模型取得——**消融得出的最优配置是否在 11B 尺度仍然最优，论文并未验证**（推断：例如 decoder-only 与 encoder-decoder 的差距完全可能随规模变化，后来的 GPT-3 恰恰展示了 decoder-only 在另一评测范式下的爆发）。严格地说，Table 2 的结论应限定为「在该预算与微调范式下」，而论文的宏大标题容易让读者越过这个限定。

**② 「探索极限」与「限制资源」的内在张力**：标题宣称 exploring the *limits*，但预训练预算刻意压在 34B（不足 RoBERTa 的 1/60），且作者自己发现「更长预训练持续有增益」——这意味着论文给出的更像「给定算力下的最优配方」，而非真正的性能极限。（推断）真正的 limit 探索要到 scaling law 一脉才算展开；T5 的 "limits" 更多指「设计空间的极限」而非「性能的极限」。

**③ 均分叙事对方差的稀释**：GLUE/SuperGLUE 均分（90.3/88.9）是 headline 数字，但 CB 验证集仅 56 例、F1 波动 ±3.237——均分把高方差任务的噪声摊薄进了几十个子任务的平均里。（推断）这不是造假，而是聚合指标的固有性质：headline 均分的提升未必逐任务稳健，读者应回到 per-task 表格核对置信区间。

**④ C4 的社会性偏差缺席讨论**：源数据记录的清洗规则全是形式性的（标点、句子数、脏词、占位符），没有任何关于语料群体偏差、毒性、地域/阶层代表性的讨论。（推断）这在 2019 年属普遍盲区，但作为被后世大量复用的公共语料，C4 的偏差也随其流行而被成比例放大——「数据基建的社会责任」这一课，是从 C4 这一代才开始补的。

### 5.3 一个历史性误读风险的澄清

后世常把「T5 证明 encoder-decoder 优于 decoder-only」当作定论引用。结合 4.2 节的分析，这句话需要三个限定状语：**在监督式预训练+全模型微调范式下、在 220M/34B 预算下、在以 GLUE/SQuAD 为代表的微调型评测下**。（推断）GPT-3 展示的 few-shot 能力、以及后来 decoder-only 在生成式交互范式中的统治地位，改变的不只是分数，而是**评测范式本身**——T5 的架构结论在其原范式内依然成立，但它没有、也不可能预判范式迁移。

> **一句话小结**：本文的批判火力集中在「结论的适用域」——小预算消融外推到大尺度、均分掩盖方差、架构结论绑定特定范式、C4 偏差无人审计；这些都不推翻论文在其设定内的严谨性，但决定了后人应该如何正确地引用它。

## 六、启示与影响：一篇论文如何预写了 LLM 时代

### 6.1 五条可迁移的启示

1. **「统一接口先行」是研究系统化的前置条件**：text-to-text 把任务多样性折叠进数据格式，才使变量可控的消融成为可能。（推断）今天所有 chat 模型「万物皆 token 序列」的接口设计，精神内核与此同源——想做好实验，先把度量衡统一。
2. **杠杆排序意识：架构 > 目标**：架构选择造成 8~20 分差距，目标变体只有零点几分。（推断）这对资源受限的研究者是重要的资源分配指南——与其在损失函数上雕花，不如把赌注押在结构级决策上；当然，该排序本身也受限于当时的范式（见 5.3）。
3. **数据工程可以被工业化复制**：C4 用一组朴素启发式 + 完全开源发行，证明了「干净的大规模语料」可以是社区公品而非私有壁垒。此后 mC4、The Pile、各类 refined-common-crawl 一脉相承——**开源数据集成为论文影响力的倍增器**。
4. **Scaling 的经验前奏**：60M→11B 单调上升 + 「更长预训练仍有增益」，在 Kaplan scaling law 之前四个月就以工程实测的形式出现。（推断）「模型越大越好、数据越多越好」在 2019 年还不是定律，只是一条被 T5 网格反复踩到的趋势线。
5. **诚实报告方差的规范价值**：主动报告 run-to-run std、指出 CB ±3.237 与 56 例验证集、提醒均分比较需谨慎——这种自我设限的报告风格，是 benchmark 论文的伦理范本。

### 6.2 它直接催生的谱系

- **Instruction tuning 的直系祖先**：T5 的任务前缀 → FLAN（同团队在 T5 上做 instruction tuning）→ T0/Flan-T5 → 今天一切 chat 模型的指令跟随能力（推断：prompt 格式驱动的多任务统一，是 T5 框架最长寿的遗产）；
- **mT5 / Switch Transformer / UL2**：同团队沿 T5 轨迹分别补上多语、稀疏 MoE、混合去噪目标三块拼图——论文自述「未探索稀疏注意力/MoE」的留白恰好是他们自己的下一站；
- **Encoder-decoder 的存续**：Flan-T5、UL2 及各类蒸馏小模型证明该结构在受控生成与端侧场景长期有用，decoder-only 的统治更多是范式选择而非绝对优劣。

### 6.3 局限的走向

- **多语化**（对应对局限②）：mT5 以 mC4 复刻 T5 配方至 100+ 语言；
- **稀疏化**（对应对局限⑤/未启用前沿组件）：Switch Transformer 把 T5 的 encoder-decoder 换上 MoE 前馈层，千亿参数进入实用；
- **目标混合化**（对应对 3.3 的目标之争）：UL2 的 mixture-of-denoisers 承认「没有单一最优目标，只有目标组合」——某种意义上否定了 3.3 节「找一个最好目标」的问题提法本身。

## 总结

《T5》是一次「把混乱变成地图」的浩大工程：它用 text-to-text 统一了任务接口，用 C4 统一了数据底座，用五个消融轴（架构/目标/数据/时长/规模）把 2019 年迁移学习的一团乱麻梳理出明确的杠杆排序——架构选择的差距远大于目标函数的雕花，预训练的红利高度集中于低资源任务，规模与时长在 34B 预算内未见饱和。它以 11B 参数在 18/24 任务上刷新 SOTA（GLUE 90.3、SuperGLUE 88.9、SQuAD F1 96.22），同时在 EnRo 翻译（28.1 vs 38.5）等专精任务上诚实地留下了统一框架的代价清单。它的批判点在于结论适用域：小预算消融外推、均分稀释方差、架构结论绑定特定范式、C4 社会性偏差无人审计。而在历史坐标上，这篇论文最深的印记是那些作者未必自觉的伏笔——任务前缀长成了 instruction tuning，C4 长成了数据工程的行业标准，「更大更好」的趋势线长成了 scaling law。可以说，GPT-3 之后的 LLM 时代所走的很多路，都能在这张 2019 年绘制的地图上找到等高线。
