## §4 方法细节

- **背景**：SSM（S4）是 RNN 与 CNN 的结合，基于经典状态空间模型；连续系统 Eq.(1)：h'(t)=Ah(t)+Bx(t), y(t)=Ch(t)。由输入 x 映射到输出 y，经隐态 h（维度 N）。
- **离散化**：将连续参数 (Δ,A,B) 经规则（如 ZOH, Eq.4）转为离散 (Ā,B̄)。计算可用线性递归（训练并行化用全局卷积）或全局卷积（Eq.3）。关键性质 LTI（线性时不变）：(Δ,A,B,C) 恒定，故可高效但**无法内容选择**。
- **选择机制（Selection）**：让 (Δ,B,C) 或部分参数成为输入的函数 s(x)=Linear(x)/Broadcast(Linear(x))，τ=softplus → 模型变为 time-varying（参数带长度维 L）。这打破卷积等价性，须用递归 scan。
- **动机（压缩视角）**：序列建模核心是"把上下文压缩进小状态"。注意力不压缩（KV cache 全存）→ 慢；循环模型状态有限 → 快。效率 vs 效果的权衡取决于状态压缩质量。合成任务揭示 LTI 失败模式：Selective Copying（随机间距，需内容感知）与 Induction Heads（关联记忆）。架构门控（gating）不在序列轴上交互，不足；选择机制才解决。
- **硬件高效算法（Selective Scan）**：三技术——kernel fusion、parallel scan、recomputation。naïve 递归 O(BLDN) FLOPs，卷积 O(BLD log L)。为省内存：不物化状态 h(B,L,D,N)，而把参数从 HBM 装入 SRAM，在 SRAM 做离散化+递归，只写输出 (B,L,D) 回 HBM。用 work-efficient parallel scan 打破序列性；用 recomputation 反向重算中间态。内存需求与 FlashAttention 优化版 Transformer 持平。
- **Mamba 架构**：合并 H3 的注意力式 block 与 Transformer 的 MLP block 为单一均质 block（借鉴 GAU）。模型维 D 按扩展因子 E 扩展；大多数参数在线性投影（3ED²=输入投影 2ED² + 输出 ED²），内部 SSM 贡献小。实验固定 E=2，用两层 block 匹配 Transformer 的 12D² 参数（MHA+MLP）。激活 SiLU/Swish（Gated-MLP→SwiGLU）；可选 LayerNorm（借鉴 RetNet 位置）。
- **算法2（S6）**：B:(B,L,N)←s_B(x), C:(B,L,N)←s_C(x), Δ:(B,L,D)←τ(Parameter+s_Δ(x))，A,B:(B,L,D,N)←discretize，y←SSM(A,B,C)(x)（仅递归 scan）。Time-varying，仅递归模式。

## §5 实验结果要点

- **4.1 合成**：Selective Copying——S4→S6 选择机制轻易解决；门控架构（H3/Mamba-with-Hyena）只部分改善。Induction Heads（2 层，序列长 256 训练，vocab 16；测试 2^6=64 至 2^20≈1,048,576）——Mamba 完美解决并外推 4000×，其他方法 ≤2×。Mamba 用 D=64，其他 D=128。
- **4.2.2 语言下游（Table 3）**：与 Pythia/RWKV 同 tokenizer 对比（300B tokens，Mamba/Pythia 上下文 2048，RWKV 1024）。每尺寸 Mamba 全线最佳。例：Mamba-2.8B avg 63.3 vs Pythia-2.8B 59.1、RWKV-3B 59.6；Mamba-1.4B avg 59.7 vs Pythia-1.4B 55.2。Mamba-370M avg 50.0 已近 Pythia-1B 51.9。Mamba 匹配两倍尺寸基线（Pile ppl LAMBADA HellaSwag PIQA Arc-E Arc-C WinoGrande）。
- **4.3 DNA**：HG38 单个人类基因组约 4.5B tokens 预训练；长序列分类任务 Mamba 优于 Hyena/先验 SOTA，长上下文性能随序列增长提升（达百万级）。
- **4.4 音频（SC09，Table 4/5）**：Mamba 6.1M 参数 FID 0.94、mIS 88.54；24.3M 时 FID 0.67、mIS 144.9、AM 0.36，优于 SaShiMi(SaShiMi 0.74 AM)、Hyena、Transformer。FID 较先前 SOTA 降超一半。
- **4.5 速度（Figure 8）**：scan 训练比标准实现快 40×；比 FlashAttention-2 在 >2K 序列更快；推理 Mamba 4–5× 吞吐（两尺寸 Mamba 6.9B/1.4B 均超高吞吐，Transformer 在长序列/大 batch 时 OOM）。
- **4.6 消融**：Table6 Mamba block ≈ H3 但更简；选择性 SSM(S6) 大幅改善（Hyena/H3/S4 系 10.2–10.8 vs Mamba+S6 8.69）。Table7 Δ 最关键（单独 Δ 9.81 vs 无选择性 10.93），多选择性参数协同 8.71。Table8 实值对角初始化（S4D-Real）优于复值 S4D-Lin。Table10 N=16 提供 >1.0 ppl 改进仅 +1% 参数（验证核心动机）。

## §6 局限

1. **Scaling 受限**：实验模型 ≤~350M 参数（Chinchilla tokens），低于 Llama/RWKV/RetNet 等 7B 级；需验证更大规模。
2. **无免费午餐（连续-离散光谱）**：选择性增强离散模态（文本/DNA）但可能削弱 LTI 擅长的连续信号（音频/视频）模态；需权衡。
3. **下游能力（affordances）**：未见成效验证 Transformer 的微调/提示/ICL/RLHF/量化等生态。
4. 复值→实值 SSM 仅推理硬件更省，效果差异小；超大规模工程挑战（scaling SSM 需额外工程调整）本文未讨论。
5. 长上下文优势依赖特定任务（合成/音频/基因组）；通用语言推理的百万级上下文未系统验证。
