## §4 方法细节

Model Card 未披露架构/训练配方，方法性内容如下：

- **四维评估框架**（§3.4）：Scientific Discovery（AInstein Bench 科学编码 + BABE 生物多模态推理）；Vibe Coding（NL2Repo-Bench：从自然语言规格端到端构建整个仓库，考跨文件一致性与依赖管理）；Context Learning（CL-Bench/KOR-Bench/DeR2 噪声长文档抽取利用 + 内部客服 Q&A 与复杂工作流）；Real-World Tasks（GDPVal-Verified rubric 自动评分、XpertBench、WorldTravel 多步规划）。
- **长尾专业知识基准设计**（§3.1.1）：LPFQA（专业论坛真实问题）、Encyclo-K（书籍级原子知识语句动态组合，支持 zero/few-shot ICL 探测训练前后知识内化）、HLE-Verified（领域专家复核原 HLE 中模糊/错误题目后的可靠子集）。
- **Agentic 评测公平化处理**（§3.3）：竞品分数取"官方报告与自己复测的最大值"；重构测试脚本（预建镜像、修复退化环境、内网镜像源）、质量过滤剔除不可复现用例（多容器 Compose、参考解不过自身验证、非确定性行为、异常磁盘/网络依赖）；Terminal-Bench 2.0 因网络限制剔除 3 题（脚注标明 Terminus2 脚手架）。
- **Thinking with Tracking**（§4.3）：TOMATO 运动感知上提示模型在推理中显式输出逐帧边界框再判定运动类型，对 Gemini 与 Seed 均有效（TOMATO 59.9→65.3）。
- **VideoCut**：指定起止时间戳以 1–5 FPS 重采样回放片段捕获高帧率细节；Seed2.0 家族默认启用。
- **Model-on-Model 自动诊断管线**（§5.5）：用 LLM 分析同级模型在异构基准上的评测产物（指标 + token 用量/格式合规/轮次/emoji 频率/best-of-N 统计 + 实例级轨迹），三层架构（数据处理/场景自适应分析工作流/报告合成），产出弱点、策略权衡与行为问题（code-switching、重复 CoT 模式）的结构化发现。
- **部署行为分析**（§2）：MaaS 数据显示互联网行业流量绝对主导，非结构化信息处理为最大场景；agentic coding 查询中前端开发与 bug fix 显著主导，Vue.js 采用率为 React 三倍以上（反映中国大陆生态）。

## §5 实验结果要点

1. **语言**（Table 3）：处于国际第一梯队——数学类多项最高（BeyondAIME/IMOAnswerBench/AIME2025），知识与长尾类 Encyclo-K 65.7 最高、HealthBench-Hard 29.1 最高；检索型长上下文（MRCR 54.0 vs GPT 89.4、Graphwalks BFS 68.9 vs 98.0）与幻觉抑制（FactScore 71.2 vs ~92）明确落后并自认。
2. **小模型梯队**（Table 4/12/14）：Seed2.0 Lite 在高效档多数基准居首或次席（SpreadsheetBench 82.3、BrowseComp 72.1、WorldTravel TEXT 24.0），配合低价定位大规模部署；Mini 主打 <\$0.50/M decode。
3. **视觉/视频**（Table 8/9）：相对 Seed1.8 全面跃升（如 HiPhO +15.8、ArcAGI2-Image 1.3→43.3），图像九类中文档与长上下文、空间理解优势突出；视频在推理/运动感知/流式三域推至 SOTA，但 ViSpeak（78.5 vs Gemini 89.0）与 VideoMMMU/MMVU 仍略逊。
4. **Agentic**（Table 11）：搜索、深度研究、视觉 agent 为最强域；编码 agent 稳定一线但非顶尖（Terminal-Bench 2.0 55.8 vs GPT-5.2 62.4；SWE-Evo 与 Claude 差距约 3 倍，作者明示为优先改进方向）。注意脚注声明部分竞品官方分数与对齐设置复测差异巨大（如 BrowseComp Sonnet 43.9→29.5）。
5. **高级任务**（Table 13）：科学发现 AInstein 47.7 最高；ToB 场景（客服问答/信息抽取/意图识别/K12）多项最高印证生产优化方向；vibe coding 端到端仓库生成与上下文学习是最大缺口。
6. **用例定性证据**（§5）：FEAL 已知明文攻击采用 meet-in-the-middle 而非暴力枚举且解法异于基准参考实现；DVC 跨版本升级 79 turns 仅凭 release notes 以测试套件为验收 oracle；FreeCAD/CapCut 展示状态跟踪与 UI 出错自恢复；Golgi 多组学实验方案被评审为"超出典型 PhD 学生水平"（同时指出 Giantin 标记选择欠妥）。

## §6 局限

1. **编码与仓库级生成差距明确**：SWE-Evo 8.5 vs Claude 27.1、NL2Repo-Bench 27.9 vs GPT 49.3、NL2Repo Pass@1 仅 3.0——作者自己点名向 Claude 学习的方向。
2. **长尾事实知识与幻觉抑制不足**：SimpleQA-Verified 36.0（vs Opus 48.6）、FactScore 71.2（vs ~92）、SuperGPQA 落后 Gemini-3-Pro（68.7 vs 73.8）。
3. **检索型长上下文薄弱**：MRCR v2 54.0、Graphwalks BFS 68.9 显著低于 GPT-5.2；作者辩称"对真实用户体验影响有限"，属未经外部验证的判断。
4. **运动感知距人类尚远**：TOMATO 59.9/65.3（tracking 增强）vs 人类 95.2；ViSpeak 落后 Gemini 约 10 分。
5. **评测口径自利风险**：竞品取"官方与自测最大值"、内部基准占比高（Encyclo-K/HLE-Verified/DeepSearchQA/ToB 系列/WorldTravel 等）、Terminal-Bench 剔除 3 题且换用自家 agent 框架，横向可比性需谨慎。
6. 纯 Model Card：无参数量/架构/数据/训练成本披露；GUI 与科研用例为精选个案，无成功率统计。
