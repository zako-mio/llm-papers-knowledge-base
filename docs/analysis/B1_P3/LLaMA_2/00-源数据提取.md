## §3 核心主张与关键数字表

> 数字与原文一致，括号注出处。

### 3.1 预训练基础（§2）

- 参数量：7B / 13B / 70B（本文不发布 34B 的 Chat 版本，源数据提取不含其数字）| §1
- 训练 token：2T | §2.1
- 上下文长度：4096（预训练时）| §2.2
- 预训练数据：2T tokens，全部来自公开可用数据（不含 Meta 自家产品/用户数据）；语料不超过 2022-09 之前 | §2.1
- 预处理：去重（sentence-level + document-level）、Claude 的 c4 去重思路、基于 langdetect 的语言过滤、用 LLaMA-1 分词器 | §2.1
- 微调：绝大多数（接近 100%）公开可用 | §2.1
- 优化器：AdamW；7B/13B/70B 与 LLaMA-1 的差异点：70B 用 AdamW（LLaMA-1 的 65B 用 Adam）| §2.2
- 学习率衰减：WSD（Warmup-Stable-Decay）；7B/13B/70B 略不同 | §2.2
- 预训练后 loss（Table 1，FKB 数据集）：7B = 2.37、13B = 2.09、70B = 1.98（越低越好）| §2.3

### 3.2 预训练模型评测（§2.3 / Table 1）

| 规模 | FKB loss | 相对 LLaMA-1 提升 |
|---|---|---|
| 7B | 2.37 | — |
| 13B | 2.09 | 平均优于同规模 LLaMA-1 |
| 70B | 1.98 | 显著优于同规模各开源模型 |

- 对比参照：MMLU 5-shot、BIG-bench、Code、CommonSense（HellaSwag PiQA SIQA WinoGrande）、MMLU（原文 §2.3）、AGIEval、Reading Comprehension（SQuAD 等）| §2.3
- 关键结论：预训练数据数量是 2 倍于 LLaMA-1 的 1.4T→2T，显著优于同规模 LLaMA-1；训练数据是主要提升来源 | §2.3

### 3.3 微调（§3）

**SFT 阶段**（§3.1）：
- SFT 数据：公开指令数据 + 采集 27,540 条高质量演示（从 100 万+ 原始人工标注中筛出）| §3.1
- 对比 SFT baselines：LLaMA 1/2 7B-70B（不含 Chat）、Vicuna（LLaMA 衍生）、开源可复现、待验证（未公开）
- 训练：2 epoch，学习率 2×10^-5 左右，seq len 4096 | §3.1

**RLHF 阶段**（§3.2）：
- 帮助性/真实性（helpfulness & truthfulness）+ 安全性（safety）三轨 reward model | §3.2.2
- reward model 数据集：帮助性/安全性分别采集标注比较；总计注解累积（帮助性 + 安全性）| §3.2.2
- RM 训练：用偏好比较（binary），转移建模为 5 分开（更细粒度）；损失 = 一组 pair 的 hinge + 其他 pair 的 sigmoid 混合 | §3.2.2
- GHM（Gloss Hinge / 依据原文为 "hinge"）边缘损失：只对有差异的 pair 用 hinge，避免"选择不诚实 / 完全不同意"等 pair 的噪声 | §3.2.2

### 3.4 RLHF / Chat 评测关键数字（§3.2.4、§3.5、Table 5）

- 人类评测（轮次制，帮助性 + 安全性）：Llama 2-Chat 70B 对 GPT-4 的胜率（帮助性）在单轮/多轮场景 ≈ **36% / 53%**（附录）；GPT-4 整体最强，但 Llama 2-Chat 在若干轮次追上 | §3.5
- 与开源竞品对比：Llama 2-Chat 在多个帮助性/安全性偏好评测中均为 SOTA（open 模型），优于同规模 OpenAI-eligible open 模型清单中除 GPT-4 外的全部开源模型 | §3.5
- 关键论断：在人类评测中，由人类标注者对开源/闭源模型做"帮助性+安全性"成对比较时，Llama 2-Chat 与 50%+ 类"可替代闭源模型（GPT-3.5 等）"；Llama 2-Chat 可与 GPT-3.5 正面竞争，但 GPT-4 仍明显领先 | §1 / §3.5
- PPO 配置：γ（对抗）只在最具挑战的会话（多轮）触发，帮助性/真实性/安全性三签 RM；迭代批训练（用当前策略对旧迭代的 RM / 数据迭代采样）| §3.2.4
- 数据集规模：SFT 约 54k 有效（含公开与自采）；RLHF 帮助性 36,569 比较、安全性 12,283 比较（合计原文标注规模）| §3.2.2

### 3.5 安全（§3.3）

- 安全训练分三阶段：安全预训练（Safety aligned pretraining）、安全 RLHF（safety RM + 安全通用偏置）、安全上下文蒸馏（safety context distillation）
- 提升点：与 LLaMA-1 相比，Llama 2-Chat 的"拒绝（refusal）率"上升、攻击时安全违规下降；更遵守安全准则
- 红队（red-teaming）：系统性地生成提示，让模型产生符合安全准则的输出，训练安全 RM

### 3.6 上下文扩展 + Ghost Attention（§3.6、§3.7）

- 预训练 4K → 用长文本微调（1M tokens，32K 上下文）→ 连续（contiguous）训练 32K → 多轮对话综合；成功扩展到 32K | §3.6
- Ghost Attention（GAtt）：让模型在长多轮对话中"记住"全局指示（system message、提示、rule、风格），通过在监督微调数据中"重复全局 instruction 到每轮"来生成合成数据 | §3.7

### 3.7 核心结论（§6 & 摘要）

- 发布 7B/13B/70B 预训练 + Llama 2-Chat 微调；**开放商用许可**（LLaMA 2 Community License，限制 >700M 月活用户需许可）
- 论文一句话定位："高配开源 chat，可当作 GPT-3.5 级别的闭源替代方案"

## §4 方法细节

### 4.1 预训练（§2.2）
- 7B/13B：AdamW + WSD（Warmup-Stable-Decay）学习率；70B 亦然；与 LLaMA-1 的差异点 70B 用 AdamW。
- 预训练数据 2T tokens：参考 The Pile 的公开子集拼接 + 自采高质量中文/英文/源代码等公开语料；以 text-only（不含 image）为主。重点：**公开可用**、不含 Meta 用户数据。
- 数据去重（sentence 级别）；语言过滤（langdetect）；混入部分中文与代码提升代码/推理能力。
- 训练 token 2T，相对 LLaMA-1（1.4T）提升 40% 数据量。

### 4.2 微调（§3）流程
1. SFT：公开指令数据 + 27,540 高质量人工标注演示（从 100 万+ 原始数据中筛）
2. RLHF 第一项——reward model：三轨（helpfulness/truthfulness/safety）RM，采用 pair 比较损失；安全 RM 采用二分类（好/坏），帮助性 RM 用更细的序数。
3. RLHF 第二项——rejection sampling：用当前最优 RM 对新样本排序，取顶级样本作 SFT 重训（相当于迭代式自我蒸馏）；注意：rejection sampling 采样用 RL 采样策略，保留 best-of-N
4. RLHF 第三项——PPO：以 RM 为奖励，加 help/truth/safety 三签；用 KL 正则；γ 对抗在最有挑战的会话触发

### 4.3 奖励模型细节（§3.2.3）
- 帮助性 RM 打分：1–5 分开
- 安全性 RM：二分类（safe / unsafe）
- GHM（Gloss Hinge）损失：只对有分歧的对使用 hinge；将"相同评分"的 pair 从 hinge 中剔除，减少标注噪声与优化偏移。

### 4.4 安全对齐（§3.3）
- 安全预训练：通过安全数据（含高风险提示被安全回应的比例）预训练阶段即注入安全行为
- 安全 RLHF：独立 safety RM + 通用偏置（global bias in softmax?——安全优先）
- 安全上下文蒸馏：以标注员生成的"安全上下文"（举例安全答法）微调模型

## §5 实验结果要点

- 预训练：2T tokens 训练，7B/13B/70B 各自在标准基准（MMLU、BIG-bench、TriviaQA、ReadingC、Code 等）全面优于同规模 LLaMA-1，部分超过同规模开源模型。
- SFT/RLHF：74B Llama 2-Chat 在人类评测（helpfulness+safety 成对比较）上显著优于开源 chat（Vicuna 等），与 GPT-3.5 正面竞争；72B 与 GPT-4 仍有差距（GPT-4 在单轮/多轮胜率各为 36% / 53%——**论文表述：GPT-4 对 Llama 2-Chat 70B 的帮助性胜率（从 Llama 2-Chat 视角看）**）。
- 关键论断：在多轮评测里，模型在"helpfulness"与"truthfulness"两个轴上都与 GPT-4 有差距，但处于公开模型最优梯队。

## §6 局限（原文 §4 / §6 与作者自述）

- **闭源竞争**：GPT-4 仍更强（尤其单轮回答问题更详尽）；Llama 2-Chat 长于多轮/闲聊，短于系统性检索/工具。
- **能力范围**：强在开放（open-ended）与百科类问题、弱在无数学/代码与深度推理的专项。
- **context 长度**：32K context 虽好，但主模型仍带训练"遗忘"问题，长上下文记忆不完全可靠。
- **价值取向与安全**：刻意与"安全红队"对齐（RLHF 偏向安全至上），可能牺牲对"开放常识问题"的直答；开放性给用户武器化风险；安全对齐易"过度拒绝"，对常规问题也安全拒答。
- **开源许可**：LLaMA 2 Community License 仍有限制（>700M 月活需 Meta 许可），不是纯 Apache/MIT（社区争论点）。
- **未公开全部细节**：34B 版本未发布 Chat；预训练/微调配置的某些细节与启发式（如 GHM、WSD 的确切配比）不完全可复现。
