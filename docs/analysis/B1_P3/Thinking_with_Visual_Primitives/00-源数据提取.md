## 3. 摘要要点

- 问题：MLLM 的 CoT 范式仍局限于语言空间；高分辨率裁剪（Thinking with Images）只解决 Perception Gap，忽视更根本的 Reference Gap——自然语言的歧义无法提供精确无歧义的指针指向复杂空间布局，导致需要严格 grounding 的任务中逻辑崩塌。
- 方法：将空间标记（点 point 与边界框 bounding box）提升为"最小思维单位"（minimal units of thought），直接交织进推理过程。模型可以"边推理边指点"（point while it reasons），把认知轨迹锚定在图像物理坐标上。
- 架构：高度优化的架构 + 极致视觉 token 效率（Compressed Sparse Attention，视觉 KV 压缩 4×）。
- 结论：紧凑模型规模 + 显著更低的 image-token 预算，在挑战性视觉 QA 套件上达到前沿竞争性能，匹配或超越 GPT-5.4、Claude-Sonnet-4.6、Gemini-3-Flash。通往更高效可扩展的 System-2 多模态智能之路。

## 4. 叙事脉络分析

叙事结构为『问题→双缺口→类比动机→方法展开（数据+后训练）→实验对比→局限→结论』变体：

1. 开篇以 Kahneman『System 2』立高维目标，指出 LLM 内部 CoT 已强但『与视觉域脱节』。
2. 引入核心创新点 Reference Gap：先承认既有工作用高分辨率裁剪/动态 patch 解决了 Perception Gap（『看见≠推理』），再批评它们忽视更根本的 Reference Gap——自然语言在连续视觉空间里无法充当精确无歧义的指针，导致密集计数/多步空间演绎中『思维丢失所指实体』级联幻觉。
3. 划清与先行工作（GRIT/Visual CoT/grounding 相关）的边界：它们只把 grounding 当事后验证、困于高分辨率『看见型』基准、依赖昂贵人工监督，未触及 Reference Gap 的结构性推理。
4. 用人类学类比建立动机：人走迷宫/数密集物体会用『手指指示』（deictic pointers）降低认知负荷，故提出『Point-to-Reason』协同。
5. 方法分两条线展开：架构侧用 CSA 做极端 token 压缩（2800+→~90 KV 条目），数据侧做大规模 web 抓取+两级过滤+四类任务 cold-start，再走『专才训练-合并』后训练管线。
6. 实验用『公共基准+自建基准』双轨对比 GPT-5.4/Claude-Sonnet-4.6/Gemini-3-Flash 等，拓扑推理（迷宫/路径追踪）差距最大。
7. 结论回收开篇：System-2 多模态智能的关键不是『看得更多像素』，而是『构建语言与视觉间精确无歧义的指称桥梁』。

## 5. 方法模块

### 5.1 架构（2.2）— 视觉 token 极致压缩
- LLaVA 式结构：DeepSeek-ViT 提特征 → 与语言指令拼成交错序列 → 输入 LLM
- DeepSeek-ViT：自研、任意分辨率、14×14 patch；ViT 输出做 3×3 空间压缩（9 邻 token 沿通道合并为 1）
- LLM 主干 DeepSeek-V4-Flash：284B 总参/13B 激活的 MoE
- Compressed Sparse Attention (CSA)：把每个视觉 token 的 KV cache 再压缩 4×
- 压缩链路示例（756×756=571,536 像素）：2,916 patch token → 3×3 压缩后 324 视觉 token → CSA 后仅 81 个视觉 KV 条目；全程总压缩比 7,056×
- ViT 输出视觉 token 数限制在 81-384，超分辨率等比缩放

### 5.2 预训练（2.3）— Visual Primitives 定义 + 大规模数据构造
- Visual Primitives = 两种标准视觉输出格式：bounding box 与 point
- box 优势：精确位置+尺度；point 优势：抽象视觉引用（运动轨迹、拓扑推理）
- 为何优先大规模扩 box 数据（3 理由）：①标注确定性（box 紧包对象确定性强，point 具歧义、遮挡下 point 可能落到前景遮挡物上）；②任务泛化（box 由两点定义，天然含 point 表示）；③信息丰富度（box 含宽高几何信息）
- 数据获取：跨网站大规模 web 爬取（HuggingFace API 过滤 ObjectDetection/Grounding 标签，按点赞/下载量初筛，剔除 val/test 分裂防泄漏），LLM agent 解析 README.md 自动统一存储格式，去重后得 97,984 个 box-grounding 数据源
- Step I 语义审查（MLLM 驱动，三图采样打分 0-10 + KEEP/DISCARD 理由）：剔除 ①无意义机器码/乱码标签（纯数字类）②不可泛化私有实体（'MyRoommate'、'ID_Card_1'，名人保留）③有歧义缩写与主观评价（'OK'/'NG'）；保留 43,141 个
- Step II 视觉-几何质量审查：剔除 ①严重漏标（漏标率>50%）②严重截断/偏移（切掉头/轮子不可接受，微松可容忍）③MegaBox（框>90% 图面积且三图均如此）；保留 31,701 个
- 类别均衡采样（每类随机 N 个，N=1,000，全局去重）→ 最终 40M+ 高质量样本
- 统一格式：box 任务 '<|ref|>TARGET<|/ref|><|box|>[[x1,y1,x2,y2],...]<|/box|>'，坐标 0-999 离散整数、多实例从左到右排序；point 任务 '<|point|>[[x1,y1],...]<|/point|>'（不输出对象名，支持轨迹等抽象表示）
- 通用多模态数据用 web 抓取真实数据，不用 LLM 蒸馏合成；含公开数据集；预训练总 token 达 trillions

### 5.3 四类任务 cold-start 数据（2.4）
- **Counting（~10,000 样本）**：粗粒度（多密集检测数据集聚合，三维过滤：密度/框大小/recall；思维三步协议=意图分析→批量 grounding（Batch Grounding 一次性定位全部候选，防重复枚举）→基于视觉原语的统计求和；严格校验框坐标=元数据、语法、数值一致）；细粒度（GQA 场景图生成问题→思维合成→对负样本构造（目标计数为 0 的对抗样本增强抗幻觉））
- **Spatial Reasoning & General VQA（9,000 样本）**：自然场景用 GQA（思维=意图分析→对象 grounding→关系推理；拥挤场景用多属性约束唯一指定目标）；合成场景用 CLEVR 工具链（可控密度，3D 坐标投影到 2D box 监督，含对象 ID 级引用）；负样本增强训练『faithful refusal』（对象/关系不存在时基于视觉证据诚实拒绝）
- **Maze Navigation（460,000 样本）**：DFS/Prim/Kruskal 生成；三种拓扑=矩形网格/同心环圆形/六边形蜂巢；不可解迷宫（在可解路径中段加墙，外观似可解）；难度=网格大小（easy 少量局部连通检查→nightmare 数百步长距离组合回溯），每难度设最小分辨率保证原语可辨（难度源于推理而非视觉模糊）；思维=DFS 探索/回溯逐坐标锚定的口头链，输出可解性+验证路径
- **Path Tracing（125,000 样本）**：Bézier 曲线纠缠图；核心挑战=交点消歧（几何连续性原语决定分支）；均匀风格模式（同色同线宽，剔除颜色捷径，强制真正内化原语）；难度=曲线数量与曲率振幅；思维=沿目标曲线采样坐标序列（直段稀疏、高曲率/密集交叉处更细粒度，模拟人慢下来细看）

### 5.4 后训练管线（2.5）— trains specialists—then—merge
- **Specialized SFT**：70% 通用多模态+纯文本 + 30% 专项；box（thinking-with-grounding F_TwG）与 point（thinking-with-pointing F_TwP）分开训练防模式冲突
- **Specialized RL**：GRPO（沿用基座超参）；RL 阶段不监督思维中的视觉原语（冷启动已严格校验，提升 RL 数据可扩展性，只需图像+问题+最终答案）；三类 RM 并发监督
  - Format RM（规则，0-1）：校验视觉原语表示格式正确；对 grounding 额外检查冗余（重复框，防 SFT 模型无限循环生成框）
  - Quality RM（LLM 生成式 GRM）：冗余度、思维与最终回答一致性、自相矛盾、框引用对象是否有意义实体、防 reward hacking（伪造假 ground truth 骗 RM）；打分三档 [0.0,0.5,1.0]
  - Accuracy RMs 按任务定制：Counting=规则式平滑指数衰减 R=α·exp(−β|ŷ−y|/(|y|+1))，α=0.7,β=3（按相对误差，接近正确轻罚）；Spatial/VQA=LLM GRM 对思维与回答分别打分取平均；Maze=规则式加权（因果探索进度/探索完整性/墙违规惩罚/最终路径有效性/答案正确性，可解迷宫前两项恒 1，不可解迷宫后两项恒 1）；Path Tracing=规则式加权（双向轨迹精度=预测点→真值多段线最小距离前向+真值点→预测线反向取平均、端点精度、轨迹连续性惩罚、答案正确性）
  - RL 数据难度分档：每样本 N 次 rollout，全对=Easy，部分对=Normal，全错=Hard；只选 Normal 做 GRPO
- **Unified RFT**：专家模型 E_TwG/E_TwP rollout 生成 RFT 数据，保留 Normal + 随机抽 5% Easy（防简单场景灾难性遗忘）；从基础预训练 checkpoint 训增强 SFT 模型 F_U；训练配置与 SFT 完全一致仅换数据
- **On-Policy Distillation**：反向 KL 蒸馏，L_OPD=Σᵢwᵢ·D_KL(π_θ∥π_Eᵢ)，全词表 logit 蒸馏；教师=E_TwG、E_TwP，把两个专家能力合并进单一统一模型

## 8. 局限与未来工作（作者自述）

1. 受输入分辨率限制，细粒度场景性能次优，偶发视觉原语输出不精确——未来可与现有『Perception Gap』方法（高分辨率裁剪等）集成形成互补
2. 当前『thinking with visual primitives』能力依赖显式 trigger 词激活——未来目标是让模型根据上下文自主决定何时调用该机制
3. 用 point 解决复杂拓扑推理仍是严峻挑战，当前跨场景泛化有限——拓宽该技术适用性与鲁棒性是重要未来方向

## 9. 关键术语表

| 术语 | 定义 |
|---|---|
| Perception Gap | 感知缺口：模型看得到细节与否的问题，由高分辨率裁剪/动态 patch 缓解；但『看见≠推理』 |
| Reference Gap | 指称缺口（本文核心新概念）：自然语言无法在连续视觉空间充当精确无歧义指针，导致密集计数/多步空间演绎中思维丢失所指实体、级联幻觉 |
| Visual Primitives | 视觉原语：spatial markers（bounding box 与 point），被提升为『minimal units of thought』（最小思维单位），直接交织进推理轨迹 |
| Point-to-Reason | 边推理边指点的协同机制：把抽象语言思维锚定到图像物理坐标；类比人类走迷宫/数密集物体时的指示手势（deictic pointers） |
| Thinking with Grounding (TwG) | 用 bounding box 作为思维原语的范式（对应专家模型 F_TwG/E_TwG） |
| Thinking with Pointing (TwP) | 用 point 作为思维原语的范式（对应 F_TwP/E_TwP） |
| Compressed Sparse Attention (CSA) | 来自 DeepSeek-V4-Flash 的压缩稀疏注意力：把每个视觉 token 的 KV cache 压缩为 1 条，视觉 KV 再压缩 4× |
| Batch Grounding | 批量 grounding：思维中一次性定位所有候选对象（粗粒度计数更高效，防重复枚举） |
| On-Policy Distillation (OPD) | 基于学生自身生成轨迹学习教师输出分布的反向 KL 蒸馏（全词表 logit），用于把 E_TwG/E_TwP 两专家合并进统一模型 |
| GRPO / Format RM / Quality RM / Accuracy RM | Group Relative Policy Optimization 强化学习算法；三类奖励模型分别校验格式、质量（LLM GRM）与任务精度（规则/LLM 定制） |
| HAI-LLM | High-Flyer 自研基于 PyTorch 的轻量分布式训练框架（训练与评测用） |
| Deictic Pointer | 指示指针：人类用指尖动作降低认知负荷的认知策略，本文方法的人类学灵感来源 |
