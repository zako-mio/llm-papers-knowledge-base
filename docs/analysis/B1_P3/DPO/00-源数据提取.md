## §4 方法细节
- 背景 RLHF 流程（Section 3）：
  1. SFT：在高质量指令数据上对预训练 LM 做监督微调得 π^SFT。
  2. Reward Modeling：用 π^SFT 采样响应对 (y1,y2)，人工标注偏好 y_w≻y_l|x；假定偏好由潜在 reward r*(x,y) 通过 Bradley-Terry 模型生成：p*(y1≻y2|x)=σ(r*(x,y1)-r*(x,y2))。用最大似然拟合 r_φ；常将 r_φ 以 π^SFT + 顶层线性层初始化；并归一化使 E[r_φ(x,y)]=0。
  3. RL Fine-Tuning：max E[r_φ(x,y)] - β·D_KL[π_θ(y|x)‖π_ref(y|x)]；π_ref=π^SFT，π_θ 亦初始化为 π^SFT；因离散生成不可微，用 PPO(max r_φ - β(logπ_θ-logπ_ref))。
- DPO 关键推导：
  - 给定 KL 约束下的最优解形式：π_r(y|x) = (1/Z(x))·π_ref(y|x)·exp(r(x,y)/β)（Eq.4），Z(x) 为 partition function（难估计）。
  - 用 change-of-variables 把 reward 反解为 policy：r(x,y) = β·log(π(y|x)/π_ref(y|x)) + β·log Z(x)（Eq.5）。
  - 代入 Bradley-Terry，partition function Z(x) 消去，人类偏好概率仅由最优 policy 与 reference policy 表达（Eq.6）。
  - 得到最大似然目标（DPO loss，Eq.7）：L_DPO(π_θ;π_ref) = -E_{(x,y_w,y_l)~D}[ log σ( β·log(π_θ(y_w|x)/π_ref(y_w|x)) - β·log(π_θ(y_l|x)/π_ref(y_l|x)) ) ]。
  - 同法可推广到 Plackett-Luce（Appendix A.3）。
- DPO 梯度直觉：∇_θ L_DPO = -β·E[ σ(r̂_θ(y_l)-r̂_θ(y_w)) · (∇_θ log π(y_w) - ∇_θ log π(y_l)) ]，其中 r̂_θ(x,y)=β·log(π_θ(y|x)/π_ref(y|x))。即增大 y_w 似然、减小 y_l 似然，且由隐式 reward 对 y_l 的高估程度加权。
- DPO 流程（两步）：①用 π_ref 为每个 prompt x 采样 y1,y2，标注人类偏好，构建离线数据集 D；②固定 π_ref 与 D、给定 β，最小化 L_DPO。若 π^SFT 不可用（无标准 SFT），用 preferred completion 先拟合 π_ref。
- 理论（Section 5）：
  - Definition 1：reward 等价类 r(x,y)-r'(x,y)=f(x)。
  - Lemma 1：同等价类的 reward 在 Bradley-Terry/Plackett-Luce 下诱导相同偏好分布。
  - Lemma 2：同等价类诱导相同最优 policy。
  - Theorem 1（mild assumptions）：所有与 Plackett-Luce/BT 一致的 reward 类都可用 r(x,y)=β·log(π(y|x)/π_ref(y|x)) 表示（证明思路：投影 operator f 归一化 partition function，不损失等价类泛化性）。该参数化不约束可表示 reward 类，且能精确恢复最优 policy。
  - 5.2：把 actor-critic 不稳定归结为缺少归一化项 f(r,π_ref,β)（reference policy 的 soft value function）；无 baseline 时 policy gradient 高方差；PPO 常用单样本 Monte-Carlo human-completion baseline 归一化，而 DPO 的参数化天然无需 baseline。
- 数据集：
  - 情感控制：IMDb 电影评论前缀 + 预训练情感分类器构造偏好对；SFT 用 GPT-2-large。
  - 摘要：Reddit TL;DR 数据集 + Stiennon 等的人类偏好；SFT 用 GPT-J（human-written forum+post summaries）。EPFL 模型链接 CarperAI/openai_summarize_tldr_sft。
  - 单轮对话：Anthropic Helpful and Harmless（HH）数据集（约 170k 对话），每段含偏好对；无标准 SFT，用 off-the-shelf（Pythia-2.8B）在 preferred completion 上微调出 SFT 模型。
- 对比方法：DPO、zero-shot GPT-J、2-shot Pythia-2.8B、SFT、Preferred-FT、Unlikelihood、PPO（学 reward）、PPO-GT（oracle，含 off-the-shelf 与改进归一化版）、Best-of-N。

## §5 实验结果要点
- 情感控制（可控 reward-KL frontier）：DPO 在所有 KL 值下给出最高 expected reward，**严格支配 PPO**，且优于能访问 ground-truth 的 PPO-GT；同为 reward-KL tradeoff，DPO 更高效。
- 摘要（Reddit TL;DR，GPT-4 评判）：DPO temp0 胜率约 61% > PPO 最优 57%；DPO 最大胜率超过 Best-of-N baseline；DPO 对采样温度更鲁棒（PPO 高温可退化为 base GPT-J），Preferred-FT 相对 SFT 无显著提升；DPO(0.25) 被人类 58% 偏好 over PPO(0)。
- 单轮对话（Anthropic-HH）：DPO 是唯一计算高效又优于 preferred completion 的方法，与计算昂贵的 Best-of-128 相似或更好；PPO 模型无法找到超过 base Pythia-2.8B 的 prompt/温度。
- 分布泛化（CNN/DailyMail OOD）：DPO win rate 0.36(0)/0.31(0.25) 显著高于 PPO 0.26/0.23，尽管 DPO 不用 PPO 使用的那部分未标注 Reddit prompts。
- 收敛速度：DPO 相对较快收敛（Figure3）。
- 人类 vs GPT-4 评判验证：人与 GPT-4 一致性(DPO 70-78%、SFT 77-86%、PPO 71-85%)与人类彼此一致性(65-87%)相当，证明 GPT-4 是合理的人类评价代理；GPT-4(C) prompt 更代表人类，故用作 6.2 主结果。
- 负结果/对比：DPO 与 PPO 优化同一目标，DPO 显著更高效；naïve（去加权）DPO 会退化（Appendix Table3）。

## §6 局限
- 分布外泛化：仅初步证据表明 DPO 与 PPO 泛化相当；需更全面研究；示例：DPO 自标注能否像 PPO 一样利用未标注 prompts。
- Reward over-optimization：在 DPO 直接偏好优化下如何表现未知；Figure3-right 的轻微性能下降是否即其体现待确认。
- 规模上限：仅在 ≤6B 模型上实验；扩展到 SOTA 级大模型（数量级更大）是未来方向。
- 评判依赖 prompt：GPT-4 算出的 win rate 受 prompt 形式影响（GPT-4(S) vs GPT-4(C) 结果不同），需研究如何引出高质量自动评判（作者用 GPT-4(C) prompt 作主结果）。
- 依赖人工/离线偏好数据：若 π^SFT 不可用需用 preferred completion 重建 reference，存在分布漂移问题（用 maximize likelihood on (x,y_w) 缓解，但并非完全消除）。
- Beta 超参未精调：摘要实验未大幅调节 DPO 的 β，作者认为结果可能低估 DPO 潜力。
- 应用面超出文本：DPO 可推广到其他模态的生成模型（未来方向，未在本工作验证）。
