## §4 方法细节

### 4.1 低秩参数化更新矩阵（§4.1, p4）
- 动机：Aghajanyan et al. (2020) 指出预训练语言模型存在低「内在维度/intrinsic dimension」，随机投影到小子空间仍能高效学习；据此假设「权重的更新 ΔW 在适配时也具有低 intrinsic rank」。
- 对预训练权重矩阵 W₀ ∈ R^{d×k}，将更新约束为低秩分解：W = W₀ + ΔW = W₀ + B·A，其中 B ∈ R^{d×r}, A ∈ R^{r×k}，rank r ≪ min(d, k)。
- B 初始化为 0（保证 ΔW=0 起始）；A 用高斯初始化（A ~ N(0, σ)）。初始化使训练开始时与原始预训练模型一致。
- 缩放：ΔW = (α/r)·B·A，α 为与 r 相关的超参（r 变化时调整），使训练稳定。
- 推理时：梯度/优化器只需维护 B、A，主权重 W₀ 冻结，从而 3 倍降低 Adam 的显存。

### 4.2 应用到 Transformer（§4.2, p5）
- Transformer 自注意力四权重 W_q, W_k, W_v, W_o + MLP 两权重；作者把 W_q（或 W_q,W_v,W_k,W_o）当作单一 d_model×d_model 矩阵（即便输出会切分到 attention heads）。
- **仅适配注意力权重，冻结 MLP 模块**（为简洁与参数效率）；文中明确把「适配 MLP/LayerNorm/bias」留作未来工作。
- 优势：训练更高效、硬件门槛降到 1/3；部署时只交换 LoRA 权重即可低成本切换任务（不用换全部参数）。
- 与 adapter 本质区别：LoRA 的学到矩阵可**合并**回主权重（推理时不增加深度），故无任何推理延迟（§6, p9）。

## §5 实验结果要点

### 5.1 GPT-2 推理延迟（Table1, p4）
- 单次前向，NVIDIA Quadro RTX 8000，100 次平均。
- Batch=32, len=512：FT/LoRA 1449.4ms；Adapter^L 1482.0ms(+2.2%)；Adapter^H 1492.2ms(+3.0%)。
- Batch=1, len=128：FT/LoRA 19.8ms；Adapter^L 23.9ms(+20.7%)；Adapter^H 25.8ms(+30.3%)。
- 结论：adapter 在短序列在线场景延迟代价显著；LoRA 由于可合并权重，无额外 inference latency。

### 5.2 GPT-2 在 E2E NLG Challenge（Table3, p7）
- GPT-2 medium：FT 68.2 BLEU；LoRA(0.35M) 70.4 BLEU，超过 FT(25.19M) 68.1。
- GPT-2 large：FT 68.5；LoRA(0.77M) 70.4，超过 FT(774.03M) 68.5 与 PreLayer(0.77M) 70.3。
- 结论：LoRA 用可比或更少的可训练参数超过多个 baseline。

### 5.3 RoBERTa-base/large 与 DeBERTa-XXL（Table2, p6）
- RoBERTa-base GLUE Avg：FT 86.4 / LoRA 87.2。
- RoBERTa-large：FT 88.9 / LoRA 89.0。
- DeBERTa-XXL：FT 91.1 / LoRA 91.3。
- CoLA 单项上 LoRA 往往更强（如 base：FT 63.6 / LoRA 63.4、large：68.0 vs 68.2 等）。

### 5.4 GPT-3 175B（Table4, p8）
- WikiSQL：FT 73.8 / LoRA(4.7M) 73.4 / LoRA(37.7M) 74.0。
- MNLI-m：FT 89.5 / LoRA(4.7M) 91.7（显著提升）。
- SAMSum R1/R2/RL：FT 52.0/28.0/44.5 → LoRA 53.8/29.8/45.9（更高）。
- 结论：在 GPT-3 175B 上 LoRA 全部三任务持平或超过全微调。作者指出并非所有方法随可训练参数增加单调受益（如 prefix tuning 超过 256/32 特殊 token 会出现明显退化，Figure2）。

## §6 局限

1. **只评估注意力权重**：仅对 self-attention 的 W_q/W_k/W_v/W_o 做 LoRA，未实证 MLP、LayerNorm、bias 等（§4.2 p5；留作未来工作）。
2. **低秩假设是经验观察**：作者通过子空间相似度（§7.2 p11）给出「ΔW 内在低秩」的部分证据，但未证明一般成立；某些任务 ΔW 可能不秩亏。且作者对「ΔW 与 W 的相关性、ΔW 相对 W 的大小」（问题(2)(3)）指向「其回答可阐明预训练模型下游适配原理」（§7, p10）。
3. **退化/非单调现象即显式局限**：prefix-embedding 或 prefix-layer tuning 在 token 数超过 256/32 时性能明显下降，作者明言「挖掘该现象超出本文范围」（§5.5, p8）。
4. **rank 选择无通用公式**：实践中 r 靠任务/预算试探（GPT-3 上 r=8 或 4；r=1 也很好）；无自动 rank 选择方法（§7.2, p10–11）。
5. **仍需下发 LoRA 权重**：虽然共享主模型，但每个任务要存储各自的 A/B 低秩矩阵，任务数量巨大时存储与管理成本需权衡（§4.2, p5）。
6. **对 GPT-3 175B 的完整统计报告受限**：因训练成本高昂，仅对特定任务在随机种子下报告典型标准差，未对每一项都提供区间（§5.5, p8）。
7. **收益集中在「参数效率」而非「绝对精度上限」**：LoRA 目标是对齐/略微超越全微调，而非突破下游任务精度上限；大规模下游任务极限仍需探索。
