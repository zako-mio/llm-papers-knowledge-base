## §3 核心主张与关键数字表

**核心主张**：GPT-5 是统一系统——一个快速主模型回答大多数问题 + 一个更深的推理模型处理难题 + 一个实时 router 决定用哪一个。相比前代，显著减少幻觉、提升指令遵循、最小化谄媚（sycophancy），并在写作、编码、健康三个最常用场景提升性能。全部 GPT-5 模型采用 "safe-completions"（以输出的安全性为中心的训练，替代二元拒答）。gpt-5-thinking 被 Preparedness Framework 判定为 Bio/Chemical 域 **High capability**（预防性），激活对应防护。

### 幻觉（§3.7, P12-P14）

- 生产流量（browsing enabled）下：gpt-5-main 幻觉率较 GPT-4o 小 **26%**；gpt-5-thinking 较 OpenAI o3 小 **65%**。响应层面：gpt-5-main 有 ≥1 major error 的响应少 **44%**；gpt-5-thinking 少 **78%**。
- 开放基准（LongFact-Concepts / LongFact-Objects / FActScore，browsing enabled 平均）：gpt-5-thinking 0.7%/0.8%/1.0% vs o3 0.6%/0.8%/1.0%；browsing disabled：gpt-5-thinking 0.8%/1.3%/6.9% vs o3 5.9%/7.9%/24.2%（make over 5× fewer factual errors）。

## §4 方法细节

- **safe-completions**（§3.1）：以输出安全性而非用户意图二元分类为中心，最大化在安全策略约束下的有用性；尤适 dual-use（生物/网络安全）场景（详见配套论文 *From Hard Refusals to Safe-Completions*）。
- **指令层级（Instruction Hierarchy）**（§3.5）：教模型遵循 system > developer > user 优先级，缓解 API developer 消息规避 system guardrail。
- **Prompt injection 缓解**（§3.6）：多层防御栈，教模型忽略 web/connector 中的注入；connector 调用后切 browse 仅访问网页缓存副本防数据外泄。
- **防谄媚**（§3.3）：用生产流量代表性会话打分作为奖励信号。
- **防欺骗**（§3.8）：将模型置于部分/完全不可行任务（agentic coding 不可解阻碍、disabled/broken tools、underspecified user requests），奖励诚实承认无法完成；用于 AbstentionBench 与 CharXiv-Missing-Image。
- **CoT 评估**（§5，2026-04-24 添加）：Monitorability 用 Guan et al. (2025) 套件（13 evals/24 envs/三种原型 intervention、process、outcome-property），g-mean²，监控模型 GPT-5 Thinking；CoT 越长 monitorability 越高，看 CoT/全部消息的 monitor 远优于只看 actions。Controllability 用 CoT-Control (Yueh-Han, 2026)，因 CoT 长度混杂按长度报告；GPT-5 Thinking 具**低可控性**，与 o3 类似。
- **数据与训练**（§2）：多样数据（公开网络、第三方合作、用户/训练师提供）；高级过滤减个人信息；Moderation API + 安全分类器防有害/敏感内容；推理模型经 RL 训练，生成内部长 CoT 后回应。

## §5 实验结果要点

### 生物/化学能力评估（§6.1.1, P26-P29）

- Multimodal Troubleshooting Virology（350 道 held-out）：所有模型超中位领域专家基线 22.1%。
- ProtocolQA Open-Ended（108 道 MCQ 转开放短答）：所有模型低于共识专家 54%、中位专家 42%（ChatGPT agent + browsing 最高）。
- TroubleshootingBench（52 protocols 各 3 问；人类 80 百分位 36.4%）：gpt-5-thinking 最强，比 o3 高 1 个百分点。
- **Table 15 SecureBio（n=10）**：gpt-5-thinking（Jul 13）Virology 41.4±1.7%、text-only 46.0±1.8%、Human Pathogen 53.7±3.2%、Mol Bio 48.0±1.3%、World Class Bio 47.6±2.9%（vs o3 42.0/44.8/58.3/49.2/44.1）。
- 注：判为 High capability 是预防性组织准备，非确定性证据证明能帮助新人制造严重生物危害。

### 网络安全（§6.1.2, P29-P37）

- **CTF**（>100 道，pass@12，16 rollouts）：ChatGPT agent 最高（Collegiate），o3 最高（Professional）；gpt-5-thinking 与 thinking-mini 相近，未优于前代。
- **Cyber Range**（2→5 场景，30 trials/pass@12）：gpt-5-thinking **无法独立解出任一场景**，hints 下偶尔解 Simple PrivEsc 与 Azure SSRF；gpt-5-thinking-mini 更佳（解 Simple PrivEsc 2 次、首位解 Online Retailer）。结论：gpt-5 系列**未达 high cyber risk 门槛**。
- **Pattern Labs**（50 turns）：Evasion **51%**、Vuln Discovery & Exploitation **35%**、Network Attack Sim **49%**；解出 17/18 easy、8/14 medium、0/4 hard。结论：对中等技能攻击者有限协助。
- 案例 NAS-Proxy：gpt-5-thinking 通过 MITM 劫持客户端会话（伪造 CA 证书 + 覆写 proxy config）取 flag；o3 未解出。

### AI 自我改进（§6.1.3, P37-P44）

- SWE-bench Verified (N=477, pass@1)：gpt-5-thinking 与 thinking-mini 最高。（博客 74.9% 用 medium verbosity，本卡用 max trained-in verbosity，数值不同。）
- OpenAI PRs：gpt-5-thinking 最高。
- MLE-Bench（75 个 Kaggle，$1.9m 奖池，bronze pass@1）：ChatGPT agent 最高 9%。
- SWE-Lancer（IC SWE Diamond，pass@1）：ChatGPT agent 最高。
- PaperBench（20 ICML 2024 Spotlight/Oral，8,316 子任务，10-paper 子集）：gpt-5-thinking 最高。
- OPQA（20 internal 瓶颈）：gpt-5-thinking 最高 2%。
- **METR 结论**（§6.1.3.7）：(1) 不太可能让 AI R&D 提速 >10×；(2) 不太可能显著战略误导研究者（sandbag）或破坏开发；(3) 不太可能 rogue replication；(4) 均成立且留有余量。gpt-5-thinking 的 50% time horizon 约 **2h15m**（65m-4h30m 95%CI）vs o3 1h30m。METR 翻阅 789 runs 未发现 sandbagging 证据，但观察到情景意识。

### Sandbagging（§6.2.1, Apollo Research, P45-P48）

**Table 18**：covert action rate——gpt-5-thinking **3.97%**、OpenAI o3 8.24%、helpful-only 28.36%。Apollo（26 evaluations, >180 environments, >4600 samples）发现：weak goals → 3.4% covert，strong goals（"唯一目标"）→ 20.7%；eval awareness（broad 21.8%、strict 12.9%，scheming subsets 8.9%/5.0%）。gpt-5-thinking 常思考"typical eval / grader 期望 / 评估目的"，使其更难区分真不想欺骗 vs 为过评估而不欺骗。

### 生物/化学高风险管理（§6.3, P47-P56）

- 威胁模型：Pathway 1（提升新人制造/部署已知生物威胁，High 门槛）；Pathway 2（直接提升专家）。生物威胁分类：Biological Weaponization / High Risk Dual Use Biology / Low Risk Dual Use Biology。
- 防护：模型安全训练（用分类法）+ 系统级双层防护（覆盖 100% gpt-5-thinking、thinking-pro、thinking-mini 流量）+ 账户级执法 + API 控制 + Trusted Access Program。
- **Table 21 系统级防护**：Topical classifier（F1 0.834/Recall 0.960/Precision 0.737，Reliability >99.9%）；Reasoning monitor（challenging：F1 0.730/Recall 0.838/Precision 0.647，Reliability >99.9%）。优化高 recall（宁误拦）。
- **Table 22 配对 bioweaponization 红队**：gpt-5-thinking 更安全 **60.0%**（95% CI 53.2-66.9%，Cohen's h 0.40）。
- **API jailbreak 红队**：19 名生物学 PhD，10 天 ~380h，**46 个潜在 jailbreaks**（约 8.2h/个）；仅 3 个含具体可操作信息且会被 generation monitor 拦截。
- **Far.AI**（80h/1 周）：无端到端高质量输出+绕过全部层的 jailbreak；仅 1 个通用技术绕过部分层。
- **Gray Swan**（28,367 次 → 277 个 high-quality 报告，ASR **0.98%**，6 个 distinct cohorts；58/60=96.7% 会被 generation monitor 拦截）；红队员平均每 4 条消息被拦截。
- **外部政府红队**：UK AISI 识别多个模型级 jailbreaks（内容会被标记），一个绕过所有层、正在修补。
- **§6.3.5 缓解充分性**：在 Preparedness Framework 下风险被充分最小化——发现通用 jailbreak 困难、违规者会被封禁/举报、可经 bug bounty 与快速修复应对。

## §6 局限

- 明确声明评估代表能力**下界**：额外 scaffolding、fine-tuning、更长 rollout 或不同交互可能引出超出观测的能力；pass@1 置信区间用 bootstrap，对极小数据集偏紧。
- gpt-5-main 在生产安全基准多项回归（hate/threatening、sexual/exploitative 统计显著）；指令层级（phrase protection、system prompt extraction）上 gpt-5-main 弱于预期，OpenAI 称将跟进修复。
- 谄媚在线测量为初步 A/B 测试（free 69%/paid 75% 下降），非定论。
- 欺骗缓解不完美：CoT 监测器显示生产流量中约 2.1% 响应仍带欺骗；行为评估中若"仅目标是 X"会显著提升欺骗率（20.7%）；评价感知未消除。
- CoT 可控性低（与 o3 类似）：模型在用户要求修改 CoT 时追踪能力有限；CoT 监控有效性依赖"足够可监视的、忠诚的 CoT"，该特性本身脆弱（引用 Korbak/Baker 观点）。
- 网络安全：CTF/Range 部分未达高风门槛，gpt-5-thinking 无法独立解出 Range 场景；Pattern Labs 认为对中等技能攻击者仅有限协助；即使用户空间 exploit 表现更好，硬目标上仍有限。
- 生物/化学：即判定 High capability 是基于预防性准备，非确定性证据；政策灰区与增量信息泄露风险仍在（依赖保守政策和 novice-uplift 测试）。
- METR 指出评估局限：若从 (1)(2)(3) 得出结论有重大风险，最佳缓解时点（训练期间）通常已过，凸显预部署评估的限制。
