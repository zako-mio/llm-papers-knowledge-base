## §3 核心主张与关键数字表

**核心主张**：同时推进两条缩放轴（scaling axis）——将预训练基础模型扩展到史无前例的 3T 级参数，同时把 RL、推理强度和长程交互扩展到 1M 上下文。Kimi K3 是首个开放 3T 级模型，整体缩放效率较 Kimi K2 提升约 **2.5×**，在长程编码、agentic、知识、推理与视觉任务上仅次于最强闭源系统（Claude Fable 5、GPT-5.6 Sol），领先其余开源与闭源模型。

### 架构关键设计（P2-P10）

- **KDA**：channel-wise forget gate 的 delta-rule 循环 `S_t=(I-β_t k_t k_t^T)Diag(α_t)S_{t-1}+β_t k_t v_t^T`，`ő_t=S_t^T q_t`。log-decay 映射改为缩放 sigmoid，`g_min=-5`，使 retention factor `α>e^-5≈6.7×10^-3`，16-token tile 累计 log-decay ∈(-80,0)，对角线 tile 也可用 dense Tensor Core 乘法。
- **Gated MLA**：沿用 DeepSeek-V2 MLA + 全 MLA 层采用 NoPE（无位置编码）；增加输入依赖全秩输出门 `y_t=W_o[Sigmoid(W_g x_t)⊙ő_t]`；训练中 attention 输出保留 FP32。
- **AttnRes**：每层用可学习 pseudo-query 选择性检索前面所有层；开销 O(Ld)→O(Nd)。93 层分 **8 blocks**（每块 12 层，含 embedding 共 9 块）。
- **Stable LatentMoE**：LatentMoE 将全宽与路由专家宽分离，每 token 激活 896 专家中的 16（稀疏度 56）。三项稳定化：up-projection 前 RMSNorm、SiTU-GLU、Quantile Balancing。Shared experts 固定 `Ns=2`。
- **SiTU-GLU**：`β1·tanh(W_g x/β1)⊙Sigmoid(W_g x)⊙(β2·tanh(W_u x/β2))`，`β1=4`、`β2=25`，输出界 `|f(x)|≤β1β2=100`。
- **Quantile Balancing (QB)**：auxiliary-loss-free 路由，按目标分位数设偏置，Top-(k+1) 取 cutoff，`b^(t+1)_j←-quantile_{1-k/n}(s_{:,j}-α^(t))`；分位数用直方图估计（每专家几百个 bin）。
- **MoonViT-V2**：27 层 ViT，约 0.4B 参数，从头以 next-token prediction 训练（不用 SigLIP 初始化，提升稳定性）；pixel-shuffle 2×2 降采样，支持最大 3584×3584 像素。
- **Per-Head Muon**：对 Q/K/V 动量矩阵按 head 切分逐个正交化。

### 预训练（P10-P12）

- 数据：四大文本域（Web Text / Code / Math / Knowledge）+ 大规模视觉语料；含程序化多模态数据（SVG、3D、Webpage、Game、CAD）。
- Scaling law：整体缩放效率较 Kimi K2 提升约 **2.5×**（Fig 7）。偏好在各自最优超参下 **cosine decay** 优于 WSD。
- 训练：Per-Head Muon 优化器 + 权重裁剪 + QB 负载均衡；cosine 学习率 + 1% warmup；weight decay 0.1。
- 上下文：训练初始 8K，后扩至 64K；cooldown 阶段 256K→1M（四阶段课程）。

### 后训练（P12-P18）

- 三阶段：SFT 冷启动 → 域专家 RL（三域 × 三推理强度 {low, high, max} = 9 个专家模型）→ Multi-Teacher On-Policy Distillation (MOPD) 收敛为单一模型。RL 训练长程 coding、general agents、general reasoning/knowledge，每个跨多级推理强度。
- 环境：可验证 search 与专业知识工作、software engineering 与 kernel 优化、多模态推理 + vision-in-the-loop 工具使用、persistent assistant 工作流、web 开发、autonomous execution。触发 1M 上下文、数百上千次工具调用、累积极百万 token 的 "reasoning-acting-observing-verifying-adapting" 循环。
- XTML 序列化；SFT 起采用 QAT（MXFP4 权重 / MXFP8 激活）。

## §4 方法细节

- **KDA chunkwise**：chunk 内并行、chunk 间循环；`O[t]=(Γ⊙Q)S[t](inter-chunk)+A[t]·ẽV[t](intra-chunk)`；`Tril()` 保留含对角线的 lower-triangular 实现因果。
- **MoE 前向**：`u=Σ_{i∈T_k(x)} p_i E_i^routed(W↓x)`；`y=Σ_j E_j^shared(x)+W↑RMSNorm(u)`。
- **Agentic RL 环境（§4.2）**：统一白盒 RL 环境、知识图谱引导任务合成、agentic 环境可验证问题、kernel optimization / personal assistant / autonomous execution / web development 任务。
- **训练系统（§5.x）**：MoonEP（完美平衡专家并行 MoE、静态计算形状 + zero-copy 通信）；统一 activation manager（recompute/quantization/offload 可组合，block-wise FP8）；SonicMoE 式梯度重写；cache-based pipeline 通信；跨 PP rank 远程 offload（Mooncake）；Pipeline ZeRO-2 梯度分片到 CPU；P2P Muon 正交化；动态 CP + ViT 计算隐藏进 pipeline bubble；co-located RL + partial rollouts + write-back 外部 KV cache 池 + 自适应限制调度器 + 参考权重梯度缓冲复用。
- **AgentENV**（Firecracker 微VM sandbox，开源）：checkpoint 133ms / resume 49ms、pause/resume（等待推理约占 sandbox 生命周期 98%）、fork（奖励判定）、snapshot；OverlayBD + ublk，内存 overcommit 6.5×。
- **推理**：KDA-aware 前缀缓存（MLA 用 512-token hash block 细粒度，物理 block 6144 token；KDA checkpoint 稀疏保存于 hash 端点，可在 B=2560 命中；chained hash 保证整段前缀匹配）；cache-aware affinity 调度（主/备双 cluster）+ budget-based admission control。
- **解码 Kernel**：KDA 状态 replay（缓存 projected inputs，on-chip 重建 accepted tokens 状态，ReplaySSM 独立提出）；Block AttnRes 的 SP 激活 + 侧流 + 融合；Stable LatentMoE 的 latent GEMM 融合 + WarpDecode token-centric 解码。

## §6 局限

- 明确承认在最强闭源系统（Claude Fable 5、GPT-5.6 Sol）之后；在 Elo 类知识工作套件（GDPval-AA v2、AA-Briefcase）及部分 harder computer-use 基准（OSWorld 2.0、SaaS-Bench）仍落后。
- 内部套件揭示的弱点：Agent Behavior Bench、MIRA Bench、24/7 ClawBench 2.0、Agentic Vision Bench、KWV Bench 落后领先者。
- 网络安全：Tier 2 对 hardened targets（Linux kernel）瓶颈明显，14 个成功中仅 4 个来自 kernel track；未解决任务直接衡量与人类专家能力的差距；四个失败模式（链条收尾困难、mitigation 下策略选择差、卡死调试循环、交付前验证不足）。自评被作者视为能力下界。
- 引用与训练数据质量：长文档/视频含大量低质内容需专门清理；long-context 能力需靠合成数据维持。
- 上下文窗口扩展依赖 KDA 的无位置编码泛化，极端长度下可靠性未完全覆盖。
