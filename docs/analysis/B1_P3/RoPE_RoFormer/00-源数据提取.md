## §3 核心主张与关键数字表

**核心主张**: 提出旋转位置嵌入 RoPE——用旋转矩阵编码绝对位置，同时在 self-attention 内显式纳入相对位置依赖。相比传统"加法式"位置编码，RoPE 是"乘法式"的，具备序列长度灵活、随相对距离增加而衰减的 token 间依赖、以及能配线性 self-attention 三大特性；RoFormer 在长文本基准上持续优于基线。

## §4 方法细节

- **问题形式化**: 要求 query 与 key 的内积只以相对位置形式编码位置信息：⟨fq(xm,m), fk(xn,n)⟩ = g(xm, xn, m-n)。
- **2D 情形推导**: 取 d=2，用复平面与向量几何证明解为 fq(xm,m)=(W^q xm)e^(imθ)、fk(xn,n)=(W^k xn)e^(inθ)，g=Re[(W^q xm)(W^k xn)* e^(i(m-n)θ)]；即把仿射变换后的词向量按位置索引倍的角旋转。
- **一般形式**: d 为偶数时把 d 维空间分为 d/2 个子空间，用旋转矩阵 R^d_Θ,m（块对角 2x2 旋转矩阵）组合；内积化为 x^T W^q R^d_Θ,(n-m) W^k xn。
- **关键性质**:
  1. **乘法式而非加法式**（对比所有加法式位置编码公式 Eq.3-10）。
  2. **长期衰减**: θi=10000^(-2i/d) 保证内积随相对距离增加而衰减（§3.4.3 用 Abel 变换证明）——长距离 token 连接更弱，符合直觉。
  3. **与线性 attention 兼容**: 旋转保持隐藏表示范数不变，因此可将 R^d 乘到线性 attention 的非负函数输出上（Eq.19），分母保持不变避免除以零。
  4. R^d_Θ 为正交矩阵，保证编码位置过程稳定。
- **计算高效实现**（Eq.34）: 利用稀疏性，旋转矩阵乘向量等效为构造 [cos mθ1, cos mθ1, cos mθ2, cos mθ2, ...] 与 [sin ...] 的逐位乘法。
- **理论与实现**: 预训练 BERT：替换 sin 位置编码为 RoPE，batch 64，max seq 512，100k steps，AdamW lr 1e-5；GLUE 微调用 HuggingFace Transformers，3 epochs，max seq 512，batch 32，lr 2/3/4/5e-5。

## §5 实验结果要点

1. **机器翻译**（Table 1, P9）: 相同设置下 RoFormer 在 WMT14 En-De 得 BLEU 27.5 优于基线 Transformer 27.3；fairseq 实现，beam size 4，length penalty 0.6，Adafactor/Adam β1=0.9 β2=0.98，lr 1e-7→5e-4 线性上升再按步数平方根衰减，label smoothing 0.1，vocal 37k joint BPE，最后 5 个 checkpoint 平均。
2. **预训练语言建模**（Fig 3 左, P10）: RoFormer 的 MLM loss 训练曲线收敛更快，优于 vanilla BERT；RoPE 替代 sin 位置编码。
3. **GLUE 微调**（Table 2, P10）: RoFormer 在 6 个数据集中 3 个（MRPC、STS-B、QQP）显著优于 BERT，其余（SST-2、QNLI、MNLI）反而不如——注意 MNLI/QQP 结果方差较大。
4. **Performer + RoPE**（Fig 3 右, P10-P11）: 在 Enwik8 上 12 层 char 级 Performer（768 维、12 heads），加入 RoPE 后收敛更快且同训练步数下 loss 更低；在保持线性复杂度的同时实现相对位置编码。
5. **中文长文本**（Table 5, P12）: 切到 1024 长度上限时 RoFormer 测试 69.79%，压过 WoBERT-512（68.10%）与 BERT-512（67.77%）；RoFormer 精度随序列长度上限增加而提升（体现 RoPE 应对长文本能力）。CAIL2019-SCM 含 8964 个三元组（最高法院发布案件），多为超 512 字符的长文档。

## §6 局限

- 作者自述（§4.5.5, P12）:
  - 虽用 2D 子空间旋转数学形式化相对位置，但**缺乏对"为何比其它位置编码收敛更快"的透彻解释**。
  - 虽证明长期衰减特性（与既有位置编码类似），但**未对"为何长文本表现更优"给出可靠解释**。
- RoFormer 基于 Transformer 基础架构，**预训练需要硬件资源**（实验在 4×V100 GPU 的两台云服务器上完成）。
- GLUE 上并非全面占优（SST-2、QNLI、MNLI 弱于 BERT），仅在部分任务获胜，且部分对比因基准版本差异未必公平。
