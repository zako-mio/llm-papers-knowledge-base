核心结论：**给定 FLOPs 预算，模型参数量(N)与训练 token 数(D)应等比例增长**，即 N∝C^a、D∝C^b，其中 a≈b≈0.5。此结论与 Kaplan et al. (2020) 的 a=0.73、b=0.27 显著不同。

## §4 方法细节

### 4.1 问题设定（§1, Eq.1）
给定固定 FLOPs 预算 C，最小化最终预训练损失 L(N,D)（N=参数数，D=训练 token 数），约束 FLOPs(N,D)=C：

N_opt(C), D_opt(C) = argmin_{N,D: FLOPs(N,D)=C} L(N,D)

采用平滑训练损失作为测试损失的无偏估计（无限数据域：训练 token 数 < 整个语料 token 数）。

### 4.2 Approach 1：固定模型规模，变化训练 token（§3.1）
对每一参数量 N 训练 4 个模型，学习率在 horizon（token 数）上衰减 10×，horizon 变化 16×。平滑并插值训练曲线，得到每个 run "FLOPs→loss" 的连续映射；对每个 FLOP 值挑 loss 最低的模型。在 1500 个对数间隔 FLOP 值上估计最优 N、D，拟合幂律，得 a=0.50、b=0.50。选点均在训练后 15% 内，因此应选择余弦循环长度约等于 D。

### 4.3 Approach 2：IsoFLOP 剖面（§3.2）
对 9 个固定训练 FLOP 数（6×10^18 到 3×10^21）变化模型规模（可达 16B），考虑每个点的最终训练损失。对每条 IsoFLOP 曲线拟合抛物线（参数-损失谷值），再拟合 FLOPs 与 loss-最优规模/token 的幂律，得 a=0.49、b=0.51。余弦长度 = 匹配的 token 数（最优）。选点离 Gopher 预算投影 63B 参数、1.4T token。

### 4.4 Approach 3：参数化损失函数拟合（§3.3, Eq.2）
经典风险分解：

L̂(N,D) = E + A/N^α + B/D^β

第一项 = 理想生成过程（数据熵），第二项 = 有限参数不完美，第三项 = 有限优化步/数据采样。用 Huber 损失（δ=10^-3，抗离群）+ L-BFGS 最小化 log-loss 残差；从初始化网格取最优。此法得 a=0.46、b=0.54。

高效前沿（Eq.4）：N_opt(C)=G(C/6)^a，D_opt(C)=G^-1(C/6)^b，其中 G=(αA/βB)^(1/(α+β))，a=β/(α+β)，b=α/(α+β)。用 FLOPs(N,D)≈6ND（Kaplan）。在 Approach 3（左图高效前沿蓝色线）投影 Gopher 预算最优模型约 40B。

### 4.5 Chinchilla 训练设置（§4.1）
- 数据：MassiveText（与 Gopher 相同），但子集分布略调整以适配更大 token 数。
- 优化器：AdamW（相较于 Gopher 的 Adam），提升 LM loss 与微调后任务性能。
- 分词：修改版 SentencePiece，不做 NFKC 归一化；词表与 Gopher 94.15% 相同，利于数学/化学表示。
- 精度：前向/反向 bfloat16，分布式优化器状态保留 float32 权重副本。
- 硬件：TPUv3/TPUv4 + JAX + Haiku。
- 与 Gopher 同 FLOPs 预算，但规模小 4×、数据多 4×（1.4T tokens），内存与推理成本因此更小。

## §5 实验结果要点

- 三种方法预测一致（详 §3.1 表）：现役大型模型普遍"过大规模"——对给定 compute budget 应更小、训练更久。
- 对 175B 模型：最优应配 4.41×10^24 FLOPs、超 4.2T tokens（正文 §3.4）；280B（Gopher 式）对应约 10^25 FLOPs——需 6.8T tokens（表 3 为 5.9T，此处正文引 6.8T，两者为不同近似来源）。
- 需超过 10^26 FLOPs（Gopher 的 250×），1T 参数模型才可能为最优——主流判断：目前规模偏大。
- 预测需数据量远超现状，凸显"数据集采集"与"工程改进"同等重要。
- Chinchilla 验证：更小的 70B 反而全面优于 Gopher 及更大模型（GPT-3 175B、Jurassic-1 178B、MT-NLG 530B）在大量下游评测上。同时降低了微调/推理的计算成本。
- 附录 C 在 C4 与 GitHub code 数据集上复现 IsoFLOP 分析，均得出"等比例缩放"结论。
- 性别/毒性：模型展现偏置与毒性，但有趣的是受偏置/毒性影响似乎小于 Gopher（§5）。

## §6 局限（§5）

- 大规模实验成本高：仅有 Chinchilla 与 Gopher 两组同级可对比 run，无中间规模验证。
- 假设高效前沿可由 compute/模型规模/token 数之间的幂律关系描述；但在高 compute 下 log N_opt 存在凹性（附录 E），可能仍高估大模型最优规模。
- 分析所用训练 run 均训练不到 1 个 epoch（无限数据域假设），未来需研究多 epoch 场景。
- 数据泄露：Chinchilla 训练 4× 更多数据，与 Gopher 的 LM 基准对比可能受 train/test 泄漏影响（作者因此更强调 MMLU、BIG-bench 等）。
- 真值性/毒性评估有限，模型仍存在显著偏置与幻觉风险。
