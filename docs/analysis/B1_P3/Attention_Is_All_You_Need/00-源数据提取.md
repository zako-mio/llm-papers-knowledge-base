## §3 核心主张与关键数字表

### §3.1 核心主张（含定位）
- **首个完全基于注意力、抛弃循环（recurrence）与卷积（convolution）的序列转导模型**（序言、§2 末）。
- 在可并行性与推理路径长度上显著优于 RNN/CNN：self-attention 连接任意两位置只需**常数级（O(1)）串行操作**，而 RNN 需 O(n)（Table 1）。

## §4 方法细节要点

### §4.1 总体架构
- Encoder-Decoder 结构：encoder 将符号序列映射为连续表示 z=(z1..zn)；decoder 逐元素自回归生成（§3）。
- 每层含 multi-head self-attention（或 encoder-decoder attention）子层 + position-wise FFN 子层，每个子层外包裹残差连接 + LayerNorm：`LayerNorm(x + Sublayer(x))`。所有子层及 embedding 输出维度 d_model（§3.1）。
- decoder 在编码器子层基础上额外插入一个对 encoder 输出做 multi-head attention 的子层。为保持自回归，decoder self-attention 做 mask（softmax 输入置 −∞）屏蔽后续位置（§3.1、§3.2.3）。

### §4.2 Scaled Dot-Product Attention
- `Attention(Q,K,V) = softmax(QK^T / sqrt(d_k)) V`（式1）。
- 除以 sqrt(d_k) 抵御大 d_k 下点积幅值增大导致 softmax 进入小梯度区（§3.2.1，脚注：q、k 分量为独立均值0方差1时，点积方差=d_k）。
- dot-product attention 比 additive attention 更快更省空间（可用高度优化矩阵乘法）。

### §4.3 Multi-Head Attention
- `MultiHead(Q,K,V) = Concat(head1..head_h) W^O`，其中 `head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)`（§3.2.2）。
- 论文用 h=8 头，d_k=d_v=d_model/h=64；多头总计算成本近似等于单头全维度注意力。多头允许模型在不同表示子空间、不同位置联合关注信息；单头平均会抑制这一能力（§3.2.2）。

### §4.4 注意力的三种用法
1. **Encoder-Decoder attention**：query 来自 decoder 上一层，key/value 来自 encoder 输出——decoder 每个位置可关注输入序列全位置。
2. **Encoder self-attention**：key/value/query 同源（上一层输出），每个位置可关注上一层全位置。
3. **Decoder self-attention**：mask 保证每个位置只关注其及之前位置（§3.2.3）。

### §4.5 其余组件
- **位置前馈网络**（FFN）：`FFN(x) = max(0, xW1 + b1)W2 + b2`（式2），两线性变换夹 ReLU，即 kernel size 1 的两个卷积；输入/输出维度 d_model，内层 d_ff（§3.3）。
- **位置编码**：正弦余弦 `PE(pos,2i)=sin(pos/10000^(2i/d_model))`，`PE(pos,2i+1)=cos(...)`，波长从 2π 到 10000·2π 几何级数（§3.5）。选择正弦版因为任 ai 固定偏移 k 可写成 PE_pos 的线性函数，且可外推到更长序列；与学习式位置编码结果几乎一致（Table 3 行(E)）。
- **权重共享**：两个 embedding 层与 softmax 前的线性变换共享权重矩阵；embedding 层将权重乘以 sqrt(d_model)（§3.4）。

## §5 实验结果要点

### §5.1 机器翻译（§6.1）
- 英→德：big 模型 28.4 BLEU，超此前最优（含集成）2+ BLEU，新 SOTA；base 模型也超过所有已发表模型/集成，成本仅为其中一部分。
- 英→法：big 模型 41.0 BLEU（正文），超此前所有单模型，训练成本不及此前 SOTA 模型 1/4；摘要/Table 2 记为 41.8。
- 训练配置：base 平均最后 5 个检查点，big 平均最后 20 个；beam search beam=4、α=0.6；最大输出长度=输入+50，尽早终止（§6.1）。

### §5.2 变体分析（§6.2，开发集 newstest2013）
- (A) head 数：单头比最优差 0.9 BLEU；头数过多也下降。
- (B) 减小 d_k 损害质量，提示判定兼容性不易，可能需比点积更复杂的兼容函数。
- (C)(D) 更大模型更好；dropout 对避免过拟合非常有效。
- (E) 正弦 vs 学习式位置编码结果几乎一致。

### §5.3 句法分析泛化（§6.3）
- 训练 4 层 transformer（d_model=1024），词表 16K（WSJ only）/32K（semi-supervised）；推理最大输出=输入+300，beam=21，α=0.3。
- WSJ 训练集仅 40K 句——Transformer 虽未做任务专门调优，仍超过此前所有报告模型（除 RNN Grammar [8]）；且超过 Berkeley-Parser [29] 即便只训 40K 句（与 RNN seq2seq 不同）。

## §6 局限与前提

1. **有效分辨率问题**：self-attention 在保持位置间常数路径长度的同时，因平均 attention 权重导致有效分辨率下降，论文用 Multi-Head Attention 抵消（§2）。
2. **长序列计算成本**：self-attention 在序列长度 n > 表示维度 d 时计算成本高于 RNN；文中主张 n < d 常见，但对超长序列建议改用受限于邻域 size r 的 restricted self-attention（最大路径长度升至 O(n/r)），列为未来工作（§4、Table 1）。
3. **指数假设**：性能必须趋平而非真正达到零损失，幂律仅在非瓶颈区间成立（§1.1、讨论）。
4. **注意力可视化非量化指标**：附录仅展示注意力头的解释性示例（长距离依赖、指代消解、句法结构），属定性质证而非性能证据（§4 side benefit）。
5. **数据与词表相关**：BLEU 与词表大小、字节对编码相关；per-wordpiece 困惑度不可与 per-word 直接比较（Table 3 注）。
6. **训练成本估算**：FLOPs 为估算值（训练时间 × GPU 数 × 单精度持续算力），非精确测量（§6.1 脚注）。
